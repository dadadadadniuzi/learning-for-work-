## 贪心算法理论基础

### 题目链接

- 代码随想录：[贪心算法理论基础](https://programmercarl.com/贪心算法理论基础.html)
- 力扣页面：无。这是方法论，不是单独力扣题。

### 简要回答

贪心算法每一步选择当前局部最优，并希望由局部最优推出全局最优。它没有固定模板，关键是能说明“当前怎么选”以及“为什么这样选不会让最终答案变差”。

### 面试表达

我会先尝试找局部最优策略，再用反例检验。如果能说明每一步局部选择不会让后续更差，就可以用贪心；如果当前选择依赖复杂历史状态，就更像动态规划。

## 455 分发饼干

### 题目链接

- 代码随想录：[455. 分发饼干](https://programmercarl.com/0455.分发饼干.html)
- 力扣页面：[455. Assign Cookies](https://leetcode.cn/problems/assign-cookies/)

### 题目描述

每个孩子有胃口值 `g[i]`，每块饼干有尺寸 `s[j]`。饼干尺寸大于等于孩子胃口时才能满足孩子。每个孩子最多一块饼干，求最多能满足几个孩子。

### 示例

```text
输入：g = [1,2,3], s = [1,1]
输出：1
```

### 贪心选择

小饼干优先喂胃口小的孩子。如果小饼干能满足当前最小胃口孩子，就用掉；否则换更大的饼干。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        // g 是孩子胃口，s 是饼干尺寸；排序后才能从小到大匹配。
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int child = 0;  // 当前等待被满足的孩子下标。
        int cookie = 0; // 当前尝试分配的饼干下标。

        // 只要还有孩子、还有饼干，就继续尝试匹配。
        while (child < g.size() && cookie < s.size()) {
            // 当前饼干能满足当前孩子，就让这个孩子得到满足。
            if (s[cookie] >= g[child]) {
                ++child; // 当前饼干满足当前孩子
            }

            // 无论当前饼干是否满足孩子，这块饼干都已经尝试过了。
            ++cookie;    // 无论是否满足，都尝试下一块饼干
        }

        // child 正好表示已经满足的孩子数量。
        return child;
    }
};
```

### 易错点

- 必须排序后才能让“小饼干优先满足小胃口”成立。
- 返回满足的孩子数量，不是用掉的饼干数量。

## 376 摆动序列

### 题目链接

- 代码随想录：[376. 摆动序列](https://programmercarl.com/0376.摆动序列.html)
- 力扣页面：[376. Wiggle Subsequence](https://leetcode.cn/problems/wiggle-subsequence/)

### 题目描述

如果连续数字之间的差值正负交替，则称为摆动序列。给定数组，返回最长摆动子序列长度。

### 示例

```text
输入：nums = [1,7,4,9,2,5]
输出：6
```

### 贪心选择

只保留峰值和谷值。当前差值和前一个有效差值符号相反时，摆动长度加一。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int wiggleMaxLength(vector<int>& nums) {
        // 空数组或单个元素，本身就是最长摆动序列。
        if (nums.size() <= 1) return nums.size();

        int preDiff = 0; // 上一个有效差值，0 表示还没有形成有效摆动。
        int result = 1;  // 至少可以选择一个元素。

        for (int i = 1; i < nums.size(); ++i) {
            // 当前相邻两个元素的差值。
            int curDiff = nums[i] - nums[i - 1];

            // curDiff 和 preDiff 一正一负，说明出现峰值或谷值。
            // preDiff 为 0 时，第一次出现正/负差值也可以计入。
            if ((curDiff > 0 && preDiff <= 0) ||
                (curDiff < 0 && preDiff >= 0)) {
                ++result;

                // 只有形成摆动时才更新 preDiff；
                // 平坡 curDiff==0 不更新，否则会破坏后续判断。
                preDiff = curDiff; // 只有形成摆动时才更新
            }
        }

        return result;
    }
};
```

### 易错点

- 平坡差值为 0，不应该更新 `preDiff`。
- 初始 `result = 1`，单个元素也是摆动序列。

## 53 最大子数组和

### 题目链接

- 代码随想录：[53. 最大子数组和](https://programmercarl.com/0053.最大子序和.html)
- 力扣页面：[53. Maximum Subarray](https://leetcode.cn/problems/maximum-subarray/)

### 题目描述

给定整数数组，找到和最大的连续子数组，返回其和。

### 示例

```text
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大。
```

### 贪心选择

如果当前连续和已经小于 0，再带着它只会拖累后面的子数组，所以从下一个元素重新开始。

### C++ 详细注释代码

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int result = INT_MIN; // 记录目前遇到的最大连续和，全负数组也能正确处理。
        int count = 0;        // 当前正在累加的连续子数组和。

        for (int x : nums) {
            // 把当前元素接到前面的连续子数组后面。
            count += x;

            // 每加入一个元素，都尝试更新全局最大值。
            result = max(result, count);

            // 如果当前连续和已经为负，继续带着它只会拖累后面的元素。
            if (count < 0) {
                count = 0; // 负前缀直接丢掉
            }
        }

        return result;
    }
};
```

### 易错点

- `result` 要初始化为 `INT_MIN`，否则全负数组会错。
- 这题也可以用动态规划，贪心写法更简洁。

## 122 买卖股票的最佳时机 II

### 题目链接

- 代码随想录：[122. 买卖股票的最佳时机 II](https://programmercarl.com/0122.买卖股票的最佳时机II.html)
- 力扣页面：[122. Best Time to Buy and Sell Stock II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)

### 题目描述

给定每天股票价格，可以多次买卖，但同一时间最多持有一股，求最大利润。

### 示例

```text
输入：prices = [7,1,5,3,6,4]
输出：7
解释：1 买 5 卖，3 买 6 卖。
```

### 贪心选择

把总利润拆成每天差价，只收集所有正利润。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int result = 0; // 收集所有上涨日差价。

        // 从第 1 天开始，看今天相对昨天是否上涨。
        for (int i = 1; i < prices.size(); ++i) {
            int diff = prices[i] - prices[i - 1];

            // 多次交易时，每一段上涨都可以看作一次买卖的一部分。
            if (diff > 0) result += diff;
        }

        return result;
    }
};
```

### 易错点

- 本题允许多次交易，所以可以收集每段上涨利润。
- 如果只能交易一次，就不能这样做。

## 55 跳跃游戏

### 题目链接

- 代码随想录：[55. 跳跃游戏](https://programmercarl.com/0055.跳跃游戏.html)
- 力扣页面：[55. Jump Game](https://leetcode.cn/problems/jump-game/)

### 题目描述

给定数组 `nums`，`nums[i]` 表示从位置 `i` 最多能跳几步，判断是否能到达最后一个下标。

### 示例

```text
输入：nums = [2,3,1,1,4]
输出：true
```

```text
输入：nums = [3,2,1,0,4]
输出：false
```

### 贪心选择

维护当前能覆盖到的最远位置。只要遍历过程中覆盖范围能到达末尾，就成功。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool canJump(vector<int>& nums) {
        int cover = 0; // 当前已经能覆盖到的最远下标。

        // 只能遍历 cover 范围内的位置；超过 cover 的位置当前不可达。
        for (int i = 0; i <= cover; ++i) {
            // 从位置 i 最远能跳到 i + nums[i]，更新全局覆盖范围。
            cover = max(cover, i + nums[i]);

            // 覆盖范围到达或超过最后一个下标，说明可以到达终点。
            if (cover >= nums.size() - 1) return true;
        }

        // 循环结束说明某个位置之后已经不可达。
        return false;
    }
};
```

### 易错点

- 循环条件是 `i <= cover`，超过覆盖范围的位置根本到不了。
- 不关心具体怎么跳，只关心覆盖范围。

## 45 跳跃游戏 II

### 题目链接

- 代码随想录：[45. 跳跃游戏 II](https://programmercarl.com/0045.跳跃游戏II.html)
- 力扣页面：[45. Jump Game II](https://leetcode.cn/problems/jump-game-ii/)

### 题目描述

给定数组 `nums`，每个元素表示最多能跳几步，返回到达最后位置的最少跳跃次数。

### 示例

```text
输入：nums = [2,3,1,1,4]
输出：2
解释：0 -> 1 -> 4。
```

### 贪心选择

在当前一步能到达的范围内，选择能让下一步覆盖最远的位置。当走到当前覆盖边界时，必须增加一次跳跃。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int jump(vector<int>& nums) {
        // 只有一个位置时，不需要跳跃。
        if (nums.size() == 1) return 0;

        int curDistance = 0;  // 当前 steps 次跳跃能到达的最远边界。
        int nextDistance = 0; // 在当前边界内再跳一步能到达的最远位置。
        int steps = 0;        // 已经使用的跳跃次数。

        // 遍历到倒数第二个位置即可，避免站在终点后又多计一次跳跃。
        for (int i = 0; i < nums.size() - 1; ++i) {
            // 枚举当前覆盖范围内的每个点，维护下一跳能覆盖的最远位置。
            nextDistance = max(nextDistance, i + nums[i]);

            // 到达当前跳跃次数的覆盖边界，说明必须再跳一次。
            if (i == curDistance) {
                ++steps;
                curDistance = nextDistance;
            }
        }

        return steps;
    }
};
```

### 易错点

- 遍历到倒数第二个位置即可，避免到终点后多跳一次。
- `curDistance` 是当前跳跃次数能覆盖的边界。

## 1005 K 次取反后最大化的数组和

### 题目链接

- 代码随想录：[1005. K 次取反后最大化的数组和](https://programmercarl.com/1005.K次取反后最大化的数组和.html)
- 力扣页面：[1005. Maximize Sum Of Array After K Negations](https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/)

### 题目描述

给定数组和整数 `k`，每次可以选择一个元素取反，恰好操作 `k` 次，求数组最大和。

### 示例

```text
输入：nums = [4,2,3], k = 1
输出：5
```

### 贪心选择

优先把绝对值大的负数变正；如果还剩奇数次取反，就反转当前绝对值最小的数。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class Solution {
public:
    int largestSumAfterKNegations(vector<int>& nums, int k) {
        // 按绝对值从大到小排：优先处理影响总和最大的数字。
        sort(nums.begin(), nums.end(), [](int a, int b) {
            return abs(a) > abs(b);
        });

        // 优先把负数变正，且优先翻绝对值大的负数。
        for (int& x : nums) {
            if (x < 0 && k > 0) {
                x = -x;
                --k;
            }
        }

        // 如果还剩奇数次，必须再翻一次；
        // 此时 nums.back() 是绝对值最小的数，损失最小。
        if (k % 2 == 1) {
            nums.back() = -nums.back();
        }

        // 返回操作后的数组和。
        return accumulate(nums.begin(), nums.end(), 0);
    }
};
```

### 易错点

- 最后剩奇数次时，要取反绝对值最小的元素。
- 按绝对值从大到小排序。

## 134 加油站

### 题目链接

- 代码随想录：[134. 加油站](https://programmercarl.com/0134.加油站.html)
- 力扣页面：[134. Gas Station](https://leetcode.cn/problems/gas-station/)

### 题目描述

环路上有若干加油站，`gas[i]` 是可加油量，`cost[i]` 是去下一站消耗。返回能绕一圈的起点下标；若不存在，返回 `-1`。

### 示例

```text
输入：gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出：3
```

### 贪心选择

如果从当前起点走到 `i` 时油量累计为负，说明当前起点到 `i` 之间任何点都不能作为起点，直接从 `i + 1` 重新开始。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int totalSum = 0; // 全局剩余油量，用来判断是否存在答案。
        int curSum = 0;   // 从当前 start 出发到当前位置的剩余油量。
        int start = 0;    // 当前尝试的起点。

        for (int i = 0; i < gas.size(); ++i) {
            // 到达 i 站后加油，再去下一站的净收益。
            int rest = gas[i] - cost[i];
            totalSum += rest;
            curSum += rest;

            // 从 start 到 i 都无法支撑继续前进，
            // 则 start..i 中任意位置都不可能作为起点。
            if (curSum < 0) {
                start = i + 1;
                curSum = 0;
            }
        }

        // 总油量不足时无论从哪里出发都不能绕一圈。
        return totalSum < 0 ? -1 : start;
    }
};
```

### 易错点

- 总油量小于总消耗时一定无解。
- `curSum < 0` 时，当前区间内所有点都不可能是起点。

## 135 分发糖果

### 题目链接

- 代码随想录：[135. 分发糖果](https://programmercarl.com/0135.分发糖果.html)
- 力扣页面：[135. Candy](https://leetcode.cn/problems/candy/)

### 题目描述

每个孩子至少一颗糖。相邻孩子中，评分更高的孩子必须比评分低的孩子糖更多。求最少糖果数。

### 示例

```text
输入：ratings = [1,0,2]
输出：5
```

### 贪心选择

左右两边约束分开处理：先从左到右保证右边评分高时糖更多，再从右到左保证左边评分高时糖更多。

### C++ 详细注释代码

```cpp
#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    int candy(vector<int>& ratings) {
        // 每个孩子至少 1 颗糖。
        vector<int> candies(ratings.size(), 1);

        // 从左到右：只处理“右边孩子评分更高”的约束。
        for (int i = 1; i < ratings.size(); ++i) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        // 从右到左：只处理“左边孩子评分更高”的约束。
        for (int i = ratings.size() - 2; i >= 0; --i) {
            if (ratings[i] > ratings[i + 1]) {
                // 不能直接覆盖，因为左到右时可能已经给了更多糖。
                candies[i] = max(candies[i], candies[i + 1] + 1);
            }
        }

        // 最少糖果总数就是 candies 数组求和。
        return accumulate(candies.begin(), candies.end(), 0);
    }
};
```

### 易错点

- 第二遍要取 `max`，不能覆盖第一遍结果。
- 两个方向约束分开处理更清晰。

## 860 柠檬水找零

### 题目链接

- 代码随想录：[860. 柠檬水找零](https://programmercarl.com/0860.柠檬水找零.html)
- 力扣页面：[860. Lemonade Change](https://leetcode.cn/problems/lemonade-change/)

### 题目描述

柠檬水每杯 5 美元，顾客依次用 5、10、20 美元付款，判断能否正确找零。

### 示例

```text
输入：bills = [5,5,5,10,20]
输出：true
```

### 贪心选择

收到 20 元时，优先用 `10 + 5` 找零，因为 10 元只能用于 20 找零，5 元更万能。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool lemonadeChange(vector<int>& bills) {
        int five = 0; // 手里 5 美元钞票数量。
        int ten = 0;  // 手里 10 美元钞票数量。

        for (int bill : bills) {
            if (bill == 5) {
                // 5 元刚好付款，不需要找零。
                ++five;
            } else if (bill == 10) {
                // 收 10 元要找 5 元。
                if (five == 0) return false;
                --five;
                ++ten;
            } else {
                // 收 20 元要找 15 元，优先用 10+5。
                if (ten > 0 && five > 0) {
                    --ten;
                    --five;
                } else if (five >= 3) {
                    // 没有 10 元时，只能用三张 5 元。
                    five -= 3;
                } else {
                    return false;
                }
            }
        }

        return true;
    }
};
```

### 易错点

- 20 元找零优先消耗 10 元。
- 10 元找零必须消耗一张 5 元。

## 406 根据身高重建队列

### 题目链接

- 代码随想录：[406. 根据身高重建队列](https://programmercarl.com/0406.根据身高重建队列.html)
- 代码随想录：[根据身高重建队列 vector 原理讲解](https://programmercarl.com/根据身高重建队列（vector原理讲解）.html)
- 力扣页面：[406. Queue Reconstruction by Height](https://leetcode.cn/problems/queue-reconstruction-by-height/)

### 题目描述

每个人表示为 `[h, k]`，`h` 是身高，`k` 是前面身高大于等于 `h` 的人数。重建队列。

### 示例

```text
输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

### 贪心选择

先按身高从高到低排，身高相同按 `k` 从小到大排。高个子先放好后，矮个子插入不会影响高个子的 `k`。

> [!note]
> 网页里的 vector 原理讲解强调 `vector::insert` 的代价：插入到中间会移动后面的元素，单次最坏 `O(n)`，所以整体复杂度是 `O(n^2)`。这题为了让思路清晰通常仍用 `vector`，面试时可以说明如果频繁中间插入，链表插入本身便宜，但定位第 `k` 个位置仍要遍历。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        // 先放高个子：矮个子插入不会影响高个子的 k 值。
        sort(people.begin(), people.end(), [](const vector<int>& a, const vector<int>& b) {
            // 身高相同，则 k 小的站前面。
            if (a[0] == b[0]) return a[1] < b[1];
            // 身高高的优先处理。
            return a[0] > b[0];
        });

        vector<vector<int>> result;
        for (const auto& person : people) {
            // 对当前 person 来说，前面已经放入的都比它高或等高，
            // 所以插入到下标 k 的位置正好满足前面有 k 个高个子。
            result.insert(result.begin() + person[1], person);
        }

        return result;
    }
};
```

### 易错点

- 先处理身高，再处理 `k`。
- 插入位置就是 `k`。

## 452 用最少数量的箭引爆气球

### 题目链接

- 代码随想录：[452. 用最少数量的箭引爆气球](https://programmercarl.com/0452.用最少数量的箭引爆气球.html)
- 力扣页面：[452. Minimum Number of Arrows to Burst Balloons](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/)

### 题目描述

每个气球是一个区间，一支箭可以引爆所有被射中区间。求引爆全部气球的最少箭数。

### 示例

```text
输入：points = [[10,16],[2,8],[1,6],[7,12]]
输出：2
```

### 贪心选择

按左边界排序，维护当前重叠区间的最小右边界。遇到不重叠区间时，需要新增一支箭。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        // 没有气球就不需要箭。
        if (points.empty()) return 0;

        // 按左边界排序，方便从左到右合并重叠区间。
        sort(points.begin(), points.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[0] < b[0];
        });

        int result = 1; // 至少有一个气球时，至少需要一支箭。
        for (int i = 1; i < points.size(); ++i) {
            // 当前气球左边界大于上一段重叠区间右边界，说明无法被同一支箭射中。
            if (points[i][0] > points[i - 1][1]) {
                ++result;
            } else {
                // 有重叠时，更新当前重叠区间的最小右边界。
                // 箭必须射在这个交集范围内。
                points[i][1] = min(points[i][1], points[i - 1][1]);
            }
        }

        return result;
    }
};
```

### 易错点

- 边界相等算重叠。
- 重叠时要收缩右边界。

## 435 无重叠区间

### 题目链接

- 代码随想录：[435. 无重叠区间](https://programmercarl.com/0435.无重叠区间.html)
- 力扣页面：[435. Non-overlapping Intervals](https://leetcode.cn/problems/non-overlapping-intervals/)

### 题目描述

给定区间数组，移除最少数量的区间，使剩余区间互不重叠。

### 示例

```text
输入：intervals = [[1,2],[2,3],[3,4],[1,3]]
输出：1
```

### 贪心选择

按右边界从小到大排序，优先保留结束早的区间，给后面留下更多空间。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        // 没有区间，不需要移除。
        if (intervals.empty()) return 0;

        // 按右边界升序，优先保留结束早的区间。
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1];
        });

        int count = 1;              // 当前最多能保留的不重叠区间数。
        int end = intervals[0][1];  // 已保留区间中的最后一个右边界。

        for (int i = 1; i < intervals.size(); ++i) {
            // 当前区间左边界 >= 上一个保留区间右边界，说明不重叠。
            if (intervals[i][0] >= end) {
                ++count;
                end = intervals[i][1];
            }
        }

        // 最少移除数量 = 总区间数 - 最多能保留的不重叠区间数。
        return intervals.size() - count;
    }
};
```

### 易错点

- `[1,2]` 和 `[2,3]` 不重叠。
- 可以转成“最多保留多少个不重叠区间”。

## 763 划分字母区间

### 题目链接

- 代码随想录：[763. 划分字母区间](https://programmercarl.com/0763.划分字母区间.html)
- 力扣页面：[763. Partition Labels](https://leetcode.cn/problems/partition-labels/)

### 题目描述

把字符串划分为尽可能多的片段，使每个字母最多出现在一个片段中，返回每个片段长度。

### 示例

```text
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
```

### 贪心选择

先记录每个字符最后出现位置。遍历时维护当前片段最远边界，走到边界就切一段。

### C++ 详细注释代码

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    vector<int> partitionLabels(string s) {
        // last[c] 记录字符 c 最后一次出现的位置。
        int last[26] = {0};
        for (int i = 0; i < s.size(); ++i) {
            last[s[i] - 'a'] = i;
        }

        vector<int> result;
        int start = 0; // 当前片段起点。
        int end = 0;   // 当前片段必须覆盖到的最远位置。

        for (int i = 0; i < s.size(); ++i) {
            // 当前字符最后出现位置可能扩展当前片段右边界。
            end = max(end, last[s[i] - 'a']);

            // 走到 end，说明当前片段里的所有字符都不会出现在后面。
            if (i == end) {
                result.push_back(end - start + 1);
                start = i + 1;
            }
        }

        return result;
    }
};
```

### 易错点

- 当前片段中所有字符的最后出现位置都要落在片段内。
- 到达最远边界才可以切。

## 56 合并区间

### 题目链接

- 代码随想录：[56. 合并区间](https://programmercarl.com/0056.合并区间.html)
- 力扣页面：[56. Merge Intervals](https://leetcode.cn/problems/merge-intervals/)

### 题目描述

给定若干区间，合并所有重叠区间。

### 示例

```text
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
```

### 贪心选择

按左边界排序。若当前区间和结果最后一个区间重叠，就更新右边界；否则新开一个区间。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        // 空输入直接返回空结果。
        if (intervals.empty()) return {};

        // 默认按第一维升序排序，也就是按左边界排序。
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> result;

        // 先放入第一个区间，后续都和 result.back() 比较。
        result.push_back(intervals[0]);

        for (int i = 1; i < intervals.size(); ++i) {
            // 当前区间左边界 <= 结果中最后区间的右边界，说明有重叠。
            if (intervals[i][0] <= result.back()[1]) {
                // 合并区间时，只需要扩展右边界。
                result.back()[1] = max(result.back()[1], intervals[i][1]);
            } else {
                // 没有重叠，当前区间单独成为新区间。
                result.push_back(intervals[i]);
            }
        }

        return result;
    }
};
```

### 易错点

- 合并区间通常按左边界排序。
- 重叠判断是 `currentLeft <= lastRight`。

## 738 单调递增的数字

### 题目链接

- 代码随想录：[738. 单调递增的数字](https://programmercarl.com/0738.单调递增的数字.html)
- 力扣页面：[738. Monotone Increasing Digits](https://leetcode.cn/problems/monotone-increasing-digits/)

### 题目描述

给定非负整数 `n`，返回小于等于 `n` 的最大单调递增数字。

### 示例

```text
输入：n = 332
输出：299
```

### 贪心选择

从后往前找下降位置，让前一位减一，并把后面所有位变成 9。

### C++ 详细注释代码

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int monotoneIncreasingDigits(int n) {
        // 转成字符串，方便逐位修改。
        string s = to_string(n);
        int flag = s.size(); // flag 记录从哪一位开始要改成 9。

        // 从后往前找逆序位置，例如 332 中第二个 3 > 2。
        for (int i = s.size() - 1; i > 0; --i) {
            if (s[i - 1] > s[i]) {
                // 前一位减 1 后，后面都改成 9 才能尽量大。
                --s[i - 1];
                flag = i;
            }
        }

        // flag 之后全部填 9，让数字在不超过 n 的前提下尽可能大。
        for (int i = flag; i < s.size(); ++i) {
            s[i] = '9';
        }

        return stoi(s);
    }
};
```

### 易错点

- 必须从后往前处理，因为前一位减一后可能继续破坏更前面的单调性。
- `flag` 记录从哪里开始填 9。

## 968 监控二叉树

### 题目链接

- 代码随想录：[968. 监控二叉树](https://programmercarl.com/0968.监控二叉树.html)
- 力扣页面：[968. Binary Tree Cameras](https://leetcode.cn/problems/binary-tree-cameras/)

### 题目描述

在二叉树节点上放摄像头，每个摄像头可以监控父节点、自己和直接孩子。求覆盖整棵树所需的最少摄像头数量。

### 示例

```text
输入：root = [0,0,null,0,0]
输出：1
```

### 贪心选择

摄像头尽量放在叶子节点的父节点上。后序遍历从下往上判断节点状态：无覆盖、有摄像头、有覆盖。

### C++ 详细注释代码

```cpp
class Solution {
private:
    int result = 0;

    // 0：无覆盖，1：有摄像头，2：有覆盖
    int traversal(TreeNode* cur) {
        // 空节点视为有覆盖，这样不会在叶子节点的空孩子上放摄像头。
        if (cur == nullptr) return 2;

        // 后序遍历：先看左右孩子状态，再决定当前节点状态。
        int left = traversal(cur->left);
        int right = traversal(cur->right);

        // 只要有一个孩子无覆盖，当前节点必须放摄像头。
        if (left == 0 || right == 0) {
            ++result;
            return 1;
        }

        // 只要有一个孩子有摄像头，当前节点就已经被覆盖。
        if (left == 1 || right == 1) {
            return 2;
        }

        // 左右孩子都被覆盖但都没有摄像头，则当前节点无覆盖，交给父节点处理。
        return 0;
    }

public:
    int minCameraCover(TreeNode* root) {
        // 如果根节点最后仍无覆盖，需要在根节点补一个摄像头。
        if (traversal(root) == 0) ++result;
        return result;
    }
};
```

### 易错点

- 空节点视为有覆盖，避免在叶子节点上放摄像头。
- 根节点最后如果无覆盖，需要补一个摄像头。

## 周总结精华

### 复盘重点

| 复盘点 | 记忆方式 |
|---|---|
| 贪心证明 | 先说局部最优，再说明局部最优能推出全局最优 |
| 分发类 | 小资源优先满足小胃口，避免大资源被浪费 |
| 摆动序列 | 只关心坡度符号变化，平坡要跳过 |
| 股票 II | 多次交易等价于收集所有正利润 |
| 跳跃游戏 | 维护当前能覆盖的最远位置 |
| 区间问题 | 先排序，再维护右边界或重叠区间 |
| 双向约束 | 分发糖果左右各扫一遍，分别满足左右规则 |
| 树形贪心 | 监控二叉树从叶子往上看，后序决定父节点状态 |

### 最容易混的点

- 贪心不是“看起来选最大的/最小的”，必须有维护变量和交换理由。
- 区间题排序规则很关键：按左边界排和按右边界排对应的维护变量不同。
- 根据身高重建队列先处理高个子，因为矮个子插入不会影响高个子的 `k`。
