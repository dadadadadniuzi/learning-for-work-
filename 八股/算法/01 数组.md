## 数组理论基础

### 题目链接

- 代码随想录：[数组理论基础](https://programmercarl.com/数组理论基础.html)
- 力扣页面：无。这一节是数组基础概念，不是单独力扣题。

### 简要回答

数组是存放在连续内存空间上的相同类型数据集合，可以通过下标 `O(1)` 访问元素，但插入、删除通常需要移动元素。很多数组题里的“删除”并不是真的释放空间，而是把有效元素覆盖到前面。

### 核心点

| 考点 | 说明 |
|---|---|
| 连续内存 | 数组元素在内存中连续存放 |
| 下标访问 | 可以通过 `base + index * sizeof(T)` 快速定位 |
| 删除元素 | 通常是覆盖，不是真的改变底层数组长度 |
| 插入元素 | 需要移动插入位置后面的元素 |
| C++ 二维数组 | 静态二维数组通常在地址上连续 |
| `vector` | 底层是动态数组，扩容时可能搬迁元素 |

### 地址示例

```cpp
#include <iostream>
using namespace std;

void test_arr() {
    // 静态二维数组在内存里按行连续存储。
    int array[2][3] = {
        {0, 1, 2},
        {3, 4, 5}
    };

    // 打印第一行三个元素的地址。
    cout << &array[0][0] << " "
         << &array[0][1] << " "
         << &array[0][2] << endl;

    // 打印第二行三个元素的地址。
    cout << &array[1][0] << " "
         << &array[1][1] << " "
         << &array[1][2] << endl;
}

int main() {
    // 调用示例函数，观察二维数组元素地址是否连续。
    test_arr();
    return 0;
}
```

可能输出：

```text
0x7ffee4065820 0x7ffee4065824 0x7ffee4065828
0x7ffee406582c 0x7ffee4065830 0x7ffee4065834
```

`int` 通常占 4 字节，所以相邻元素地址差 4，说明二维数组在内存里也是按行连续存放的。

### 面试表达

数组的优势是支持 `O(1)` 下标访问，因为内存连续；缺点是插入和删除成本高，因为要移动后续元素。很多数组题本质不是删除元素，而是用覆盖的方式维护有效区间。

## 704 二分查找

### 题目链接

- 代码随想录：[704. 二分查找](https://programmercarl.com/0704.二分查找.html)
- 力扣页面：[704. Binary Search](https://leetcode.cn/problems/binary-search/)

### 题目描述

给定一个升序数组 `nums` 和目标值 `target`，如果目标值存在，返回它的下标；如果不存在，返回 `-1`。

### 示例

```text
输入：nums = [-1,0,3,5,9,12], target = 9
输出：4
解释：9 出现在 nums[4]。
```

```text
输入：nums = [-1,0,3,5,9,12], target = 2
输出：-1
解释：2 不存在于数组中。
```

### 思路

二分查找适用于有序数组。最关键的是先确定搜索区间。这里使用左闭右闭区间 `[left, right]`，所以当 `left == right` 时区间仍然有效，循环条件写 `left <= right`。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int search(vector<int>& nums, int target) {
        // left 和 right 表示当前仍然可能包含 target 的搜索区间。
        // 本写法使用左闭右闭区间 [left, right]。
        int left = 0;
        int right = nums.size() - 1;

        // 因为区间是 [left, right]，所以 left == right 时仍然要检查。
        while (left <= right) {
            // 不直接写 (left + right) / 2，是为了避免 left + right 整数溢出。
            int middle = left + (right - left) / 2;

            if (nums[middle] > target) {
                // middle 位置已经比 target 大，middle 及其右侧都不可能是答案。
                // 新区间变成 [left, middle - 1]。
                right = middle - 1;
            } else if (nums[middle] < target) {
                // middle 位置比 target 小，middle 及其左侧都不可能是答案。
                // 新区间变成 [middle + 1, right]。
                left = middle + 1;
            } else {
                // 找到目标值，直接返回下标。
                return middle;
            }
        }

        // 循环结束说明搜索区间已经为空，target 不存在。
        return -1;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(log n)` |
| 空间 | `O(1)` |

### 易错点

- 左闭右闭区间用 `while (left <= right)`。
- 如果写左闭右开区间 `[left, right)`，循环和边界更新都要换。
- `middle` 建议写成 `left + (right - left) / 2`。

### 面试表达

二分查找最重要的是循环不变量。我会先定义搜索区间，如果是左闭右闭，就用 `left <= right`；如果是左闭右开，就用 `left < right`，边界更新也必须和区间定义一致。

## 27 移除元素

### 题目链接

- 代码随想录：[27. 移除元素](https://programmercarl.com/0027.移除元素.html)
- 力扣页面：[27. Remove Element](https://leetcode.cn/problems/remove-element/)

### 题目描述

给定一个数组 `nums` 和一个值 `val`，原地移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。元素顺序可以改变也可以不改变，超过新长度后的元素不需要关心。

### 示例

```text
输入：nums = [3,2,2,3], val = 3
输出：2
解释：函数返回 2，nums 的前两个元素应为 [2,2]。
```

```text
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5
解释：函数返回 5，nums 的前五个元素可为 [0,1,3,0,4]。
```

### 思路

数组不能真正删除某个元素，只能把不需要删除的元素覆盖到前面。快指针遍历旧数组，慢指针维护新数组的写入位置。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        // slowIndex 表示新数组下一个应该写入的位置。
        // 换句话说，[0, slowIndex) 是已经处理好的有效区间。
        int slowIndex = 0;

        // fastIndex 用来遍历原数组，逐个检查元素是否需要保留。
        for (int fastIndex = 0; fastIndex < nums.size(); ++fastIndex) {
            // 如果当前元素不等于 val，说明它应该保留。
            if (nums[fastIndex] != val) {
                // 把要保留的元素覆盖到 slowIndex 位置。
                nums[slowIndex] = nums[fastIndex];

                // slowIndex 后移，准备写入下一个有效元素。
                ++slowIndex;
            }
        }

        // slowIndex 正好等于有效元素个数，也就是新数组长度。
        return slowIndex;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 返回的是新长度，不是删除了几个元素。
- 新长度之后的内容不用管。
- 本题的“删除”本质是覆盖，不是调用容器删除接口。

### 面试表达

快指针负责扫描旧数组，慢指针负责维护新数组有效区间。遇到不等于 `val` 的元素，就写入慢指针位置，最后慢指针的值就是新长度。

## 977 有序数组的平方

### 题目链接

- 代码随想录：[977. 有序数组的平方](https://programmercarl.com/0977.有序数组的平方.html)
- 力扣页面：[977. Squares of a Sorted Array](https://leetcode.cn/problems/squares-of-a-sorted-array/)

### 题目描述

给定一个非递减排序的整数数组 `nums`，返回每个数字的平方组成的新数组，要求新数组也按非递减顺序排序。

### 示例

```text
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
```

```text
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

### 思路

原数组有序，但平方后最大值可能来自最左侧负数，也可能来自最右侧正数。所以使用左右双指针比较两端平方值，每次把较大的平方值放到结果数组末尾。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n, 0);

        // left 指向数组最左端，right 指向数组最右端。
        int left = 0;
        int right = n - 1;

        // write 指向 result 当前要写入的位置。
        // 因为每次选出的是最大平方值，所以从后往前写。
        int write = n - 1;

        while (left <= right) {
            int leftSquare = nums[left] * nums[left];
            int rightSquare = nums[right] * nums[right];

            if (leftSquare > rightSquare) {
                // 左端平方更大，把它放到当前最后位置。
                result[write] = leftSquare;
                ++left;
            } else {
                // 右端平方更大或相等，把它放到当前最后位置。
                result[write] = rightSquare;
                --right;
            }

            // 写完一个最大值后，写入位置向前移动。
            --write;
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 循环条件要用 `left <= right`，否则最后一个元素会漏处理。
- 结果数组要从后往前填，因为每次选的是当前最大平方值。
- 不要被“原数组有序”迷惑，平方后的最小值可能在中间。

### 面试表达

有序数组平方后，最大值一定来自两端之一。我用左右指针比较两端平方值，把更大的放到结果数组末尾，这样一次遍历就能得到有序结果。

## 209 长度最小的子数组

### 题目链接

- 代码随想录：[209. 长度最小的子数组](https://programmercarl.com/0209.长度最小的子数组.html)
- 力扣页面：[209. Minimum Size Subarray Sum](https://leetcode.cn/problems/minimum-size-subarray-sum/)

### 题目描述

给定一个正整数数组 `nums` 和目标值 `target`，找出和大于等于 `target` 的长度最小的连续子数组，返回其长度。如果不存在符合条件的子数组，返回 `0`。

### 示例

```text
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 的和为 7，长度最短。
```

```text
输入：target = 4, nums = [1,4,4]
输出：1
解释：子数组 [4] 已经满足条件。
```

### 思路

因为数组元素都是正数，窗口右边界向右移动时窗口和会增加，左边界向右移动时窗口和会减少。所以可以使用滑动窗口：右指针扩张窗口，满足条件后左指针尽量收缩窗口。

### C++ 详细注释代码

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        // result 记录目前找到的最短长度。
        int result = INT_MAX;

        // sum 记录当前窗口内元素之和。
        int sum = 0;

        // left 是窗口左边界。
        int left = 0;

        // right 是窗口右边界，每轮把 nums[right] 加入窗口。
        for (int right = 0; right < nums.size(); ++right) {
            sum += nums[right];

            // 只要当前窗口已经满足 sum >= target，
            // 就不断尝试收缩左边界，看看能不能得到更短长度。
            while (sum >= target) {
                int currentLength = right - left + 1;
                result = min(result, currentLength);

                // 移除窗口最左侧元素，然后 left 右移。
                sum -= nums[left];
                ++left;
            }
        }

        // 如果 result 没被更新，说明不存在满足条件的子数组。
        return result == INT_MAX ? 0 : result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 本题能用滑动窗口，是因为 `nums` 全是正整数。
- `while (sum >= target)` 不能写成 `if`，因为要尽量缩短窗口。
- 窗口长度是 `right - left + 1`。

### 面试表达

我把右指针作为窗口终点不断扩张，当窗口和达到目标值后，就移动左指针收缩窗口，并在每次满足条件时更新最短长度。

## 59 螺旋矩阵 II

### 题目链接

- 代码随想录：[59. 螺旋矩阵 II](https://programmercarl.com/0059.螺旋矩阵II.html)
- 力扣页面：[59. Spiral Matrix II](https://leetcode.cn/problems/spiral-matrix-ii/)

### 题目描述

给定正整数 `n`，生成一个 `n x n` 的矩阵，矩阵元素从 `1` 到 `n^2`，按顺时针螺旋顺序填充。

### 示例

```text
输入：n = 3
输出：
[
  [1,2,3],
  [8,9,4],
  [7,6,5]
]
```

```text
输入：n = 1
输出：[[1]]
```

### 思路

这是一道模拟题。难点不在算法，而在边界控制。每一圈分成上、右、下、左四条边来填，统一采用左闭右开的规则，避免角落重复填。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        // 创建 n x n 矩阵，初始值都为 0。
        vector<vector<int>> result(n, vector<int>(n, 0));

        // startX 和 startY 表示当前这一圈左上角的起点。
        int startX = 0;
        int startY = 0;

        // n / 2 表示需要完整转几圈。
        // 例如 n = 3，只完整转 1 圈，中间点单独处理。
        int loop = n / 2;

        // n 为奇数时，mid 是中心点下标。
        int mid = n / 2;

        // count 是当前要填入的数字。
        int count = 1;

        // offset 控制每一圈的边界收缩。
        int offset = 1;

        while (loop--) {
            int i = startX;
            int j = startY;

            // 1. 填上边：从左到右。
            // 固定行 i，列 j 从 startY 到 n - offset - 1。
            for (; j < n - offset; ++j) {
                result[i][j] = count++;
            }

            // 2. 填右边：从上到下。
            // 固定列 j，行 i 从 startX 到 n - offset - 1。
            for (; i < n - offset; ++i) {
                result[i][j] = count++;
            }

            // 3. 填下边：从右到左。
            for (; j > startY; --j) {
                result[i][j] = count++;
            }

            // 4. 填左边：从下到上。
            for (; i > startX; --i) {
                result[i][j] = count++;
            }

            // 进入内一圈，起点向右下移动。
            ++startX;
            ++startY;

            // 边界继续向内收缩。
            ++offset;
        }

        // 如果 n 是奇数，最中心的位置还没有填。
        if (n % 2 == 1) {
            result[mid][mid] = count;
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n^2)` |
| 空间 | `O(1)`，不算返回矩阵 |

### 易错点

- 四条边要坚持同一种开闭区间规则。
- 奇数阶矩阵中心要单独填。
- 每转完一圈，起点和边界都要更新。

### 面试表达

这题主要考边界控制。我会按圈填充，每条边统一使用左闭右开原则，避免拐角重复填或漏填。

## 58 区间和

### 题目链接

- 代码随想录：[58. 区间和](https://programmercarl.com/kamacoder/0058.区间和.html)
- 卡码网页面：[58. 区间和](https://kamacoder.com/problempage.php?pid=1070)
- 力扣页面：无。这是卡码网 ACM 模式题，不是力扣题。

### 题目描述

给定一个整数数组，再给出多组查询区间 `[a, b]`，要求输出每个区间内元素之和。

### 示例

```text
输入：
5
1 2 3 4 5
0 1
1 3

输出：
3
9
```

解释：

- `[0,1]` 的和是 `1 + 2 = 3`。
- `[1,3]` 的和是 `2 + 3 + 4 = 9`。

### 思路

多次查询区间和时，如果每次都重新累加，会重复计算。前缀和 `prefix[i]` 表示区间 `[0, i]` 的元素和，查询 `[a, b]` 时：

- 如果 `a == 0`，答案是 `prefix[b]`。
- 否则答案是 `prefix[b] - prefix[a - 1]`。

### C++ 详细注释代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> nums(n);
    vector<int> prefix(n);

    int sum = 0;
    for (int i = 0; i < n; ++i) {
        cin >> nums[i];

        // sum 保存从 nums[0] 到 nums[i] 的累加和。
        sum += nums[i];

        // prefix[i] 表示区间 [0, i] 的和。
        prefix[i] = sum;
    }

    int a, b;

    // ACM 模式下，查询组数可能没有单独给出。
    // while (cin >> a >> b) 表示一直读到输入结束。
    while (cin >> a >> b) {
        int answer = 0;

        if (a == 0) {
            // 查询区间从 0 开始，不需要减前面的前缀。
            answer = prefix[b];
        } else {
            // [a, b] 的和 = [0, b] 的和 - [0, a - 1] 的和。
            answer = prefix[b] - prefix[a - 1];
        }

        cout << answer << endl;
    }

    return 0;
}
```

### 复杂度

| 阶段 | 复杂度 |
|---|---|
| 预处理 | `O(n)` |
| 单次查询 | `O(1)` |
| 空间 | `O(n)` |

### 易错点

- 查询 `[a, b]` 是闭区间。
- `a == 0` 时不能访问 `prefix[-1]`。
- ACM 模式要注意 `while (cin >> a >> b)` 这种读到 EOF 的写法。

### 面试表达

前缀和适合多次区间求和。它把重复累加提前预处理掉，后续每个区间查询只需要两个前缀和相减。

### 题目描述

给定一个 `n x m` 的矩阵，每个格子表示土地价值。现在只能横向或纵向切一刀，把土地分成两块，要求两块土地价值总和差值尽可能小，输出最小差值。

### 示例

```text
输入：
3 3
1 2 3
2 1 3
1 2 3

输出：
0
```

解释：可以找到一种切法，使两边价值和相等，差值为 `0`。

### 思路

先求整个矩阵总和 `total`。如果某一边的价值是 `part`，另一边就是 `total - part`，两边差值为：

```text
abs((total - part) - part) = abs(total - 2 * part)
```

所以只要枚举每一条横向切线和纵向切线，维护其中一边的累加和，就能更新最小差值。

### C++ 详细注释代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
#include <cstdlib>
using namespace std;

int main() {
    int n, m;
    // n 行 m 列。
    cin >> n >> m;

    vector<vector<int>> grid(n, vector<int>(m, 0));

    // total 表示所有土地价值总和。
    int total = 0;

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            // 读入每块土地价值，并累加总价值。
            cin >> grid[i][j];
            total += grid[i][j];
        }
    }

    // rowSum[i] 表示第 i 行的价值总和。
    vector<int> rowSum(n, 0);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            rowSum[i] += grid[i][j];
        }
    }

    // colSum[j] 表示第 j 列的价值总和。
    vector<int> colSum(m, 0);
    for (int j = 0; j < m; ++j) {
        for (int i = 0; i < n; ++i) {
            colSum[j] += grid[i][j];
        }
    }

    int result = INT_MAX;

    // 枚举横向切分。
    // part 表示切线以上区域的价值和。
    int part = 0;
    for (int i = 0; i < n; ++i) {
        part += rowSum[i];

        // 一边是 part，另一边是 total - part。
        // abs(total - 2 * part) 就是两边差值。
        result = min(result, abs(total - 2 * part));
    }

    // 枚举纵向切分。
    // part 表示切线左侧区域的价值和。
    part = 0;
    for (int j = 0; j < m; ++j) {
        part += colSum[j];
        result = min(result, abs(total - 2 * part));
    }

    cout << result << endl;
    return 0;
}
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n * m)` |
| 空间 | `O(n * m + n + m)` |

### 易错点

- 横切和竖切都要枚举。
- 差值公式可以写成 `abs(total - 2 * part)`。
- 如果题目规定必须分成非空两块，枚举切线时要注意不要把整块都放到一边。代码随想录原题按其输入约定整理，实际考试要看题面限制。

### 面试表达

这题本质是二维区域切分。先求总和，然后枚举每条横向或纵向切分线，只要知道一边的和 `part`，另一边就是 `total - part`，差值就是 `abs(total - 2 * part)`。
