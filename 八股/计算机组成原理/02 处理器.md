## CPU 和 GPU 有什么区别

### 简要回答

CPU 核心少但单核能力强，适合复杂控制和通用计算；GPU 核心多但单核较简单，适合大规模并行计算。

### 对比表

| 对比点 | CPU | GPU |
|---|---|---|
| 核心数量 | 少 | 多 |
| 单核能力 | 强 | 相对弱 |
| 适合任务 | 复杂逻辑、控制流、通用任务 | 图形渲染、矩阵计算、并行任务 |
| 并行能力 | 较弱 | 很强 |
| 设计目标 | 低延迟、强控制 | 高吞吐、大规模并行 |
| 典型瓶颈 | 并行规模有限 | 复杂分支效率较低 |

### 面试表达

> CPU 像少数几个能力很强的通用工人，GPU 像大量适合做重复工作的工人。所以 CPU 适合复杂分支和调度，GPU 适合大量相似计算。

## CPU 主要由哪些部分组成

### 简要回答

CPU 主要由运算器和控制器组成，也可以从硬件实现角度分成数据通路和控制部件。

### 详细回答

CPU 的主要功能：

1. 指令控制：保证指令按程序规定顺序执行，完成取指、分析、执行。
2. 操作控制：产生执行一条指令所需的操作信号。
3. 时序控制：控制操作信号产生的时间和持续时间。
4. 中断控制：响应内部异常和外部中断，如缺页异常、键盘中断。
5. 数据加工：进行算术运算、逻辑运算和数据传送。

### 面试表达

> 控制器负责“指挥”，运算器负责“计算”。CPU 不只是算数，还要控制指令执行顺序、产生控制信号、响应中断。

## GPU 主要由哪些部分组成

### 简要回答

GPU 主要由大量流处理器和显存等部分组成，核心优势是高并行吞吐。

### 详细回答

GPU 的主要能力：

- 并行计算：大量小核心同时处理相似任务。
- 图形渲染：处理 3D 图形、纹理、光照、阴影等。
- 通用计算：现代 GPU 可用于 GPGPU，例如深度学习、科学模拟、密码学。
- 大量数据处理：适合高吞吐场景，不擅长复杂分支和强顺序逻辑。

## 为什么 GPU 适合并行计算

### 简要回答

因为 GPU 有大量计算核心，适合把同一种计算分发到大量数据上同时执行。

### 典型场景

- 图像渲染
- 矩阵运算
- 深度学习
- 科学计算

### 举例

图像处理中，每个像素的计算通常相对独立，GPU 可以让大量核心同时处理不同像素，因此吞吐量很高。

## CPU 更适合什么场景

### 简要回答

CPU 更适合控制逻辑复杂、分支多、任务类型变化大的通用计算场景。

### 面试表达

> 如果任务需要复杂判断、频繁系统调用、强顺序依赖，一般更适合 CPU；如果任务是大量数据做相同计算，就更适合 GPU。

## CPU 和 GPU 如何协作

### 简要回答

CPU 通常负责复杂逻辑、任务调度和控制流程，GPU 负责大规模并行计算。

### 详细回答

典型流程是：CPU 准备数据和任务，把适合并行的计算交给 GPU；GPU 批量计算完成后，把结果返回给 CPU 继续处理后续逻辑。

### 面试表达

> CPU 和 GPU 不是互相替代，而是分工协作。CPU 管控制和调度，GPU 做高吞吐并行计算。
