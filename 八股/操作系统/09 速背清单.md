# 操作系统速背清单

返回：[[操作系统导航]]

## 基础概念

- [[01 基础概念#什么是操作系统|操作系统]]：硬件和应用之间的系统软件，向下管资源，向上给系统调用。
- [[01 基础概念#操作系统有哪些特征|四大特征]]：并发、共享、虚拟、异步；并发是同一时间段，并行是同一时刻。
- [[01 基础概念#操作系统有哪些功能|操作系统功能]]：CPU 调度、内存管理、文件管理、I/O 管理、安全保护。
- [[操作系统基础#操作系统的角色|操作系统角色]]：资源管理者 + 抽象魔术师，让进程感觉自己独占 CPU 和内存。
- [[操作系统基础#用户程序与操作系统的关系|用户程序和 OS]]：用户程序运行在 OS 之上，通过系统调用使用内核服务。
- [[01 基础概念#用户态和内核态是什么|用户态和内核态]]：用户态权限低，内核态权限高；系统调用、中断、异常会切到内核态。
- [[01 基础概念#系统调用是什么|系统调用]]：用户程序请求内核服务的入口，如 `open/read/write/fork/socket`。

## 进程与线程

- [[02 进程与线程#进程和线程有什么区别|进程和线程]]：进程是资源分配基本单位，线程是 CPU 调度基本单位。
- [[02 进程与线程#PCB 和 TCB 是什么|PCB / TCB]]：PCB 是进程档案，TCB 是线程档案，保存状态、寄存器、调度等上下文。
- [[02 进程与线程#进程有哪些状态|进程状态]]：创建、就绪、运行、阻塞、终止；就绪等 CPU，阻塞等事件。
- [[02 进程与线程#线程共享哪些资源，独享哪些资源|线程共享与独享]]：线程共享进程地址空间、堆、全局变量、fd；独享栈、寄存器、程序计数器。
- [[02 进程与线程#进程切换和线程切换有什么区别|切换开销]]：进程切换通常更重，涉及地址空间；线程切换更轻但也有上下文成本。
- [[02 进程与线程#进程间通信有哪些方式|IPC]]：管道、命名管道、消息队列、共享内存、信号量、信号、Socket；共享内存最快但要同步。
- [[02 进程与线程#进程调度算法有哪些|进程调度算法]]：FCFS、SJF、高响应比、时间片轮转、优先级、多级反馈队列。
- [[02 进程与线程#作业调度、内存调度、进程调度有什么区别|三种调度]]：作业调度管“进不进系统”，内存调度管“在不在内存”，进程调度管“谁用 CPU”。
- [[02 进程与线程#处理机有哪些状态|处理机状态]]：用户态和内核态；特权指令只能在内核态执行。

## 中断与异常

- [[03 中断与异常#中断和异常有什么区别|中断和异常]]：中断多来自外部设备，异步；异常来自当前指令执行，同步。
- [[03 中断与异常#系统调用、中断、异常有什么关系|三者关系]]：系统调用是主动进内核，中断是外部触发，异常是执行时触发。
- [[03 中断与异常#时钟中断是什么|时钟中断]]：周期性打断当前进程，让内核有机会做抢占式调度。
- [[03 中断与异常#缺页异常是什么|缺页异常]]：访问页不在物理内存时触发；合法则调页，不合法可能段错误。
- [[03 中断与异常#上下文切换是什么|上下文切换]]：保存当前现场、恢复另一个现场；有 CPU、缓存、TLB 成本。
- [[03 中断与异常#中断处理流程是什么|中断流程]]：中断请求 -> 保存现场 -> 查中断向量 -> 执行服务程序 -> 恢复现场。

## 同步与互斥

- [[04 同步与互斥#临界区是什么|临界区]]：访问共享资源的代码区域，需要互斥保护。
- [[04 同步与互斥#同步和互斥有什么区别|同步和互斥]]：互斥管“不能同时进”，同步管“必须按顺序”。
- [[04 同步与互斥#线程同步方式有哪些|线程同步方式]]：互斥锁、读写锁、自旋锁、条件变量、信号量、原子操作。
- [[04 同步与互斥#互斥锁和自旋锁有什么区别|互斥锁和自旋锁]]：互斥锁抢不到会睡，自旋锁抢不到会忙等；短临界区偏自旋。
- [[04 同步与互斥#信号量和条件变量有什么区别|信号量和条件变量]]：信号量带计数，条件变量等条件，且通常配合互斥锁。
- [[04 同步与互斥#生产者消费者问题怎么理解|生产者消费者]]：缓冲区互斥访问；空了消费者等，满了生产者等。
- [[04 同步与互斥#读写问题怎么理解|读写问题]]：读读不互斥，读写和写写互斥；读多写少用读写锁。

## 死锁

- [[05 死锁#什么是死锁|死锁]]：多个线程/进程互相等待对方资源，谁都无法继续。
- [[05 死锁#死锁产生的四个必要条件|四个必要条件]]：互斥、请求并保持、不可剥夺、循环等待。
- [[05 死锁#如何处理死锁|死锁处理]]：预防、避免、检测、解除；破坏必要条件之一就能预防。
- [[05 死锁#银行家算法是什么|银行家算法]]：分配前模拟是否仍有安全序列，不安全就拒绝分配。
- [[05 死锁#活锁和饥饿是什么|活锁和饥饿]]：死锁是不动，活锁是一直动但没进展，饥饿是长期轮不到资源。

## 内存管理

- [[06 内存管理#虚拟内存是什么|虚拟内存]]：给每个进程独立逻辑地址空间，通过页表映射到物理内存。
- [[06 内存管理#分页和分段有什么区别|分页和分段]]：分页固定大小，利于管理；分段按逻辑模块，利于理解。
- [[06 内存管理#页面置换算法有哪些|页面置换]]：FIFO、LRU、LFU、Clock、OPT；OPT 理论最优但不可实现。
- [[06 内存管理#TLB 是什么|TLB]]：页表缓存，加速虚拟地址到物理地址转换。
- [[06 内存管理#什么是内存碎片|内存碎片]]：内部碎片是分配了没用完，外部碎片是总量够但不连续。
- [[03 中断与异常#缺页异常是什么|缺页中断]]：虚拟页不在内存，触发内核调页。
- [[06 内存管理#连续内存分配方式有哪些|连续内存分配]]：单一连续、固定分区、动态分区；动态分区容易外部碎片。

## I/O 与设备管理

- [[07 IO与设备管理#I/O 控制方式有哪些|I/O 控制方式]]：程序轮询、中断驱动、DMA、通道控制；DMA 减少 CPU 参与数据搬运。
- [[07 IO与设备管理#缓冲区是什么|缓冲区]]：协调 CPU 和 I/O 设备速度差，减少频繁 I/O，提高吞吐。
- [[07 IO与设备管理#零拷贝是什么|零拷贝]]：减少用户态和内核态之间的数据拷贝，常见 `sendfile`、`mmap`。
- [[07 IO与设备管理#常见 I/O 模型有哪些|I/O 模型]]：阻塞、非阻塞、多路复用、信号驱动、异步 I/O。
- [[07 IO与设备管理#select、poll、epoll 有什么区别|select / poll / epoll]]：`select` 有 fd 限制，`poll` 数组无固定小限制，`epoll` 返回就绪事件适合高并发。
- [[07 IO与设备管理#select、poll、epoll 有什么区别|epoll 高效点]]：监听集合在内核，返回就绪列表，适合大量连接少量活跃。
- [[07 IO与设备管理#磁盘调度算法有哪些|磁盘调度]]：FCFS、SSTF、SCAN、C-SCAN；电梯算法减少磁头来回移动。
- [[07 IO与设备管理#设备管理主要做什么|设备管理]]：设备分配、驱动、缓冲、中断处理、设备独立性。

## 其他

- [[08 其他#用户程序到可执行程序经历什么|编译到可执行]]：预处理、编译、汇编、链接。
- [[08 其他#文件系统是什么|文件系统]]：管理文件、目录、权限、空间和文件名到元数据的映射。
- [[08 其他#inode 是什么|inode]]：保存文件元信息和数据块位置；文件名通常在目录项里。
- [[08 其他#硬链接和软链接有什么区别|硬链接和软链接]]：硬链接共 inode，软链接存路径；删原文件后硬链接仍可用，软链接可能悬空。
- [[08 其他#缓存一致性是什么|缓存一致性]]：多个缓存副本和底层数据要保持一致，核心是更新、失效和最新数据归属。
- [[08 其他#崩溃恢复是什么|崩溃恢复]]：通过日志、检查点等机制让系统异常后回到一致状态。
