## 链表理论基础

### 题目链接

- 代码随想录：[链表理论基础](https://programmercarl.com/链表理论基础.html)
- 力扣页面：无。这一节是链表基础概念，不是单独力扣题。

### 简要回答

链表是一种通过指针把节点串起来的线性结构。每个节点通常包含数据域和指针域，单链表节点只知道下一个节点，不能直接访问前一个节点。

### 常见类型

| 类型 | 特点 | 常见场景 |
|---|---|---|
| 单链表 | 每个节点只有 `next` | LeetCode 高频链表题 |
| 双链表 | 有 `prev` 和 `next` | LRU、双向遍历 |
| 循环链表 | 尾节点指回头节点 | 约瑟夫环 |

### C++ 节点定义

```cpp
struct ListNode {
    int val;        // 当前节点存储的值
    ListNode* next; // 指向下一个节点的指针

    ListNode(int x) : val(x), next(nullptr) {}
};
```

### 链表和数组对比

| 对比点 | 数组 | 链表 |
|---|---|---|
| 内存 | 连续 | 不连续，通过指针连接 |
| 随机访问 | `O(1)` | `O(n)` |
| 插入删除 | 通常要移动元素 | 找到位置后改指针即可 |
| 额外空间 | 不需要指针域 | 每个节点要存指针 |

### 面试表达

链表的节点在内存中不要求连续，靠 `next` 指针串起来。它插入删除方便，但随机访问差。单链表操作当前节点时，经常需要找到前驱节点，所以虚拟头节点非常常用。

## 203 移除链表元素

### 题目链接

- 代码随想录：[203. 移除链表元素](https://programmercarl.com/0203.移除链表元素.html)
- 力扣页面：[203. Remove Linked List Elements](https://leetcode.cn/problems/remove-linked-list-elements/)

### 题目描述

给定一个链表头节点 `head` 和整数 `val`，删除链表中所有节点值等于 `val` 的节点，并返回新的头节点。

### 示例

```text
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]
```

```text
输入：head = [7,7,7,7], val = 7
输出：[]
```

### 思路

删除链表节点时，最麻烦的是头节点，因为删除头节点会改变 `head`。虚拟头节点 `dummyHead` 可以让真实头节点也拥有一个前驱节点，从而把所有删除逻辑统一成“检查并删除 `cur->next`”。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        // 创建虚拟头节点。它不属于原链表，只是为了统一删除逻辑。
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;

        // cur 永远指向“当前要检查节点的前一个节点”。
        ListNode* cur = dummyHead;

        // cur->next 才是我们真正要判断是否删除的节点。
        while (cur->next != nullptr) {
            if (cur->next->val == val) {
                // tmp 指向要删除的节点，先保存下来，方便释放内存。
                ListNode* tmp = cur->next;

                // 跳过 tmp，让 cur 直接连到 tmp 后面的节点。
                cur->next = cur->next->next;

                // C++ 中手动 new 出来的节点需要 delete。
                delete tmp;
            } else {
                // cur->next 不需要删除，cur 才可以往后移动。
                cur = cur->next;
            }
        }

        // 新链表头节点可能已经改变，所以从 dummyHead->next 取。
        head = dummyHead->next;

        // 虚拟头节点也要释放。
        delete dummyHead;
        return head;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 删除后 `cur` 不要立刻后移，因为新的 `cur->next` 可能仍然需要删除。
- 删除头节点时可能连续删除多个。
- 虚拟头节点最后要 `delete`。

### 面试表达

单链表删除节点需要拿到前驱节点。虚拟头节点让真实头节点也有前驱，这样所有删除逻辑都可以统一为检查并删除 `cur->next`。

## 707 设计链表

### 题目链接

- 代码随想录：[707. 设计链表](https://programmercarl.com/0707.设计链表.html)
- 力扣页面：[707. Design Linked List](https://leetcode.cn/problems/design-linked-list/)

### 题目描述

设计一个链表，支持：

- `get(index)`：获取第 `index` 个节点的值。
- `addAtHead(val)`：头插。
- `addAtTail(val)`：尾插。
- `addAtIndex(index, val)`：在指定位置前插入。
- `deleteAtIndex(index)`：删除指定位置节点。

### 示例

```text
输入：
["MyLinkedList","addAtHead","addAtTail","addAtIndex","get","deleteAtIndex","get"]
[[],[1],[3],[1,2],[1],[1],[1]]

输出：
[null,null,null,null,2,null,3]
```

解释：

```text
addAtHead(1)   -> [1]
addAtTail(3)   -> [1,3]
addAtIndex(1,2)-> [1,2,3]
get(1)         -> 2
deleteAtIndex(1)-> [1,3]
get(1)         -> 3
```

### 思路

用单链表实现时，虚拟头节点可以统一头插、普通插入和删除。额外维护 `_size`，避免每次判断下标时重新遍历链表长度。

### C++ 详细注释代码

```cpp
class MyLinkedList {
public:
    struct LinkedNode {
        int val;
        LinkedNode* next;

        LinkedNode(int val) : val(val), next(nullptr) {}
    };

    MyLinkedList() {
        // 虚拟头节点不存有效数据，只用于简化边界。
        _dummyHead = new LinkedNode(0);
        _size = 0;
    }

    int get(int index) {
        // index 从 0 开始。非法下标直接返回 -1。
        if (index < 0 || index >= _size) {
            return -1;
        }

        // cur 从真实头节点开始走。
        LinkedNode* cur = _dummyHead->next;

        // 走 index 步后，cur 就指向第 index 个节点。
        while (index--) {
            cur = cur->next;
        }

        return cur->val;
    }

    void addAtHead(int val) {
        // 头插等价于在 index = 0 的位置插入。
        addAtIndex(0, val);
    }

    void addAtTail(int val) {
        // 尾插等价于在 index = _size 的位置插入。
        addAtIndex(_size, val);
    }

    void addAtIndex(int index, int val) {
        // index 大于链表长度时不能插入。
        if (index > _size) return;

        // 题目规定 index < 0 时插入到头部。
        if (index < 0) index = 0;

        // 找到插入位置的前驱节点。
        LinkedNode* cur = _dummyHead;
        while (index--) {
            cur = cur->next;
        }

        LinkedNode* newNode = new LinkedNode(val);

        // 插入顺序很重要：先让新节点连向后继，再让前驱连向新节点。
        newNode->next = cur->next;
        cur->next = newNode;

        ++_size;
    }

    void deleteAtIndex(int index) {
        // 下标非法时不做任何操作。
        if (index < 0 || index >= _size) return;

        // 找到待删除节点的前驱。
        LinkedNode* cur = _dummyHead;
        while (index--) {
            cur = cur->next;
        }

        LinkedNode* tmp = cur->next;
        cur->next = cur->next->next;

        delete tmp;
        --_size;
    }

private:
    int _size;
    LinkedNode* _dummyHead;
};
```

### 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `get` | `O(index)`，最坏 `O(n)` | `O(1)` |
| 头插 | `O(1)` | `O(1)` |
| 尾插 | `O(n)` | `O(1)` |
| 指定位置插入/删除 | `O(index)`，最坏 `O(n)` | `O(1)` |

### 易错点

- `index == _size` 表示尾插，是合法的。
- 删除时找的是待删除节点的前驱。
- 插入时必须先 `newNode->next = cur->next`，再 `cur->next = newNode`。

## 206 反转链表

### 题目链接

- 代码随想录：[206. 反转链表](https://programmercarl.com/0206.翻转链表.html)
- 力扣页面：[206. Reverse Linked List](https://leetcode.cn/problems/reverse-linked-list/)

### 题目描述

给定单链表的头节点 `head`，反转链表，并返回反转后的头节点。

### 示例

```text
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

```text
输入：head = []
输出：[]
```

### 思路

反转链表不需要创建新链表，只需要逐个改变 `next` 指针方向。用 `pre` 表示已经反转好的部分的头，`cur` 表示当前处理节点，`temp` 临时保存下一个节点，避免断链。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // pre 指向当前节点反转后应该指向的前一个节点。
        // 最开始头节点反转后要指向 nullptr。
        ListNode* pre = nullptr;

        // cur 指向当前正在处理的节点。
        ListNode* cur = head;

        while (cur != nullptr) {
            // 一定先保存下一个节点，否则 cur->next 改掉后就找不到后续链表。
            ListNode* temp = cur->next;

            // 反转当前节点的 next 指针。
            cur->next = pre;

            // pre 和 cur 同时向后移动一位。
            pre = cur;
            cur = temp;
        }

        // 循环结束时 cur == nullptr，pre 指向新的头节点。
        return pre;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 必须先保存 `cur->next`。
- 返回的是 `pre`，不是 `cur`。
- 空链表和单节点链表也能自然处理。

### 面试表达

翻转链表本质是逐个改变 `next` 指针。为了不丢失后续链表，我会先用 `temp` 保存 `cur->next`，再把 `cur->next` 指向 `pre`，最后整体后移。

## 24 两两交换链表中的节点

### 题目链接

- 代码随想录：[24. 两两交换链表中的节点](https://programmercarl.com/0024.两两交换链表中的节点.html)
- 力扣页面：[24. Swap Nodes in Pairs](https://leetcode.cn/problems/swap-nodes-in-pairs/)

### 题目描述

给定一个链表，两两交换其中相邻的节点，并返回交换后的链表头节点。要求不能只交换节点值，而要真正交换节点。

### 示例

```text
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

```text
输入：head = [1,2,3]
输出：[2,1,3]
```

### 思路

使用虚拟头节点，让 `cur` 始终指向待交换两个节点的前驱。每次交换 `first` 和 `second`，同时保存 `third`，避免链表断掉。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;

        // cur 指向当前要交换的两个节点的前驱。
        ListNode* cur = dummyHead;

        // 必须保证后面至少有两个节点，才能交换。
        while (cur->next != nullptr && cur->next->next != nullptr) {
            // first 是第一個待交换节点。
            ListNode* first = cur->next;

            // second 是第二个待交换节点。
            ListNode* second = cur->next->next;

            // third 是下一组的起点，先保存，避免断链。
            ListNode* third = second->next;

            // 第一步：前驱指向 second。
            cur->next = second;

            // 第二步：second 指向 first。
            second->next = first;

            // 第三步：first 指向 third。
            first->next = third;

            // cur 移动到交换后的第二个节点，也就是 first。
            cur = first;
        }

        ListNode* result = dummyHead->next;
        delete dummyHead;
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 要保存 `third`，否则交换后会丢失后续链表。
- 循环条件必须保证有两个节点。
- 交换的是节点连接，不是交换节点值。

## 19 删除链表的倒数第 N 个节点

### 题目链接

- 代码随想录：[19. 删除链表的倒数第 N 个节点](https://programmercarl.com/0019.删除链表的倒数第N个节点.html)
- 力扣页面：[19. Remove Nth Node From End of List](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

### 题目描述

给定一个链表，删除链表的倒数第 `n` 个节点，并返回链表头节点。

### 示例

```text
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

```text
输入：head = [1], n = 1
输出：[]
```

### 思路

用快慢指针。虚拟头节点可以处理删除头节点的情况。让快指针先走 `n + 1` 步，使慢指针最终停在待删除节点的前驱。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        // 虚拟头节点指向真正头节点，方便删除 head 本身。
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;

        // fast 和 slow 都从虚拟头开始。
        ListNode* fast = dummyHead;
        ListNode* slow = dummyHead;

        // fast 先走 n 步。
        while (n-- > 0) {
            fast = fast->next;
        }

        // 再多走一步，让 fast 和 slow 之间隔着 n 个节点。
        // 这样 fast 到 nullptr 时，slow 正好在待删除节点前驱。
        fast = fast->next;

        while (fast != nullptr) {
            // fast 和 slow 保持固定距离一起走。
            fast = fast->next;
            slow = slow->next;
        }

        // slow->next 就是要删除的节点。
        ListNode* tmp = slow->next;
        slow->next = tmp->next;

        delete tmp;

        ListNode* result = dummyHead->next;
        // dummyHead 是手动 new 的，也要释放。
        delete dummyHead;
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 使用虚拟头节点可以自然处理删除头节点。
- 慢指针要停在待删除节点前驱，不是待删除节点本身。
- 快指针先走 `n + 1` 步的效果，也可以拆成“先走 n 步，再额外走一步”。

## 面试题 02.07 链表相交

### 题目链接

- 代码随想录：[面试题 02.07. 链表相交](https://programmercarl.com/面试题02.07.链表相交.html)
- 力扣页面：[面试题 02.07. Intersection of Two Linked Lists LCCI](https://leetcode.cn/problems/intersection-of-two-linked-lists-lcci/)
- 同类力扣：[160. Intersection of Two Linked Lists](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

### 题目描述

给定两个单链表的头节点 `headA` 和 `headB`，找出两个链表相交的起始节点。如果两个链表没有交点，返回 `nullptr`。

注意：相交指的是两个节点在内存地址上相同，不是节点值相同。

### 示例

```text
输入：
listA = [4,1,8,4,5]
listB = [5,6,1,8,4,5]
intersectVal = 8

输出：Intersected at '8'
解释：两个链表从值为 8 的同一个节点开始相交。
```

```text
输入：
listA = [2,6,4]
listB = [1,5]
输出：No intersection
```

### 思路

两个链表如果相交，那么从交点到尾部的节点完全相同。先分别求两个链表长度，让长链表先走长度差，然后两个指针同步走，第一次指针相等的位置就是交点。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        // curA/curB 先用于统计长度，后面再重置为头节点。
        ListNode* curA = headA;
        ListNode* curB = headB;

        int lenA = 0;
        int lenB = 0;

        // 统计链表 A 的长度。
        while (curA != nullptr) {
            ++lenA;
            curA = curA->next;
        }

        // 统计链表 B 的长度。
        while (curB != nullptr) {
            ++lenB;
            curB = curB->next;
        }

        curA = headA;
        curB = headB;

        // 保证 curA 指向较长链表，curB 指向较短链表。
        if (lenB > lenA) {
            // 交换长度和指针，后面统一让 curA 先走差值。
            swap(lenA, lenB);
            swap(curA, curB);
        }

        // 长链表先走 gap 步，让两个指针到尾部的距离相同。
        int gap = lenA - lenB;
        while (gap-- > 0) {
            curA = curA->next;
        }

        // 同步向后走。相交判断必须比较指针地址。
        while (curA != nullptr) {
            if (curA == curB) {
                // 指针地址相同，说明从这个节点开始两条链表共享尾部。
                return curA;
            }
            // 两个指针到尾部距离相同，所以会同时到达交点或同时到达 nullptr。
            curA = curA->next;
            curB = curB->next;
        }

        // 同时走到末尾仍未相遇，说明没有交点。
        return nullptr;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(m + n)` |
| 空间 | `O(1)` |

### 易错点

- 比较的是节点地址 `curA == curB`，不是 `curA->val == curB->val`。
- 长链表先走长度差后，两个指针才同步。
- 题目要求不能破坏原链表结构。

### 面试表达

相交不是值相等，而是地址相等。为了同步比较，我会先让长链表走掉长度差，使两个指针到链表尾部的距离一致，再一起向后走。

## 142 环形链表 II

### 题目链接

- 代码随想录：[142. 环形链表 II](https://programmercarl.com/0142.环形链表II.html)
- 力扣页面：[142. Linked List Cycle II](https://leetcode.cn/problems/linked-list-cycle-ii/)

### 题目描述

给定一个链表头节点 `head`，如果链表中存在环，返回环的入口节点；如果没有环，返回 `nullptr`。不能修改链表。

### 示例

```text
输入：head = [3,2,0,-4], pos = 1
输出：tail connects to node index 1
解释：链表尾部连接到下标为 1 的节点，环入口是值为 2 的节点。
```

```text
输入：head = [1,2], pos = 0
输出：tail connects to node index 0
```

### 思路

先用快慢指针判断是否有环。快指针每次走两步，慢指针每次走一步；如果二者相遇，说明有环。相遇后，一个指针从头节点出发，另一个从相遇点出发，每次都走一步，它们再次相遇的位置就是环入口。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* fast = head;
        ListNode* slow = head;

        // fast 每次走两步，所以必须保证 fast 和 fast->next 都不为空。
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;

            // 快慢指针相遇，说明链表有环。
            if (slow == fast) {
                // index1 从相遇点出发。
                ListNode* index1 = fast;

                // index2 从头节点出发。
                ListNode* index2 = head;

                // 两个指针每次都走一步，再次相遇点就是环入口。
                while (index1 != index2) {
                    index1 = index1->next;
                    index2 = index2->next;
                }

                return index2;
            }
        }

        // fast 走到空，说明无环。
        return nullptr;
    }
};
```

### 为什么能找到入口

设头节点到入口距离为 `x`，入口到相遇点距离为 `y`，相遇点再到入口距离为 `z`。慢指针走了 `x + y`，快指针走了 `x + y + n(y + z)`，且快指针路程是慢指针 2 倍。推导后可得：

```text
x = (n - 1)(y + z) + z
```

也就是说，从头节点到入口的距离，等于从相遇点到入口的距离再加若干圈。所以两个指针同步走，会在入口相遇。

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 不能返回第一次相遇点，第一次相遇点不一定是入口。
- 循环条件必须写 `fast != nullptr && fast->next != nullptr`。
- 题目不允许修改链表。

### 面试表达

我先用快慢指针判断是否有环。若相遇，再让一个指针从头节点走，一个从相遇点走，每次一步。根据路程关系，它们会在环入口相遇。
