## 栈与队列理论基础

### 题目链接

- 代码随想录：[栈与队列理论基础](https://programmercarl.com/栈与队列理论基础.html)
- 力扣页面：无。这是基础概念，不是单独力扣题。

### 简要回答

栈是后进先出，队列是先进先出。C++ STL 中的 `stack` 和 `queue` 是容器适配器，默认底层容器通常是 `deque`，也可以指定其他底层容器。

### 基础对比

| 结构 | 规则 | 常用接口 | 典型场景 |
|---|---|---|---|
| 栈 `stack` | 后进先出 | `push`、`pop`、`top` | 括号匹配、表达式求值、递归模拟 |
| 队列 `queue` | 先进先出 | `push`、`pop`、`front` | BFS、任务队列 |
| 双端队列 `deque` | 两端可进出 | `push_back`、`pop_front` | 单调队列 |
| 优先队列 `priority_queue` | 按优先级出队 | `push`、`pop`、`top` | Top K、堆 |

### C++ 示例

```cpp
#include <stack>
#include <queue>
#include <vector>
#include <list>
using namespace std;

// 使用 vector 作为 stack 的底层容器。
stack<int, vector<int>> st;

// 使用 list 作为 queue 的底层容器。
queue<int, list<int>> que;
```

### 易错点

- `stack` 不提供迭代器，因为它只允许访问栈顶。
- `queue` 只能访问队头和队尾，不能随机访问中间元素。
- 栈里元素在内存中是否连续，取决于底层容器。

## 232 用栈实现队列

### 题目链接

- 代码随想录：[232. 用栈实现队列](https://programmercarl.com/0232.用栈实现队列.html)
- 力扣页面：[232. Implement Queue using Stacks](https://leetcode.cn/problems/implement-queue-using-stacks/)

### 题目描述

只使用两个栈实现先入先出队列，支持 `push`、`pop`、`peek` 和 `empty`。

### 示例

```text
输入：
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]

输出：
[null, null, null, 1, 1, false]
```

### 思路

用两个栈：输入栈 `stIn` 负责接收新元素，输出栈 `stOut` 负责弹出队头。当 `stOut` 为空时，把 `stIn` 中所有元素倒入 `stOut`，顺序就从后进先出变成先进先出。

### C++ 详细注释代码

```cpp
#include <stack>
using namespace std;

class MyQueue {
public:
    stack<int> stIn;  // 输入栈：负责 push 新元素。
    stack<int> stOut; // 输出栈：负责 pop/peek 队头元素。

    MyQueue() {}

    void push(int x) {
        // 新来的元素直接进入输入栈。
        stIn.push(x);
    }

    int pop() {
        // 只有输出栈为空时，才把输入栈里的元素全部倒过去。
        if (stOut.empty()) {
            while (!stIn.empty()) {
                stOut.push(stIn.top());
                stIn.pop();
            }
        }

        // 倒栈后，stOut.top() 就是最早进入队列的元素。
        int result = stOut.top();
        stOut.pop();
        return result;
    }

    int peek() {
        // 复用 pop 逻辑拿到队头。
        int result = pop();

        // peek 不能真正删除元素，所以再放回 stOut。
        stOut.push(result);
        return result;
    }

    bool empty() {
        // 两个栈都为空，队列才为空。
        return stIn.empty() && stOut.empty();
    }
};
```

### 复杂度

| 操作 | 均摊时间复杂度 | 空间复杂度 |
|---|---|---|
| `push` | `O(1)` | `O(n)` |
| `pop` | 均摊 `O(1)` | `O(n)` |
| `peek` | 均摊 `O(1)` | `O(n)` |

### 易错点

- 只有 `stOut` 为空时才倒数据。
- 倒数据必须一次性全部倒过去。
- 队列为空要求两个栈都为空。

## 225 用队列实现栈

### 题目链接

- 代码随想录：[225. 用队列实现栈](https://programmercarl.com/0225.用队列实现栈.html)
- 力扣页面：[225. Implement Stack using Queues](https://leetcode.cn/problems/implement-stack-using-queues/)

### 题目描述

只使用队列实现后进先出栈，支持 `push`、`pop`、`top` 和 `empty`。

### 示例

```text
输入：
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]

输出：
[null, null, null, 2, 2, false]
```

### 思路

一个队列就能模拟栈。`pop` 时，把队头元素依次搬到队尾，直到只剩最后一个元素；这个最后入队的元素就是栈顶。

### C++ 详细注释代码

```cpp
#include <queue>
using namespace std;

class MyStack {
public:
    // 用一个队列模拟栈。
    queue<int> que;

    MyStack() {}

    void push(int x) {
        // 入栈等价于直接入队。
        que.push(x);
    }

    int pop() {
        // 当前队列长度固定下来，避免搬运过程中 size 变化影响循环。
        int size = que.size();

        // 留下最后一个元素不搬，其余元素都从队头搬到队尾。
        for (int i = 0; i < size - 1; ++i) {
            que.push(que.front());
            que.pop();
        }

        // 此时队头就是最后入队的元素，也就是栈顶。
        int result = que.front();
        que.pop();
        return result;
    }

    int top() {
        int result = pop();

        // top 不能删除元素，所以拿出来后再放回队尾。
        que.push(result);
        return result;
    }

    bool empty() {
        // 队列为空，模拟的栈也为空。
        return que.empty();
    }
};
```

### 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| `push` | `O(1)` | `O(n)` |
| `pop` | `O(n)` | `O(n)` |
| `top` | `O(n)` | `O(n)` |

### 易错点

- `pop` 时只搬 `size - 1` 个元素，最后一个就是栈顶。
- `top` 要把弹出的元素放回去。

## 20 有效的括号

### 题目链接

- 代码随想录：[20. 有效的括号](https://programmercarl.com/0020.有效的括号.html)
- 力扣页面：[20. Valid Parentheses](https://leetcode.cn/problems/valid-parentheses/)

### 题目描述

给定只包含 `(`、`)`、`{`、`}`、`[`、`]` 的字符串，判断括号是否有效。有效要求左括号必须用相同类型右括号闭合，并且顺序正确。

### 示例

```text
输入：s = "()[]{}"
输出：true
```

```text
输入：s = "(]"
输出：false
```

```text
输入：s = "([)]"
输出：false
```

### 思路

遇到左括号时，不把左括号入栈，而是把它期待匹配的右括号入栈。遇到右括号时，只需要判断它是否等于栈顶。

### C++ 详细注释代码

```cpp
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    bool isValid(string s) {
        // 奇数长度不可能完全匹配。
        if (s.size() % 2 == 1) return false;

        stack<char> st;

        for (char c : s) {
            if (c == '(') {
                // 遇到左小括号，期待后面出现右小括号。
                st.push(')');
            } else if (c == '[') {
                // 遇到左中括号，期待后面出现右中括号。
                st.push(']');
            } else if (c == '{') {
                // 遇到左大括号，期待后面出现右大括号。
                st.push('}');
            } else {
                // 当前是右括号：
                // 1. 栈空说明右括号多了；
                // 2. 栈顶不等于当前字符说明括号类型不匹配。
                if (st.empty() || st.top() != c) {
                    return false;
                }
                st.pop();
            }
        }

        // 所有括号都匹配完，栈应该为空。
        return st.empty();
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 遍历结束后栈不空，说明左括号多了。
- 栈空时遇到右括号，说明右括号多了。
- 类型不同，比如 `(]`，也要返回 false。

## 1047 删除字符串中的所有相邻重复项

### 题目链接

- 代码随想录：[1047. 删除字符串中的所有相邻重复项](https://programmercarl.com/1047.删除字符串中的所有相邻重复项.html)
- 力扣页面：[1047. Remove All Adjacent Duplicates In String](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)

### 题目描述

给定字符串 `s`，不断删除相邻且相同的两个字符，直到不能继续删除，返回最终字符串。

### 示例

```text
输入：s = "abbaca"
输出："ca"
解释："abbaca" -> "aaca" -> "ca"。
```

### 思路

这和括号匹配类似，都是“栈消除”。当前字符和栈顶相同就弹出，不同就压入。可以直接用字符串当栈，`back()` 就是栈顶。

### C++ 详细注释代码

```cpp
#include <string>
using namespace std;

class Solution {
public:
    string removeDuplicates(string s) {
        // result 当作栈使用，result.back() 就是栈顶。
        string result;

        for (char c : s) {
            // 如果当前字符和栈顶相同，它们就是一对相邻重复项。
            if (!result.empty() && result.back() == c) {
                // 当前字符和栈顶相同，形成一对相邻重复，删除栈顶。
                result.pop_back();
            } else {
                // 当前字符暂时无法消除，入栈。
                result.push_back(c);
            }
        }

        // 栈中剩下的字符就是所有消除完成后的结果。
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 删除后可能产生新的相邻重复，所以栈结构很适合。
- 用 `string` 当栈可以避免最后再反转结果。

## 150 逆波兰表达式求值

### 题目链接

- 代码随想录：[150. 逆波兰表达式求值](https://programmercarl.com/0150.逆波兰表达式求值.html)
- 力扣页面：[150. Evaluate Reverse Polish Notation](https://leetcode.cn/problems/evaluate-reverse-polish-notation/)

### 题目描述

给定一个逆波兰表达式，也叫后缀表达式，求表达式的值。有效运算符包括 `+`、`-`、`*`、`/`。

### 示例

```text
输入：tokens = ["2","1","+","3","*"]
输出：9
解释：((2 + 1) * 3) = 9
```

```text
输入：tokens = ["4","13","5","/","+"]
输出：6
解释：(4 + (13 / 5)) = 6
```

### 思路

遇到数字就入栈；遇到运算符就弹出两个数字计算，再把结果压回栈。注意减法和除法有左右操作数顺序。

### C++ 详细注释代码

```cpp
#include <vector>
#include <string>
#include <stack>
using namespace std;

class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        // 栈里保存已经计算出来的操作数。
        stack<long long> st;

        for (const string& token : tokens) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                // 先弹出的是右操作数。
                long long right = st.top();
                st.pop();

                // 后弹出的是左操作数。
                long long left = st.top();
                st.pop();

                if (token == "+") st.push(left + right);
                else if (token == "-") st.push(left - right); // 注意顺序是左减右。
                else if (token == "*") st.push(left * right);
                else st.push(left / right);                    // C++ 整数除法向 0 截断。
            } else {
                // stoll 可以处理负数字符串，例如 "-11"。
                st.push(stoll(token));
            }
        }

        // 最后栈中唯一元素就是表达式结果。
        return st.top();
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 减法和除法顺序不能反：`left - right`、`left / right`。
- token 可能是负数，不能只看第一个字符是不是 `-` 来判断运算符。

## 239 滑动窗口最大值

### 题目链接

- 代码随想录：[239. 滑动窗口最大值](https://programmercarl.com/0239.滑动窗口最大值.html)
- 力扣页面：[239. Sliding Window Maximum](https://leetcode.cn/problems/sliding-window-maximum/)

### 题目描述

给定整数数组 `nums` 和窗口大小 `k`，窗口每次向右移动一位，返回每个窗口中的最大值。

### 示例

```text
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
```

解释：

```text
窗口 [1,3,-1] 最大值是 3
窗口 [3,-1,-3] 最大值是 3
窗口 [-1,-3,5] 最大值是 5
```

### 思路

用单调队列维护窗口内可能成为最大值的元素。队列从头到尾单调递减，队头就是当前窗口最大值。新元素入队时，把队尾所有比它小的元素弹出，因为这些元素以后不可能成为最大值。

### C++ 详细注释代码

```cpp
#include <vector>
#include <deque>
using namespace std;

class Solution {
private:
    class MonotonicQueue {
    public:
        deque<int> que;

        void pop(int value) {
            // 只有当窗口移出的元素正好等于队头时，才弹出队头。
            if (!que.empty() && que.front() == value) {
                que.pop_front();
            }
        }

        void push(int value) {
            // 保持队列从头到尾单调递减。
            // 队尾比当前值小的元素不可能再成为最大值，直接删除。
            while (!que.empty() && que.back() < value) {
                que.pop_back();
            }
            que.push_back(value);
        }

        int maxValue() {
            // 单调队列队头始终是当前窗口最大值。
            return que.front();
        }
    };

public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        MonotonicQueue que;
        vector<int> result;

        // 先把第一个窗口的元素加入单调队列。
        for (int i = 0; i < k; ++i) {
            que.push(nums[i]);
        }
        result.push_back(que.maxValue());

        // 窗口开始向右滑动。
        for (int i = k; i < nums.size(); ++i) {
            // 移除窗口左侧滑出的元素 nums[i - k]。
            que.pop(nums[i - k]);

            // 加入窗口右侧新进入的元素 nums[i]。
            que.push(nums[i]);

            // 队头就是当前窗口最大值。
            result.push_back(que.maxValue());
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(k)` |

### 易错点

- 单调队列里不是保存所有窗口元素，只保存有可能成为最大值的元素。
- 窗口滑出元素只有等于队头时才需要弹出。
- 大顶堆也能做，但删除窗口外元素更麻烦。

## 347 前 K 个高频元素

### 题目链接

- 代码随想录：[347. 前 K 个高频元素](https://programmercarl.com/0347.前K个高频元素.html)
- 力扣页面：[347. Top K Frequent Elements](https://leetcode.cn/problems/top-k-frequent-elements/)

### 题目描述

给定整数数组 `nums` 和整数 `k`，返回出现频率前 `k` 高的元素。答案顺序任意。

### 示例

```text
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

```text
输入：nums = [1], k = 1
输出：[1]
```

### 思路

先用 `unordered_map` 统计每个元素出现次数，再用大小为 `k` 的小顶堆保留频率最高的 `k` 个元素。堆顶是当前候选里频率最低的元素，一旦堆大小超过 `k`，就弹出堆顶。

### C++ 详细注释代码

```cpp
#include <vector>
#include <unordered_map>
#include <queue>
using namespace std;

class Solution {
public:
    // 小顶堆比较器：频率小的排在堆顶。
    class Compare {
    public:
        bool operator()(const pair<int, int>& lhs, const pair<int, int>& rhs) {
            return lhs.second > rhs.second;
        }
    };

    vector<int> topKFrequent(vector<int>& nums, int k) {
        // frequency[num] 表示 num 出现了多少次。
        unordered_map<int, int> frequency;

        // 统计每个数字出现次数。
        for (int num : nums) {
            ++frequency[num];
        }

        // pair.first 是数字，pair.second 是频率。
        priority_queue<pair<int, int>, vector<pair<int, int>>, Compare> heap;

        for (auto& item : frequency) {
            // 先把当前数字及其频率放入小顶堆。
            heap.push(item);

            // 只保留 k 个频率最高的元素。
            if (heap.size() > k) {
                // 堆顶是候选中频率最低的，超过 k 时弹掉它。
                heap.pop();
            }
        }

        vector<int> result;
        while (!heap.empty()) {
            // 题目允许任意顺序，所以直接弹出即可。
            result.push_back(heap.top().first);
            heap.pop();
        }

        // 返回前 k 个高频元素，顺序不作要求。
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n log k)` |
| 空间 | `O(n)` |

### 易错点

- 用小顶堆，不是大顶堆；小顶堆方便维护大小为 `k` 的候选集合。
- 比较器里 `lhs.second > rhs.second` 才能形成频率小的在堆顶。
- 结果顺序任意，通常不用再排序。

## 栈与队列总结

### 题型速记

| 题型 | 关键词 | 常用结构 |
|---|---|---|
| 括号匹配 | 成对消除 | 栈 |
