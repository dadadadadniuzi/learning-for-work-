# 网络速背清单

返回：[[网络导航]]

> [!abstract]

## 基础概念

- [[01 基础概念#TCP 和 UDP 有什么区别|TCP vs UDP]]：TCP 连接、可靠、有序、字节流；UDP 无连接、尽力而为、数据报、开销小。
- [[01 基础概念#HTTP 常见请求方法有哪些|HTTP 方法]]：GET 查，POST 提交，PUT 整体改，PATCH 局部改，DELETE 删，HEAD 只要头，OPTIONS 问能力。
- [[01 基础概念#GET 和 POST 有什么区别|GET vs POST]]：GET 获取、URL 参数、幂等、易缓存；POST 提交、body 参数、通常非幂等。
- [[01 基础概念#HTTP 状态码有哪些|状态码]]：2xx 成功，3xx 重定向/缓存，4xx 客户端错，5xx 服务端错。
- [[01 基础概念#HTTP 头部字段有哪些|HTTP 头]]：`Host` 站点，`Content-Type` 类型，`Cookie` 状态，`Authorization` 认证，`Cache-Control` 缓存。
- [[01 基础概念#常见网络排查命令|排查命令]]：连通 `ping`，HTTP `curl`，端口 `telnet/nc`，连接 `ss/netstat`，抓包 `tcpdump`。

## TCP

- [[02 TCP深入#TCP 三次握手过程|三次握手]]：`SYN -> SYN+ACK -> ACK`，确认双方收发能力，同步初始序列号。
- [[02 TCP深入#为什么 TCP 是三次握手，不是两次或四次|为什么三次]]：两次防不了历史 SYN 和半开连接，四次多余。
- [[02 TCP深入#TCP 四次挥手过程|四次挥手]]：`FIN -> ACK -> FIN -> ACK`，TCP 全双工，两个方向分别关闭。
- [[02 TCP深入#为什么会有 TIME_WAIT|TIME_WAIT]]：保证最后 ACK 可重发，让旧报文自然消失，通常 2MSL。
- [[02 TCP深入#TCP 如何保证可靠传输|可靠传输]]：序列号、ACK、重传、校验和、滑动窗口、流量控制、拥塞控制。
- [[02 TCP深入#TCP 拥塞控制有哪些机制|拥塞控制]]：慢启动、拥塞避免、快重传、快恢复；记住 `cwnd` 和 `ssthresh`。
- [[02 TCP深入#TCP Keepalive 和 HTTP Keep-Alive 有什么区别|Keepalive 区别]]：TCP Keepalive 探活；HTTP Keep-Alive 复用连接。

## HTTP

- [[03 HTTP进阶#HTTP/1.0 和 HTTP/1.1 有什么区别|HTTP/1.0 vs 1.1]]：1.1 默认长连接、Host、分块传输、缓存增强、范围请求。
- [[03 HTTP进阶#HTTP/2.0 有哪些改进|HTTP/2]]：二进制分帧、多路复用、HPACK、流优先级、服务器推送。
- [[03 HTTP进阶#为什么浏览器会建立多个 TCP 连接|多个 TCP 连接]]：HTTP/1.1 用多个连接并发加载资源，缓解队头阻塞。
- [[03 HTTP进阶#长连接和短连接有什么区别|长连接]]：复用 TCP，减少握手挥手开销，但占用连接资源。

## HTTPS 与缓存

- [[04 安全与缓存#HTTP 和 HTTPS 有什么区别|HTTP vs HTTPS]]：HTTPS = HTTP + TLS，解决窃听、篡改、冒充，默认 443。
- [[04 安全与缓存#HTTPS 工作原理是什么|HTTPS 原理]]：非对称加密协商密钥，对称加密传输数据，证书验证身份。
- [[04 安全与缓存#对称加密和非对称加密有什么区别|对称/非对称]]：对称快但密钥分发难；非对称慢但适合交换密钥和身份认证。
- [[04 安全与缓存#证书校验解决什么问题|证书校验]]：确认公钥属于目标网站，防中间人冒充。
- [[04 安全与缓存#强缓存和协商缓存有什么区别|缓存]]：强缓存不请求服务器；协商缓存请求验证，命中返回 `304`。
- [[04 安全与缓存#Cookie 和 Session 有什么区别|Cookie vs Session]]：Cookie 在客户端，Session 在服务端；Session ID 常放 Cookie。

## 综合应用

- [[05 综合应用#DNS 查询过程是什么|DNS 流程]]：浏览器缓存、系统缓存、hosts、本地 DNS、根、顶级、权威 DNS。
- [[05 综合应用#递归查询和迭代查询有什么区别|递归/迭代]]：递归是帮你查到底，迭代是告诉你下一步问谁。
- [[05 综合应用#DNS 常见记录类型有哪些|DNS 记录]]：A IPv4，AAAA IPv6，CNAME 别名，MX 邮件，NS 权威服务器，TXT 文本验证。
- [[05 综合应用#输入 URL 到页面展示发生了什么|URL 全流程]]：URL 解析、DNS、TCP、TLS、HTTP、服务器处理、响应、浏览器渲染。
- [[05 综合应用#浏览器访问服务器流程|服务器流程]]：读请求、路由匹配、业务处理、生成响应、写回 socket。
