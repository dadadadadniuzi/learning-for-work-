# 算法速背清单

## 数组

- [[01 数组#704 二分查找|二分查找]]：先明确区间定义，左闭右闭用 `while (left <= right)`，左闭右开用 `while (left < right)`。
- [[01 数组#27 移除元素|移除元素]]：快慢指针，快指针遍历原数组，慢指针维护新数组位置。
- [[01 数组#209 长度最小的子数组|滑动窗口]]：右指针扩张窗口，满足条件后左指针收缩。
- [[01 数组#58 区间和|前缀和]]：区间和转成两个前缀和相减。
- [[01 数组#59 螺旋矩阵 II|模拟]]：坚持同一套边界规则，别一圈里混用开闭区间。

## 链表

- [[02 链表#203 移除链表元素|虚拟头节点]]：统一处理删除头节点和普通节点。
- [[02 链表#206 反转链表|翻转链表]]：`pre`、`cur`、`tmp` 三指针。
- [[02 链表#19 删除链表的倒数第 N 个节点|倒数第 N 个]]：快指针先走 N 步，再一起走。
- [[02 链表#面试题 02.07 链表相交|链表相交]]：A+B 和 B+A，两指针同步到交点。
- [[02 链表#142 环形链表 II|环形链表]]：快慢指针相遇，再从头和相遇点同步走找入口。

## 哈希表

- [[03 哈希表#242 有效的字母异位词|字符计数]]：小写字母优先用长度 26 数组。
- [[03 哈希表#349 两个数组的交集|去重]]：`unordered_set`。
- [[03 哈希表#1 两数之和|两数之和]]：一边遍历一边查 `target - nums[i]`。

- [[03 哈希表#15 三数之和|三数/四数之和]]：排序 + 双指针 + 去重。

- [[06 栈与队列#232 用栈实现队列|双栈队列]]：输入栈负责 push，输出栈负责 pop/peek。

## 二叉树

## 面试开口模板

| 题型 | 开口第一句 |
|---|---|
| 数组二分 | 我先确定区间定义，避免边界混乱；这里找的是第一个满足条件的位置。 |
| 滑动窗口 | 右指针扩张窗口，窗口满足条件后左指针收缩，同时维护答案。 |
| 链表 | 我会加虚拟头节点处理头节点变化，再用指针维护局部连接关系。 |
| 回溯 | 这题是树形搜索，我先确定递归参数、终止条件和单层选择，再处理撤销选择。 |
| 贪心 | 我先说明局部最优选择是什么，再解释这个选择不会破坏后续最优性。 |
| 动态规划 | 我先定义 `dp` 数组含义，再推递推公式，最后确认初始化和遍历顺序。 |
| 图论 | 我先判断图是否有向、是否带权、边权是否可能为负，再选择 DFS/BFS、并查集、拓扑或最短路。 |
