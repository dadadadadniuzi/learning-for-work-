# C++ 今日速背清单

返回：[[C++导航]]

## 1. C++ 三大特性

封装、继承、多态。封装隐藏实现细节，继承复用和扩展父类能力，多态让同一个接口在不同对象上表现出不同行为。

## 2. 指针和引用

指针是保存地址的变量，可以为空，可以改指向；引用是对象别名，定义时必须绑定，一般不能改绑。

## 2.5 struct 和 class

`struct` 和 `class` 在 C++ 中语法能力几乎一样，核心区别是默认权限：`struct` 成员和继承默认 `public`，`class` 成员和继承默认 `private`。实际使用中，`struct` 常用来表示简单数据结构，`class` 常用来表示有封装和行为的对象。

## 2.6 struct 和 union

`struct` 的成员各自占用独立空间，可以同时有效；`union` 的所有成员共享同一块空间，同一时间通常只有一个活跃成员。C++11 后 `union` 可以包含非 POD 类型，但需要手动管理构造、析构和当前活跃成员；现代 C++ 更推荐用 `std::variant` 表示安全的变体类型。

## 2.7 sizeof 和 strlen

`sizeof` 是运算符，看类型占用字节数；`strlen` 是函数，数到 `\0` 前有多少字符。`char arr[] = "hello"` 时 `sizeof(arr)` 是 6；`const char* p = "hello"` 时 `sizeof(p)` 是指针大小。数组作为函数参数会退化成指针，所以函数里 `sizeof(arr)` 得不到原数组大小。`strlen` 是 `O(n)`，循环里要缓存结果。

## 2.8 浮点数比较

浮点数计算会有二进制表示误差，所以多数情况下不要直接用 `==`。固定范围或已知精度用绝对误差，数值规模变化很大时用相对误差，工程中常二者结合。`0.1 + 0.2 != 0.3` 是因为十进制小数在二进制中可能无限循环。NaN 和任何值比较都为 false，应使用 `std::isnan`、`std::isinf`、`std::isfinite` 判断特殊值。

## 2.9 C++ 四种类型转换

`static_cast` 做编译期可判断的常规转换；`dynamic_cast` 做多态继承体系中的安全向下或交叉转换，失败指针返回 `nullptr`；`const_cast` 只改 `const/volatile` 属性，不能修改本身就是 const 的对象；`reinterpret_cast` 是底层比特重解释，风险最高。C++ 推荐用这四种命名转换替代 C 风格强转，因为意图更明确。

## 3. 构造函数调用

定义对象会调用构造，`new A()` 会调用构造，`new A[3]` 会调用三次构造，成员对象会先于外层对象构造。只写 `A* p = nullptr` 不会创建对象，所以不调用构造。

构造函数常见种类：默认构造、参数化构造、拷贝构造、移动构造、委托构造、继承构造。拷贝构造用已有对象初始化新对象，移动构造用右值引用转移资源，委托构造减少重复初始化代码，继承构造用 `using Base::Base` 复用基类构造函数。

## 3.5 面向对象学习主线

接下来面向对象按这条线复习：构造/析构 -> 拷贝控制 -> 重载/重写 -> 继承 -> 虚函数/纯虚函数 -> 虚表/虚指针 -> 多态 -> 多重继承/菱形继承 -> final 禁止继承 -> 单例模式。当前总入口见 [[08 面向对象导航]]。

构造函数用于初始化对象，析构函数用于释放资源。构造函数不能是虚函数，因为虚函数机制依赖对象已经构造好；析构函数可以且很多基类应该写成虚函数，否则通过基类指针删除派生类对象时可能只析构基类部分，导致资源泄漏。

重载是同一作用域下同名不同参，编译期决定；重写是子类重写父类虚函数，运行时决定。`virtual` 写在父类上，表示支持多态；`override` 写在子类上，表示“我就是在重写你”，并让编译器帮忙检查签名。

运行时多态的核心公式：`virtual` + 继承 + 基类指针或引用 + 子类重写。底层通常靠对象里的 `vptr` 指向类的 `vtable`，调用虚函数时通过虚表做动态绑定。纯虚函数写成 `= 0`，能把类变成抽象类；`override` 用于检查重写，`final` 用于禁止继续重写或继承。

虚函数可以有默认实现，类也可以实例化；纯虚函数写成 `virtual void f() = 0`，主要用于定义接口规范，含纯虚函数的类通常是抽象类，不能实例化。纯虚函数甚至可以单独提供实现，但类依然是抽象类。

虚函数底层通常是：类有 `vtable`，对象里有隐藏的 `vptr` 指向 `vtable`，调用虚函数时通过 `vptr -> vtable -> 函数地址` 做动态绑定。多继承下对象可能有多个 `vptr`；虚函数调用比普通函数多一次间接寻址，略有开销。

单独问“虚函数表是什么”时可以直接答：它就是编译器为含虚函数的类生成的一张函数地址表，通常位于只读数据段，对象通过内部隐藏的 `vptr` 指向它，从而在运行时找到正确的虚函数实现。

多重继承允许一个类同时继承多个基类，优点是接口组合和更自然建模，缺点是名称冲突、对象布局复杂和菱形继承问题。菱形继承会让最派生类里出现多份同一基类子对象，造成二义性和冗余；C++ 通常通过虚继承解决，让虚基类只保留一份。很多时候组合比多重继承更稳。

禁止类被继承时，现代 C++ 直接用 `final` 修饰类；禁止虚函数继续被重写时，也可以用 `final` 修饰函数。它除了语义清晰，还可能帮助编译器做去虚拟化优化。C++11 之前那些私有构造 + 友元 + 虚继承的技巧，知道有即可，不是现在的推荐方案。

深拷贝和浅拷贝的区别在于资源所有权。浅拷贝只复制成员值，指针成员只复制地址，多个对象可能共享同一块资源，容易出现悬垂指针和 `double free`；深拷贝会重新分配资源并复制内容，让对象彼此独立。类里只要自己管理裸资源，就要认真考虑拷贝构造、赋值运算符和三五法则。

## 4. this

`this` 是非静态成员函数里的隐藏指针，指向当前调用该函数的对象，本质上是编译器自动传入的参数。`p->member` 等价于 `(*p).member`，它们都属于指针访问成员；对象本身用 `obj.member`。`*this` 得到当前对象本身，常用于链式调用。静态成员函数没有 `this`，因为它不属于某个具体对象。

单例模式的核心是：私有构造、删除拷贝、类内保存唯一实例、通过静态接口统一访问。常见写法有饿汉式、懒汉式、双检锁和局部静态变量。其中现代 C++ 最推荐的是 C++11 的 Magic Static：`static Singleton instance;`，因为它简洁、延迟初始化，而且线程安全。

饿汉式里常见的 `Singleton* Singleton::instance = new Singleton();` 虽然写在类外，但它是在定义这个类自己的静态成员，所以仍然处于类成员定义语境，允许访问 private 构造函数；这行代码通常在 `main` 之前执行。

## 4.5 STL 主线

STL 这轮先按这条线复习：容器分类 -> `vector` 底层和扩容 -> `push_back/emplace_back` -> 迭代器失效 -> `map` / `unordered_map` 对比 -> `rehash` -> `deque/list/map` 底层 -> `allocator`。主入口见 [[09 STL与容器]]。

## 5. 模板

`template <typename T>` 表示把类型作为参数。线程池写成模板，是为了不把任务类型写死，可以支持 `http_conn*`、`Task*`、`std::function<void()>` 等不同任务。

`template <int N>` 表示非类型模板参数，传入的是编译期整数常量。比如 `Array<10>` 中的 `10` 在编译期就确定，可以用于固定数组大小；`Array<10>` 和 `Array<20>` 是两个不同类型。

## 6. std::list<T *> m_workqueue

`std::list` 是双向链表，`T*` 表示元素类型是 T 的指针，`m_workqueue` 是工作队列变量名。在线程池中，它通常保存待处理任务指针。

## 6.5 static 和 const

`static` 控制生命周期和可见性：局部静态变量不会随函数栈帧销毁，文件作用域的 `static` 只在当前文件可见，类静态成员被所有对象共享。`const` 控制可修改性：普通变量只读，指针和引用不能通过它修改对象，`const` 成员函数承诺不修改对象状态。

高频追问：C++ 中优先用 `const/constexpr` 替代 `#define` 常量；C++11 保证局部 `static` 初始化线程安全，但初始化后的读写不自动线程安全；`mutable` 允许在 `const` 成员函数中修改内部实现细节；跨 `.cpp` 的全局静态对象初始化顺序不能依赖，常用函数内局部 `static` 规避。

变量生命周期：局部变量通常在栈上，每次进入作用域创建、离开销毁，未初始化值不确定；静态局部变量作用域在函数内，但生命周期贯穿程序，只初始化一次，存储在全局/静态区；全局变量定义在函数外，生命周期贯穿程序，默认零初始化，通常在全局/静态区，不在堆上。

## 6.6 extern C

`extern "C"` 告诉 C++ 编译器按 C 语言链接规则处理函数名，核心是禁止 C++ 名称修饰，避免 C++ 去找 `_Z3fooi` 这类修饰符号而 C 库里只有 `foo`。它常用于 C++ 调 C 库、C 调 C++ 包装接口、Python/Lua 等语言扩展入口。

## 6.7 volatile

`volatile` 表示变量可能被硬件、ISR、信号处理程序等外部因素修改，编译器不能把访问随意优化掉。它和 `const` 不冲突，`const volatile` 常用于只读硬件寄存器。`volatile` 不保证原子性，也不提供多线程同步；多线程共享变量优先用 `std::atomic` 或锁。

## 6.8 inline 和宏

`inline` 是 C++ 函数，有类型检查、作用域和调试信息；宏是预处理期文本替换，没有类型检查，容易多次求值。`inline` 不保证一定展开，类内定义的成员函数默认具有 `inline` 语义。宏仍适合条件编译、日志裁剪、`#` 字符串化和 `##` 令牌拼接。

## 6.9 auto 和 decltype

`auto` 根据初始化表达式推导变量类型，适合简化复杂类型、范围 for、lambda 和模板局部变量。`decltype` 根据表达式推导类型，适合保留引用和 const、模板返回类型、元编程。`decltype(x)` 得到声明类型，`decltype((x))` 因为 `(x)` 是左值表达式，所以得到 `T&`；`decltype(auto)` 能保留返回值的引用属性。

## 7. const 指针组合

```cpp
const int* p;       // 不能通过 p 改值，p 可改指向
int* const p;       // p 不能改指向，可通过 p 改值
const int* const p; // 值和指向都不能改
```

## 8. 二级指针和指针引用

`int** pp` 是指向指针的指针；`int*& k` 是指针变量的引用，可以在函数里修改外部指针本身。

## 9. 指针相减

同一段连续内存中的两个指针相减，结果是相差的元素个数。`char*` 相减时就是相差几个字符。

## 10. 静态成员变量

类的静态成员变量属于类，不属于对象，通常必须在类外定义一次。类内声明不分配存储空间，类外定义才真正分配。

## 11. 饿汉式单例

```cpp
single* single::p = new single();
```

这句是静态成员变量的类外定义和初始化。它会在 `main` 前创建实例，所以是饿汉式。

## 12. 数组不能事后整体赋值

```cpp
int a[3];
a = {1, 2, 3}; // 错
```

C/C++ 原生数组不是可修改左值，不支持创建后整体赋值。可以初始化时赋值，或用 `std::array`。
