## 二叉树理论基础

### 题目链接

- 代码随想录：[二叉树理论基础](https://programmercarl.com/二叉树理论基础.html)
- 力扣页面：无。这一节是基础概念，不是单独力扣题。

### 简要回答

二叉树是每个节点最多有两个孩子的树。刷题里最常见的是普通二叉树、完全二叉树、满二叉树、二叉搜索树和平衡二叉树。

### C++ 节点定义

```cpp
struct TreeNode {
    int val;          // 当前节点值
    TreeNode *left;   // 左孩子
    TreeNode *right;  // 右孩子

    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right)
        : val(x), left(left), right(right) {}
};
```

### 核心概念

| 类型 | 特点 |
|---|---|
| 满二叉树 | 除叶子外每个节点都有两个孩子，深度为 `k` 时节点数是 `2^k - 1` |
| 完全二叉树 | 从上到下、从左到右连续填充，堆通常就是完全二叉树 |
| 二叉搜索树 | 左子树所有节点 `< 根节点 < 右子树所有节点` |
| 平衡二叉树 | 任意节点左右子树高度差不超过 1 |

### 面试表达

二叉树题先判断遍历顺序：当前节点先做决策，多半前序；需要左右子树结果再处理当前节点，多半后序；BST 题优先想到中序有序和大小剪枝；按层描述就用队列层序。

## 144 94 145 二叉树的递归遍历

### 题目链接

- 代码随想录：[二叉树的递归遍历](https://programmercarl.com/二叉树的递归遍历.html)
- 力扣页面：[144. Binary Tree Preorder Traversal](https://leetcode.cn/problems/binary-tree-preorder-traversal/)
- 力扣页面：[94. Binary Tree Inorder Traversal](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- 力扣页面：[145. Binary Tree Postorder Traversal](https://leetcode.cn/problems/binary-tree-postorder-traversal/)

### 题目描述

给定一棵二叉树，分别返回它的前序、中序、后序遍历结果。

### 示例

```text
输入：root = [1,null,2,3]
前序输出：[1,2,3]
中序输出：[1,3,2]
后序输出：[3,2,1]
```

### 思路

前中后序说的是“中节点”的访问位置：

- 前序：中、左、右。
- 中序：左、中、右。
- 后序：左、右、中。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void preorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;

        result.push_back(root->val);      // 中：先记录当前节点
        preorder(root->left, result);     // 左：遍历左子树
        preorder(root->right, result);    // 右：遍历右子树
    }

    void inorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;

        inorder(root->left, result);      // 左
        result.push_back(root->val);      // 中
        inorder(root->right, result);     // 右
    }

    void postorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;

        postorder(root->left, result);    // 左
        postorder(root->right, result);   // 右
        result.push_back(root->val);      // 中：最后记录当前节点
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(h)`，`h` 是树高，最坏 `O(n)` |

### 易错点

- 前中后序看的是“当前节点”在什么时候处理。
- 递归函数如果只收集答案，可以用 `void`；如果子树要返回状态，就设计返回值。

## 144 94 145 二叉树的迭代遍历

### 题目链接

- 代码随想录：[二叉树的迭代遍历](https://programmercarl.com/二叉树的迭代遍历.html)
- 力扣页面：[144. Binary Tree Preorder Traversal](https://leetcode.cn/problems/binary-tree-preorder-traversal/)
- 力扣页面：[94. Binary Tree Inorder Traversal](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- 力扣页面：[145. Binary Tree Postorder Traversal](https://leetcode.cn/problems/binary-tree-postorder-traversal/)

### 题目描述

不用递归，使用栈模拟二叉树遍历。

### 示例

```text
输入：root = [1,null,2,3]
前序输出：[1,2,3]
中序输出：[1,3,2]
后序输出：[3,2,1]
```

### 思路

栈可以模拟递归调用。前序比较直观；中序需要一路向左入栈；后序可以先按“中右左”遍历，再反转结果得到“左右中”。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        // 空树直接返回空数组。
        if (root == nullptr) return result;

        // 栈用来模拟递归调用过程。
        stack<TreeNode*> st;
        st.push(root);

        while (!st.empty()) {
            // 弹出当前要处理的节点。
            TreeNode* node = st.top();
            st.pop();
            result.push_back(node->val); // 前序：先处理中节点

            // 栈后进先出，所以先压右，再压左。
            // 这样下一次弹出的就是左节点，符合前序“中左右”。
            if (node->right) st.push(node->right);
            if (node->left) st.push(node->left);
        }

        return result;
    }

    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        // cur 负责向左一路探路，栈负责保存回溯路径。
        TreeNode* cur = root;

        while (cur != nullptr || !st.empty()) {
            // 先一路走到最左，并把沿途节点压栈。
            while (cur != nullptr) {
                st.push(cur);
                cur = cur->left;
            }

            // 左边走到底后，弹出中节点。
            cur = st.top();
            st.pop();
            result.push_back(cur->val);

            // 再处理右子树。
            // 如果右子树为空，下一轮会继续从栈里弹父节点。
            cur = cur->right;
        }

        return result;
    }

    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> result;
        // 空树直接返回空数组。
        if (root == nullptr) return result;

        stack<TreeNode*> st;
        st.push(root);

        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            result.push_back(node->val); // 先得到中右左

            // 为了得到“中右左”，入栈顺序要先左后右。
            if (node->left) st.push(node->left);
            if (node->right) st.push(node->right);
        }

        reverse(result.begin(), result.end()); // 反转为左右中
        return result;
    }
};
```

### 易错点

- 中序迭代中，`cur` 负责向下探路，`st` 负责回溯父节点。
- 后序反转法适合返回遍历数组，但如果题目要边遍历边判断，可能要写更严格的后序模拟。

## 二叉树的统一迭代法

### 题目链接

- 代码随想录：[二叉树的统一迭代法](https://programmercarl.com/二叉树的统一迭代法.html)
- 力扣页面：[94. Binary Tree Inorder Traversal](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

### 题目描述

使用统一写法完成前序、中序、后序迭代遍历。

### 示例

```text
输入：root = [1,null,2,3]
中序输出：[1,3,2]
```

### 思路

统一迭代法用 `nullptr` 标记“这个节点已经访问过，但还没有处理”。这样前中后序只需要调整入栈顺序。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        // 先把根节点压栈；空树则保持空栈。
        if (root != nullptr) st.push(root);

        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();

            if (node != nullptr) {
                // 中序是左中右。
                // 因为栈后进先出，所以入栈顺序要反过来：右、中、左。
                if (node->right) st.push(node->right);

                st.push(node);       // 中节点先放入栈
                st.push(nullptr);    // nullptr 标记：下次弹出时处理这个中节点

                if (node->left) st.push(node->left);
            } else {
                // 遇到 nullptr，说明下一个节点该真正处理了。
                // 这里的下一个节点，就是之前和 nullptr 配对放入的“中节点”。
                node = st.top();
                st.pop();
                result.push_back(node->val);
            }
        }

        return result;
    }
};
```

### 易错点

- `nullptr` 必须紧挨着被标记的节点入栈。
- 前序、中序、后序只改“右、中标记、左”的入栈顺序。

## 102 二叉树的层序遍历

### 题目链接

- 代码随想录：[102. 二叉树的层序遍历](https://programmercarl.com/0102.二叉树的层序遍历.html)
- 力扣页面：[102. Binary Tree Level Order Traversal](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

### 题目描述

给定一棵二叉树，返回其按层遍历的节点值。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
```

### 思路

层序遍历就是 BFS。队列里保存当前待处理的节点，每轮先记录当前队列大小 `size`，这个 `size` 就是当前层节点数。

### C++ 详细注释代码

```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        // 空树没有层序结果。
        if (root == nullptr) return result;

        queue<TreeNode*> que;
        // 根节点作为第 0 层入队。
        que.push(root);

        while (!que.empty()) {
            int size = que.size(); // 固定当前层节点数
            vector<int> level;

            // 本轮只处理当前层的 size 个节点。
            for (int i = 0; i < size; ++i) {
                TreeNode* node = que.front();
                que.pop();
                level.push_back(node->val);

                // 左右孩子属于下一层，放到队列尾部。
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }

            // 当前层处理完后加入结果。
            result.push_back(level);
        }

        return result;
    }
};
```

### 易错点

- 每层循环前要保存 `size`，不能在 `for` 条件里动态读 `que.size()`。
- 队列入队的是下一层节点。

## 226 翻转二叉树

### 题目链接

- 代码随想录：[226. 翻转二叉树](https://programmercarl.com/0226.翻转二叉树.html)
- 力扣页面：[226. Invert Binary Tree](https://leetcode.cn/problems/invert-binary-tree/)

### 题目描述

给定一棵二叉树，翻转它，使每个节点的左右孩子交换。

### 示例

```text
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

### 思路

每个节点都执行同一个动作：交换左右孩子。前序和后序都可以，中序容易因为交换后重复访问原左子树而写错。

### C++ 详细注释代码

```cpp
#include <algorithm>
using namespace std;

class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        // 空节点不需要翻转。
        if (root == nullptr) return nullptr;

        // 先交换当前节点的左右孩子。
        swap(root->left, root->right);

        // 再翻转交换后的左右子树。
        // 注意这里 root->left 已经是原来的右子树。
        invertTree(root->left);
        invertTree(root->right);

        // 返回翻转后的当前子树根节点。
        return root;
    }
};
```

### 易错点

- 中序写法容易重复处理同一侧子树。
- 这题是“每个节点做同一件事”，前序很好理解。

## 101 对称二叉树

### 题目链接

- 代码随想录：[101. 对称二叉树](https://programmercarl.com/0101.对称二叉树.html)
- 力扣页面：[101. Symmetric Tree](https://leetcode.cn/problems/symmetric-tree/)

### 题目描述

判断一棵二叉树是否轴对称。

### 示例

```text
输入：root = [1,2,2,3,4,4,3]
输出：true
```

```text
输入：root = [1,2,2,null,3,null,3]
输出：false
```

### 思路

对称不是比较一个节点的左右孩子，而是比较两棵子树的外侧和内侧：左子树的左 vs 右子树的右，左子树的右 vs 右子树的左。

### C++ 详细注释代码

```cpp
class Solution {
public:
    bool compare(TreeNode* left, TreeNode* right) {
        // 两边都为空，结构对称。
        if (left == nullptr && right == nullptr) return true;

        // 只有一边为空，结构不对称。
        if (left == nullptr || right == nullptr) return false;

        // 两边节点值不同，数值不对称。
        if (left->val != right->val) return false;

        // 外侧比较：左子树的左孩子 vs 右子树的右孩子。
        bool outside = compare(left->left, right->right);

        // 内侧比较：左子树的右孩子 vs 右子树的左孩子。
        bool inside = compare(left->right, right->left);

        return outside && inside;
    }

    bool isSymmetric(TreeNode* root) {
        // 空树可以认为是对称的。
        if (root == nullptr) return true;

        // 从根的左右子树开始成对比较。
        return compare(root->left, root->right);
    }
};
```

### 易错点

- 递归函数一次传两个节点。
- 不是比较 `root->left->val` 和 `root->right->val` 就结束，要递归比较外侧和内侧。

## 104 二叉树的最大深度

### 题目链接

- 代码随想录：[104. 二叉树的最大深度](https://programmercarl.com/0104.二叉树的最大深度.html)
- 力扣页面：[104. Maximum Depth of Binary Tree](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

### 题目描述

给定一棵二叉树，返回其最大深度。最大深度是从根节点到最远叶子节点路径上的节点数。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：3
```

### 思路

最大深度可以看成根节点高度。后序遍历先拿到左右子树高度，再取最大值加一。

### C++ 详细注释代码

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        // 空节点没有深度。
        if (root == nullptr) return 0;

        // 先求左子树最大深度。
        int leftDepth = maxDepth(root->left);

        // 再求右子树最大深度。
        int rightDepth = maxDepth(root->right);

        // 当前节点深度 = 左右子树较大深度 + 当前节点这一层。
        return max(leftDepth, rightDepth) + 1;
    }
};
```

### 易错点

- 空节点深度是 0。
- 求高度时天然是后序，因为要先知道左右子树高度。

## 111 二叉树的最小深度

### 题目链接

- 代码随想录：[111. 二叉树的最小深度](https://programmercarl.com/0111.二叉树的最小深度.html)
- 力扣页面：[111. Minimum Depth of Binary Tree](https://leetcode.cn/problems/minimum-depth-of-binary-tree/)

### 题目描述

给定一棵二叉树，返回其最小深度。最小深度是从根节点到最近叶子节点路径上的节点数。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：2
```

```text
输入：root = [2,null,3,null,4,null,5,null,6]
输出：5
```

### 思路

只有左右孩子都为空才是叶子。若某一侧为空，最小深度不能走空侧，必须走非空子树。

### C++ 详细注释代码

```cpp
class Solution {
public:
    int minDepth(TreeNode* root) {
        // 空节点深度为 0。
        if (root == nullptr) return 0;

        // 左子树为空，不能把左子树深度 0 当成最小路径。
        if (root->left == nullptr && root->right != nullptr) {
            return 1 + minDepth(root->right);
        }

        // 右子树为空，必须走左子树。
        if (root->right == nullptr && root->left != nullptr) {
            return 1 + minDepth(root->left);
        }

        // 左右子树都存在，才能取较小深度。
        return 1 + min(minDepth(root->left), minDepth(root->right));
    }
};
```

### 易错点

- 不能直接写 `min(left, right) + 1`，单边树会算错。
- 叶子节点必须左右孩子都为空。

## 222 完全二叉树的节点个数

### 题目链接

- 代码随想录：[222. 完全二叉树的节点个数](https://programmercarl.com/0222.完全二叉树的节点个数.html)
- 力扣页面：[222. Count Complete Tree Nodes](https://leetcode.cn/problems/count-complete-tree-nodes/)

### 题目描述

给定一棵完全二叉树，返回节点个数。

### 示例

```text
输入：root = [1,2,3,4,5,6]
输出：6
```

### 思路

普通二叉树计数要遍历全部节点。完全二叉树可以判断某棵子树是否是满二叉树：如果最左深度和最右深度相同，则节点数可用公式直接算。

### C++ 详细注释代码

```cpp
class Solution {
public:
    int countNodes(TreeNode* root) {
        // 空树节点数为 0。
        if (root == nullptr) return 0;

        // 分别沿最左链和最右链向下走。
        TreeNode* left = root->left;
        TreeNode* right = root->right;
        int leftDepth = 0;
        int rightDepth = 0;

        // 统计左边界深度。
        while (left != nullptr) {
            left = left->left;
            ++leftDepth;
        }

        // 统计右边界深度。
        while (right != nullptr) {
            right = right->right;
            ++rightDepth;
        }

        // 左右边界深度相同，说明这棵子树是满二叉树。
        if (leftDepth == rightDepth) {
            // 满二叉树节点数为 2^(高度+1)-1；
            // 这里 leftDepth 是从 root 的孩子开始数，所以写 2 << leftDepth。
            return (2 << leftDepth) - 1;
        }

        // 不是满二叉树，就递归统计左右子树，再加当前根节点。
        return countNodes(root->left) + countNodes(root->right) + 1;
    }
};
```

### 易错点

- 这套公式利用的是完全二叉树性质，普通二叉树不能这样判断。
- 这里从孩子开始数，所以写 `(2 << leftDepth) - 1`。

## 110 平衡二叉树

### 题目链接

- 代码随想录：[110. 平衡二叉树](https://programmercarl.com/0110.平衡二叉树.html)
- 力扣页面：[110. Balanced Binary Tree](https://leetcode.cn/problems/balanced-binary-tree/)

### 题目描述

判断一棵二叉树是否高度平衡。高度平衡指每个节点左右子树高度差不超过 1。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：true
```

```text
输入：root = [1,2,2,3,3,null,null,4,4]
输出：false
```

### 思路

后序遍历求高度。如果某棵子树已经不平衡，就返回 `-1` 作为标记，向上剪枝。

### C++ 详细注释代码

```cpp
#include <cmath>
using namespace std;

class Solution {
public:
    int getHeight(TreeNode* root) {
        // 空节点高度为 0。
        if (root == nullptr) return 0;

        // 后序：先求左子树高度。
        int leftHeight = getHeight(root->left);

        // 左子树已经不平衡，直接向上返回 -1 剪枝。
        if (leftHeight == -1) return -1;

        // 再求右子树高度。
        int rightHeight = getHeight(root->right);

        // 右子树已经不平衡，也直接返回 -1。
        if (rightHeight == -1) return -1;

        // 当前节点左右高度差超过 1，说明当前子树不平衡。
        if (abs(leftHeight - rightHeight) > 1) {
            return -1;
        }

        // 当前子树平衡，返回真实高度。
        return max(leftHeight, rightHeight) + 1;
    }

    bool isBalanced(TreeNode* root) {
        // getHeight 返回 -1 表示某处不平衡。
        return getHeight(root) != -1;
    }
};
```

### 易错点

- 平衡要看每个节点，不是只看根节点左右高度差。
- 返回值同时表达“高度”和“不平衡标记”。

## 257 二叉树的所有路径

### 题目链接

- 代码随想录：[257. 二叉树的所有路径](https://programmercarl.com/0257.二叉树的所有路径.html)
- 代码随想录：[二叉树中递归带着回溯](https://programmercarl.com/二叉树中递归带着回溯.html)
- 力扣页面：[257. Binary Tree Paths](https://leetcode.cn/problems/binary-tree-paths/)

### 题目描述

给定一棵二叉树，返回所有从根节点到叶子节点的路径。

### 示例

```text
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
```

### 思路

路径问题用前序遍历加回溯。先把当前节点放入路径，遇到叶子节点就收集路径，递归回来后撤销选择。

> [!note]
> “二叉树中递归带着回溯”补充的是路径题的本质：递归向下时把当前节点加入路径，递归返回时把当前节点从路径中弹出。只要路径容器是共享的，就必须撤销；如果每次递归都拷贝一份路径，逻辑上不用撤销，但空间开销更大。

### C++ 详细注释代码

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    void traversal(TreeNode* cur, vector<int>& path, vector<string>& result) {
        // 前序位置：先把当前节点加入路径。
        path.push_back(cur->val);

        // 叶子节点表示一条根到叶子的路径结束。
        if (cur->left == nullptr && cur->right == nullptr) {
            string s;
            for (int i = 0; i < path.size(); ++i) {
                // 把路径数字拼成 "1->2->5" 这种字符串。
                s += to_string(path[i]);
                if (i != path.size() - 1) s += "->";
            }
            result.push_back(s);
            return;
        }

        // 递归左子树，回来后撤销左孩子路径。
        if (cur->left) {
            traversal(cur->left, path, result);
            path.pop_back(); // 回溯左孩子
        }

        // 递归右子树，回来后撤销右孩子路径。
        if (cur->right) {
            traversal(cur->right, path, result);
            path.pop_back(); // 回溯右孩子
        }
    }

    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> result;
        vector<int> path;
        // 空树没有路径。
        if (root == nullptr) return result;
        traversal(root, path, result);
        return result;
    }
};
```

### 易错点

- 叶子节点是左右孩子都为空。
- `push` 和 `pop` 要成对出现。

## 404 左叶子之和

### 题目链接

- 代码随想录：[404. 左叶子之和](https://programmercarl.com/0404.左叶子之和.html)
- 力扣页面：[404. Sum of Left Leaves](https://leetcode.cn/problems/sum-of-left-leaves/)

### 题目描述

计算给定二叉树中所有左叶子节点的值之和。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：24
解释：左叶子有 9 和 15。
```

### 思路

当前节点自己无法判断自己是不是左叶子，必须由父节点判断：父节点的左孩子存在，并且这个左孩子没有左右孩子。

### C++ 详细注释代码

```cpp
class Solution {
public:
    int sumOfLeftLeaves(TreeNode* root) {
        // 空树没有左叶子。
        if (root == nullptr) return 0;

        // 当前节点直接贡献的左叶子值。
        int midValue = 0;

        // root->left 是左孩子，并且它是叶子节点。
        if (root->left != nullptr &&
            root->left->left == nullptr &&
            root->left->right == nullptr) {
            midValue = root->left->val;
        }

        // 当前节点贡献 + 左子树里的左叶子 + 右子树里的左叶子。
        return midValue + sumOfLeftLeaves(root->left) + sumOfLeftLeaves(root->right);
    }
};
```

### 易错点

- “左叶子”不是“左孩子”，左孩子还必须是叶子。
- 必须从父节点角度判断。

## 513 找树左下角的值

### 题目链接

- 代码随想录：[513. 找树左下角的值](https://programmercarl.com/0513.找树左下角的值.html)
- 力扣页面：[513. Find Bottom Left Tree Value](https://leetcode.cn/problems/find-bottom-left-tree-value/)

### 题目描述

给定一棵二叉树，找到最底层最左边节点的值。

### 示例

```text
输入：root = [2,1,3]
输出：1
```

```text
输入：root = [1,2,3,4,null,5,6,null,null,7]
输出：7
```

### 思路

层序遍历最直观：每层第一个节点就是这一层最左节点，遍历结束后保存的就是最底层最左值。

### C++ 详细注释代码

```cpp
#include <queue>
using namespace std;

class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> que;
        que.push(root);

        // result 保存每一层最左节点值，最终留下最底层的。
        int result = root->val;

        while (!que.empty()) {
            // 当前层节点数量，必须先固定。
            int size = que.size();

            for (int i = 0; i < size; ++i) {
                TreeNode* node = que.front();
                que.pop();

                // 每层第一个弹出的节点就是这一层最左节点。
                if (i == 0) {
                    result = node->val; // 当前层第一个节点
                }

                // 下一层节点从左到右入队。
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
        }

        return result;
    }
};
```

### 易错点

- 题目要的是最深一层最左边，不一定是某个节点的左孩子。
- 层序遍历时每层要固定 `size`。

## 112 路径总和

### 题目链接

- 代码随想录：[112. 路径总和](https://programmercarl.com/0112.路径总和.html)
- 力扣页面：[112. Path Sum](https://leetcode.cn/problems/path-sum/)

### 题目描述

判断树中是否存在一条从根节点到叶子节点的路径，使路径上所有节点值之和等于 `targetSum`。

### 示例

```text
输入：root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
输出：true
解释：路径 5->4->11->2 的和为 22。
```

### 思路

递归时不断从目标值中减去当前节点值。到达叶子节点时，如果剩余目标值正好等于叶子值，说明存在合法路径。

### C++ 详细注释代码

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        // 空节点不能构成根到叶子的路径。
        if (root == nullptr) return false;

        // 必须到叶子节点才能判断路径是否完整。
        if (root->left == nullptr && root->right == nullptr) {
            // 走到叶子时，剩余目标值正好等于叶子值才成功。
            return targetSum == root->val;
        }

        // 继续向左右子树找，同时从目标和中扣掉当前节点值。
        return hasPathSum(root->left, targetSum - root->val) ||
               hasPathSum(root->right, targetSum - root->val);
    }
};
```

### 易错点

- 必须是根到叶子的完整路径。
- 中途和等于目标值不能提前返回。

## 106 从中序与后序遍历序列构造二叉树

### 题目链接

- 代码随想录：[106. 从中序与后序遍历序列构造二叉树](https://programmercarl.com/0106.从中序与后序遍历序列构造二叉树.html)
- 力扣页面：[106. Construct Binary Tree from Inorder and Postorder Traversal](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/)

### 题目描述

给定中序遍历和后序遍历结果，构造并返回二叉树。

### 示例

```text
输入：inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出：[3,9,20,null,null,15,7]
```

### 思路

后序数组最后一个元素是根节点。在中序数组中找到根节点位置，就能切分左子树和右子树。递归构造时要统一区间定义。

### C++ 详细注释代码

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    TreeNode* build(vector<int>& inorder, int inLeft, int inRight,
                    vector<int>& postorder, int postLeft, int postRight,
                    unordered_map<int, int>& index) {
        // 后序区间为空，说明当前子树不存在。
        if (postLeft > postRight) return nullptr;

        int rootVal = postorder[postRight]; // 后序最后一个是根
        TreeNode* root = new TreeNode(rootVal);

        int rootIndex = index[rootVal];     // 根在中序数组中的位置
        int leftSize = rootIndex - inLeft;  // 左子树节点数

        // 中序左区间：[inLeft, rootIndex-1]
        // 后序左区间：[postLeft, postLeft+leftSize-1]
        root->left = build(inorder, inLeft, rootIndex - 1,
                           postorder, postLeft, postLeft + leftSize - 1,
                           index);

        // 中序右区间：[rootIndex+1, inRight]
        // 后序右区间：[postLeft+leftSize, postRight-1]
        root->right = build(inorder, rootIndex + 1, inRight,
                            postorder, postLeft + leftSize, postRight - 1,
                            index);

        return root;
    }

    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        unordered_map<int, int> index;
        // 用哈希表记录中序数组中每个值的位置，避免每层递归线性查找。
        for (int i = 0; i < inorder.size(); ++i) {
            index[inorder[i]] = i;
        }

        // 整体使用左闭右闭区间。
        return build(inorder, 0, inorder.size() - 1,
                     postorder, 0, postorder.size() - 1,
                     index);
    }
};
```

### 易错点

- 中序和后序无重复元素时才能唯一构造。
- 区间边界最容易错，建议统一左闭右闭。

## 654 最大二叉树

### 题目链接

- 代码随想录：[654. 最大二叉树](https://programmercarl.com/0654.最大二叉树.html)
- 力扣页面：[654. Maximum Binary Tree](https://leetcode.cn/problems/maximum-binary-tree/)

### 题目描述

给定一个不含重复元素的整数数组，用以下规则构造最大二叉树：根是数组最大值，左子树由最大值左边部分构造，右子树由最大值右边部分构造。

### 示例

```text
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
```

### 思路

每一层递归都在当前区间中找最大值作为根，再递归构造左右区间。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    TreeNode* construct(vector<int>& nums, int left, int right) {
        // 当前区间为空，返回空节点。
        if (left > right) return nullptr;

        // 在 [left,right] 中找最大值下标。
        int maxIndex = left;
        for (int i = left + 1; i <= right; ++i) {
            if (nums[i] > nums[maxIndex]) {
                maxIndex = i;
            }
        }

        // 最大值作为当前子树根节点。
        TreeNode* root = new TreeNode(nums[maxIndex]);

        // 最大值左边构造左子树。
        root->left = construct(nums, left, maxIndex - 1);

        // 最大值右边构造右子树。
        root->right = construct(nums, maxIndex + 1, right);
        return root;
    }

    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        // 初始处理整个数组区间。
        return construct(nums, 0, nums.size() - 1);
    }
};
```

### 易错点

- 递归函数要明确当前处理的数组区间。
- 朴素找最大值最坏时间复杂度 `O(n^2)`。

给定两棵二叉树，将它们合并。重叠节点的值相加，不重叠的位置直接使用非空节点。

```text
输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]

class Solution {
public:
    TreeNode* mergeTrees(TreeNode* root1, TreeNode* root2) {
        // root1 为空，合并结果就是 root2。
        if (root1 == nullptr) return root2;

        // root2 为空，合并结果就是 root1。
        if (root2 == nullptr) return root1;

        root1->val += root2->val;

        // 同步合并左右子树。
        root1->left = mergeTrees(root1->left, root2->left);
        root1->right = mergeTrees(root1->right, root2->right);

        return root1;
    }
};
```

### 易错点

- 复用原树会修改输入；如果要求不修改原树，需要新建节点。
- 两棵树要同步递归。

### 题目链接

- 代码随想录：[700. 二叉搜索树中的搜索](https://programmercarl.com/0700.二叉搜索树中的搜索.html)

### 题目描述

给定二叉搜索树和目标值 `val`，返回以目标节点为根的子树；如果不存在，返回 `nullptr`。

### 示例

```text
输入：root = [4,2,7,1,3], val = 2
输出：[2,1,3]
```

### 思路

利用 BST 性质：目标值小于当前节点就去左子树，大于当前节点就去右子树。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* searchBST(TreeNode* root, int val) {
        // 利用 BST 性质迭代查找，避免遍历整棵树。
        while (root != nullptr) {
            // 找到目标值，返回以该节点为根的整棵子树。
            if (root->val == val) return root;

            // 目标值更小，只可能在左子树。
            if (val < root->val) root = root->left;

            // 目标值更大，只可能在右子树。
            else root = root->right;
        }

        // 走到空节点，说明不存在目标值。
        return nullptr;
    }
};
```

### 易错点

- 普通二叉树不能这样剪枝，BST 才可以。
- 返回的是节点指针，不是布尔值。

### 题目链接

- 代码随想录：[98. 验证二叉搜索树](https://programmercarl.com/0098.验证二叉搜索树.html)
- 力扣页面：[98. Validate Binary Search Tree](https://leetcode.cn/problems/validate-binary-search-tree/)

### 题目描述

判断一棵二叉树是否是有效二叉搜索树。

### 示例

```text
输入：root = [2,1,3]
输出：true
```

```text
输入：root = [5,1,4,null,null,3,6]
输出：false
```

### 思路

BST 的中序遍历应该是严格递增序列。用 `pre` 记录中序遍历的前一个节点。

### C++ 详细注释代码

```cpp
class Solution {
public:
    // pre 记录中序遍历中当前节点的前一个节点。
    TreeNode* pre = nullptr;

    bool isValidBST(TreeNode* root) {
        // 空树是合法 BST。
        if (root == nullptr) return true;

        // 先验证左子树。
        if (!isValidBST(root->left)) return false;

        // 中序当前节点必须大于前一个节点。
        if (pre != nullptr && pre->val >= root->val) {
            return false;
        }

        // 更新 pre，让当前节点成为下一个节点的前驱。
        pre = root;

        // 再验证右子树。
        return isValidBST(root->right);
    }
};
```

### 易错点

- 不能只比较当前节点和左右孩子。
- LeetCode 98 要求严格递增，不允许重复值。

### 题目链接

- 代码随想录：[530. 二叉搜索树的最小绝对差](https://programmercarl.com/0530.二叉搜索树的最小绝对差.html)
- 力扣页面：[530. Minimum Absolute Difference in BST](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/)

### 题目描述

给定一棵二叉搜索树，返回任意两个不同节点值之间的最小绝对差。

### 示例

```text
输入：root = [4,2,6,1,3]
输出：1
```

### 思路

BST 中序遍历有序，最小差一定出现在中序相邻节点之间。

### C++ 详细注释代码

```cpp
#include <climits>
using namespace std;

class Solution {
public:
    int result = INT_MAX;    // 当前最小绝对差。
    TreeNode* pre = nullptr; // 中序遍历中的前一个节点。

    void traversal(TreeNode* root) {
        // 空节点直接返回。
        if (root == nullptr) return;

        // BST 中序遍历是升序。
        traversal(root->left);

        // 最小差只可能出现在中序相邻节点之间。
        if (pre != nullptr) {
            result = min(result, root->val - pre->val);
        }

        // 更新前一个节点。
        pre = root;

        traversal(root->right);
    }

    int getMinimumDifference(TreeNode* root) {
        // 遍历整棵 BST，过程中更新 result。
        traversal(root);
        return result;
    }
};
```

### 易错点

- 不需要两两比较所有节点。
- 利用 BST 中序相邻即可。

## 501 二叉搜索树中的众数

### 题目链接

- 代码随想录：[501. 二叉搜索树中的众数](https://programmercarl.com/0501.二叉搜索树中的众数.html)
- 力扣页面：[501. Find Mode in Binary Search Tree](https://leetcode.cn/problems/find-mode-in-binary-search-tree/)

### 题目描述

给定一棵含重复值的二叉搜索树，返回所有众数。

### 示例

```text
输入：root = [1,null,2,2]
输出：[2]
```

### 思路

BST 中序遍历后相同值会连续出现。用 `pre` 记录前一个节点，用 `count` 统计当前值连续次数，用 `maxCount` 记录最大次数。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> result;       // 存放所有众数。
    TreeNode* pre = nullptr;  // 中序遍历中的前一个节点。
    int count = 0;            // 当前值连续出现次数。
    int maxCount = 0;         // 目前发现的最大出现次数。

    void traversal(TreeNode* cur) {
        // 空节点直接返回。
        if (cur == nullptr) return;

        // BST 中序遍历会让相同值连续出现。
        traversal(cur->left);

        // 第一个节点，或者当前值和前一个值不同，重新计数。
        if (pre == nullptr || pre->val != cur->val) {
            count = 1;
        } else {
            // 当前值和前一个值相同，连续次数加一。
            ++count;
        }

        // 当前值出现次数等于最大次数，也是众数之一。
        if (count == maxCount) {
            result.push_back(cur->val);
        } else if (count > maxCount) {
            // 出现了更高频率，之前的众数都失效。
            maxCount = count;
            result.clear();
            result.push_back(cur->val);
        }

        // 更新 pre，供下一个中序节点比较。
        pre = cur;
        traversal(cur->right);
    }

    vector<int> findMode(TreeNode* root) {
        // 中序遍历整棵 BST，过程中维护 count/maxCount/result。
        traversal(root);
        return result;
    }
};
```

### 易错点

- 众数可能有多个。
- BST 中序连续性可以避免额外哈希表。

## 236 二叉树的最近公共祖先

### 题目链接

- 代码随想录：[236. 二叉树的最近公共祖先](https://programmercarl.com/0236.二叉树的最近公共祖先.html)
- 力扣页面：[236. Lowest Common Ancestor of a Binary Tree](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

### 题目描述

给定普通二叉树和两个节点 `p`、`q`，返回它们的最近公共祖先。

### 示例

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
```

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
```

### 思路

后序遍历。若左右子树分别找到 `p` 和 `q`，当前节点就是最近公共祖先；若只在一边找到，就把找到的节点向上返回。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // root 为空，说明当前子树找不到 p/q。
        // root 等于 p 或 q，说明当前节点本身就是目标之一，向上返回。
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        // 在左子树中寻找 p 或 q。
        TreeNode* left = lowestCommonAncestor(root->left, p, q);

        // 在右子树中寻找 p 或 q。
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        // 左右子树各找到一个目标，当前 root 就是最近公共祖先。
        if (left != nullptr && right != nullptr) {
            return root;
        }

        // 只在左边找到，就把左边结果向上返回。
        if (left != nullptr) return left;

        // 否则返回右边结果；右边也可能是 nullptr。
        return right;
    }
};
```

### 易错点

- 返回值含义是“当前子树里找到的目标节点或公共祖先”。
- 普通二叉树不能用 BST 大小关系。

## 235 二叉搜索树的最近公共祖先

### 题目链接

- 代码随想录：[235. 二叉搜索树的最近公共祖先](https://programmercarl.com/0235.二叉搜索树的最近公共祖先.html)
- 力扣页面：[235. Lowest Common Ancestor of a Binary Search Tree](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/)

### 题目描述

给定二叉搜索树和两个节点 `p`、`q`，返回它们的最近公共祖先。

### 示例

```text
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6
```

### 思路

利用 BST 性质。如果 `p`、`q` 都小于当前节点，就往左；都大于当前节点，就往右；否则当前节点就是分叉点。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 利用 BST 性质迭代寻找分叉点。
        while (root != nullptr) {
            // p 和 q 都小于 root，公共祖先一定在左子树。
            if (root->val > p->val && root->val > q->val) {
                root = root->left;
            } else if (root->val < p->val && root->val < q->val) {
                // p 和 q 都大于 root，公共祖先一定在右子树。
                root = root->right;
            } else {
                // p 和 q 分别在两侧，或者 root 本身就是 p/q，root 就是最近公共祖先。
                return root;
            }
        }

        // 正常题目保证 p/q 存在，一般不会走到这里。
        return nullptr;
    }
};
```

### 易错点

- BST 版本不用遍历整棵树。
- 分叉点就是最近公共祖先，也可能当前节点就是 `p` 或 `q`。

## 701 二叉搜索树中的插入操作

### 题目链接

- 代码随想录：[701. 二叉搜索树中的插入操作](https://programmercarl.com/0701.二叉搜索树中的插入操作.html)
- 力扣页面：[701. Insert into a Binary Search Tree](https://leetcode.cn/problems/insert-into-a-binary-search-tree/)

### 题目描述

给定二叉搜索树和要插入的值 `val`，将值插入 BST，并返回根节点。

### 示例

```text
输入：root = [4,2,7,1,3], val = 5
输出：[4,2,7,1,3,5]
```

### 思路

BST 插入一定可以插到叶子位置。递归找到空位置，新建节点，并把返回的子树接回父节点。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        // 找到空位置，新建节点作为当前子树根。
        if (root == nullptr) {
            return new TreeNode(val);
        }

        // val 更小，插入到左子树，并把插入后的左子树接回 root->left。
        if (val < root->val) {
            root->left = insertIntoBST(root->left, val);
        } else {
            // val 更大，插入到右子树。
            root->right = insertIntoBST(root->right, val);
        }

        // 返回当前子树根节点，供父节点接回。
        return root;
    }
};
```

### 易错点

- 递归返回值要接回 `root->left` 或 `root->right`。
- 不需要重构整棵树。

## 450 删除二叉搜索树中的节点

### 题目链接

- 代码随想录：[450. 删除二叉搜索树中的节点](https://programmercarl.com/0450.删除二叉搜索树中的节点.html)
- 力扣页面：[450. Delete Node in a BST](https://leetcode.cn/problems/delete-node-in-a-bst/)

### 题目描述

给定 BST 根节点和目标值 `key`，删除值为 `key` 的节点，并返回新的根节点。

### 示例

```text
输入：root = [5,3,6,2,4,null,7], key = 3
输出：[5,4,6,2,null,null,7]
```

### 思路

删除节点分情况：没找到、叶子、只有左子树、只有右子树、左右子树都存在。左右都存在时，可以把左子树挂到右子树最左节点下面，然后返回右子树作为新的根。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        // 没找到 key，返回空。
        if (root == nullptr) return nullptr;

        // 找到要删除的节点。
        if (root->val == key) {
            // 情况 1/2：左子树为空，右子树顶上来。
            if (root->left == nullptr) return root->right;

            // 情况 3：右子树为空，左子树顶上来。
            if (root->right == nullptr) return root->left;

            // 情况 4：左右子树都存在。
            // 找到右子树最左节点，也就是右子树中的最小节点。
            TreeNode* cur = root->right;
            while (cur->left != nullptr) {
                cur = cur->left;
            }

            // 把被删节点的左子树挂到右子树最小节点的左边。
            cur->left = root->left;

            // 用原右子树作为新的子树根。
            return root->right;
        }

        // key 更小，去左子树删除，并接回删除后的左子树。
        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else {
            // key 更大，去右子树删除。
            root->right = deleteNode(root->right, key);
        }

        // 返回当前子树根节点。
        return root;
    }
};
```

### 易错点

- 删除后要返回新的子树根节点。
- 左右子树都存在时，不能丢掉任何一边。

## 669 修剪二叉搜索树

### 题目链接

- 代码随想录：[669. 修剪二叉搜索树](https://programmercarl.com/0669.修剪二叉搜索树.html)
- 力扣页面：[669. Trim a Binary Search Tree](https://leetcode.cn/problems/trim-a-binary-search-tree/)

### 题目描述

给定 BST 和范围 `[low, high]`，修剪树，使所有节点值都在范围内，并保持 BST 性质。

### 示例

```text
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
```

### 思路

如果当前节点值小于 `low`，它的左子树也都小于当前节点，直接去右子树找；如果当前节点值大于 `high`，直接去左子树找。

### C++ 详细注释代码

```cpp
class Solution {
public:
    TreeNode* trimBST(TreeNode* root, int low, int high) {
        // 空树修剪后仍为空。
        if (root == nullptr) return nullptr;

        // 当前节点太小，且左子树所有节点更小，整棵左侧都不要。
        if (root->val < low) {
            return trimBST(root->right, low, high);
        }

        // 当前节点太大，且右子树所有节点更大，整棵右侧都不要。
        if (root->val > high) {
            return trimBST(root->left, low, high);
        }

        // 当前节点在范围内，递归修剪左右子树并接回。
        root->left = trimBST(root->left, low, high);
        root->right = trimBST(root->right, low, high);
        return root;
    }
};
```

### 易错点

- 利用 BST 性质可以整段剪掉。
- 返回值代表修剪后的子树根节点。

## 108 将有序数组转换为二叉搜索树

### 题目链接

- 代码随想录：[108. 将有序数组转换为二叉搜索树](https://programmercarl.com/0108.将有序数组转换为二叉搜索树.html)
- 力扣页面：[108. Convert Sorted Array to Binary Search Tree](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

### 题目描述

给定升序数组，将它转换为高度平衡二叉搜索树。

### 示例

```text
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
```

### 思路

每次取数组中点作为根节点，左半部分构造左子树，右半部分构造右子树。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    TreeNode* build(vector<int>& nums, int left, int right) {
        // 区间为空，返回空节点。
        if (left > right) return nullptr;

        // 选择中点作为根，保证左右子树规模尽量接近。
        int mid = left + (right - left) / 2;
        TreeNode* root = new TreeNode(nums[mid]);

        // 左半区间构造左子树。
        root->left = build(nums, left, mid - 1);

        // 右半区间构造右子树。
        root->right = build(nums, mid + 1, right);
        return root;
    }

    TreeNode* sortedArrayToBST(vector<int>& nums) {
        // 初始处理整个数组。
        return build(nums, 0, nums.size() - 1);
    }
};
```

### 易错点

- 取左中位或右中位都可以。
- 中点作为根能保证左右子树规模接近。

## 538 把二叉搜索树转换为累加树

### 题目链接

- 代码随想录：[538. 把二叉搜索树转换为累加树](https://programmercarl.com/0538.把二叉搜索树转换为累加树.html)
- 力扣页面：[538. Convert BST to Greater Tree](https://leetcode.cn/problems/convert-bst-to-greater-tree/)

### 题目描述

给定 BST，将每个节点的值更新为原树中大于等于该节点值的所有节点值之和。

### 示例

```text
输入：root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]
```

### 思路

BST 中序是升序。累加树需要先访问更大的值，所以按右、中、左的反中序遍历，用 `pre` 保存已经累加过的和。

### C++ 详细注释代码

```cpp
class Solution {
public:
    int pre = 0; // 保存比当前节点更大的节点累加和

    void traversal(TreeNode* cur) {
        // 空节点直接返回。
        if (cur == nullptr) return;

        // 反中序：先访问更大的右子树。
        traversal(cur->right);

        // 当前节点新值 = 原值 + 所有更大节点的累加和。
        cur->val += pre;

        // 更新累加和，给后面更小的节点使用。
        pre = cur->val;

        // 最后访问更小的左子树。
        traversal(cur->left);
    }

    TreeNode* convertBST(TreeNode* root) {
        // 遍历过程中原地修改节点值。
        traversal(root);
        return root;
    }
};
```

### 易错点

- 遍历顺序是右、中、左，不是普通中序。
- `pre` 保存的是已经累加过的更大值之和。

## 总结篇

### 题目链接

- 代码随想录：[二叉树总结篇](https://programmercarl.com/二叉树总结篇.html)
- 力扣页面：无。这是专题总结，不是单独力扣题。

### 题型速记

| 题型 | 关键词 | 常用套路 |
|---|---|---|
| 遍历 | 前中后序、层序 | 递归、栈、队列 |
| 深度高度 | 最大/最小/平衡 | 后序返回高度 |
| 路径 | 根到叶子 | 前序 + 回溯 |
| 构造树 | 中序后序、最大树 | 找根 + 切区间 |
| BST | 搜索、验证、最小差、众数 | 中序有序、大小剪枝 |
| 公共祖先 | 普通树/BST | 后序回溯 / BST 分叉 |
| BST 修改 | 插入、删除、修剪 | 返回新子树根 |

### 面试总表达

我做二叉树题会先判断当前题是不是要依赖左右子树返回值：如果依赖，优先后序；如果当前节点要先做决策，优先前序；如果是 BST，先想中序有序和大小剪枝；如果题目按层描述，直接用队列层序遍历。

## 周总结精华

### 复盘重点

| 复盘点 | 记忆方式 |
|---|---|
| 递归遍历 | 前序是“先处理自己”，中序常用于 BST，后序是“先拿左右结果” |
| 迭代遍历 | 栈模拟递归，统一迭代法用空指针标记“该处理节点了” |
| 层序遍历 | 队列 BFS，每一层先固定 `size`，不要边入队边改变本层范围 |
| 深度/高度 | 求深度常前序带参数，求高度常后序返回值 |
| 路径问题 | 进入节点加入路径，离开节点撤销路径，叶子节点收集答案 |
| 构造二叉树 | 找根节点，再切左右子树区间，递归返回当前子树根 |
| BST | 中序有序是第一反应；插入、删除、修剪都要返回新子树根 |

### 最容易混的点

- 最大深度和高度写法不同：深度偏“从上往下数”，高度偏“从下往上返回”。
- 二叉树路径题只在叶子节点收集路径，普通中间节点不能提前收集。
- BST 删除节点时，删除后当前子树根可能变化，所以函数返回值不能丢。
