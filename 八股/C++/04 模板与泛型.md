# C++ 模板与泛型

## template typename T 是什么

### 简要回答

`template <typename T>` 是 C++ 模板机制的起点，表示后面的类或函数不是写死某一种类型，而是可以接收一种“类型参数”。

```cpp
template <typename T>
class Foo {
public:
    T value;
};
```

使用时：

```cpp
Foo<int> a;
Foo<string> b;
```

### 面试表达

模板的核心价值是泛型复用：同一套逻辑可以适配不同类型，编译器会根据使用的类型生成对应代码。

## 函数模板和类模板

### 函数模板

函数模板用于让一个函数适配不同类型。

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}

int x = add<int>(1, 2);
double y = add<double>(1.1, 2.2);
```

很多时候模板参数可以由编译器自动推导：

```cpp
auto z = add(1, 2); // T 推导为 int
```

### 类模板

类模板用于让一个类适配不同类型。

```cpp
template <typename T>
class Box {
public:
    T value;
};

Box<int> a;
Box<string> b;
```

### 面试表达

函数模板解决“同一个函数逻辑适配不同类型”的问题；类模板解决“同一种数据结构或类逻辑适配不同类型”的问题。比如 `std::vector<int>` 和 `std::vector<string>` 本质上就是同一个模板类的不同实例。

## 模板参数有哪些类型

模板参数常见分为两类：

1. 类型模板参数：传入的是一种类型。
2. 非类型模板参数：传入的是一个编译期常量值。

```cpp
template <typename T>
class A {};

template <int N>
class B {};
```

`T` 是类型参数，使用时写 `A<int>`、`A<string>`；`N` 是非类型参数，使用时写 `B<10>`、`B<1024>`。

## template int N 是什么

### 简要回答

`template <int N>` 表示模板接收的不是类型，而是一个 `int` 类型的**编译期常量值**。

```cpp
template <int N>
class Array {
private:
    int data[N];

public:
    int size() const {
        return N;
    }
};

Array<10> a;
Array<100> b;
```

这里的 `N` 在编译期就确定，所以可以用于数组长度、循环展开、模板选择等场景。

### 和 template typename T 的区别

| 写法 | 参数含义 | 使用示例 | 传入内容 |
|---|---|---|---|
| `template <typename T>` | 类型模板参数 | `Box<int>` | 类型 |
| `template <int N>` | 非类型模板参数 | `Array<10>` | 编译期整数常量 |

### 为什么 N 必须是编译期常量

因为模板是在编译期实例化的。编译器看到 `Array<10>` 时，会生成一份 `N = 10` 的类；看到 `Array<100>` 时，会生成另一份 `N = 100` 的类。
✅ **`const`≠ 编译期常量**​
✅ **`constexpr`= 编译期常量**

```cpp
int n = 10;
// Array<n> arr; // 错，n 是运行时变量

constexpr int m = 10;
Array<m> arr; // 对，m 是编译期常量
```

### 常见用途

1. 固定大小数组。
2. 固定容量容器。
3. 编译期计算。
4. 矩阵维度、缓冲区大小、线程池固定参数等。
5. 和 `std::array<T, N>` 类似的类型设计。

```cpp
template <typename T, int N>
class FixedArray {
private:
    T data[N];

public:
    T& operator[](int index) {
        return data[index];
    }

    int size() const {
        return N;
    }
};

FixedArray<int, 5> nums;
FixedArray<double, 3> scores;
```

### 面试表达

`template <int N>` 是非类型模板参数，它把“值”也纳入模板参数，让一些信息在编译期固定下来。这样可以让类型携带大小信息，比如 `FixedArray<int, 10>` 和 `FixedArray<int, 20>` 是两个不同类型。

## typename 和 class 在模板参数里的区别

### 简要回答

在声明类型模板参数时，`typename` 和 `class` 大多数情况下等价。

```cpp
template <typename T>
void f(T value) {}

template <class T>
void g(T value) {}
```

上面两个都表示 `T` 是一个类型参数，不代表只能传 `class` 定义的类型，也可以传 `int`、`double`、`struct` 等。

### 易错点

`template <class T>` 中的 `class` 只是模板语法里的历史写法，不是访问权限里的 `class`，也不是要求 T 必须是类。

## std list T 指针成员变量

```cpp
std::list<T *> m_workqueue;
```

逐词拆解：

| 部分 | 含义 |
|---|---|
| `std::list` | 标准库双向链表容器 |
| `T *` | 元素类型是 `T` 的指针 |
| `m_workqueue` | 成员变量名，常表示工作队列 |

### 放在线程池里怎么理解

如果 `T` 是 `http_conn`，那么：

```cpp
std::list<http_conn*> m_workqueue;
```

意思是队列中保存很多 `http_conn` 对象的指针，线程池从队列里取出一个连接任务去处理。

## 线程池为什么适合写成模板

### 写死版本

```cpp
class threadpool {
public:
    void append(http_conn* task);
};
```

问题：

- 只能处理 `http_conn*`。
- 不能复用给其他任务类型。
- 项目一变，线程池就要改。

### 模板版本

```cpp
template <typename T>
class threadpool {
public:
    void append(T task);
};
```

可以实例化成：

```cpp
threadpool<http_conn*>
threadpool<Task*>
threadpool<std::function<void()>>
```

### 工程表达

线程池的本质是“接收任务、排队、唤醒线程、执行任务”。任务具体是什么类型，不应该由线程池写死。所以用模板可以把线程池做成更通用的基础组件。

## 模板常见易错点

- 模板不是运行时多态，而是编译期生成代码。
- 模板类的定义通常要放在头文件中，否则其他编译单元实例化时可能找不到定义。
- `typename T` 和 `class T` 在模板类型参数里大多数时候等价。
- `template <int N>` 里的 `N` 必须是编译期常量，不能传普通运行时变量。
- 不同模板实参会生成不同类型，例如 `Array<10>` 和 `Array<20>` 不是同一种类型。

## 面试速背

1. 模板让类型参数化，解决代码复用问题。
2. `template <typename T>` 表示后续代码里可以使用类型参数 `T`。
3. `template <int N>` 表示非类型模板参数，`N` 是编译期整数常量。
4. `std::list<T*>` 是一个双向链表，里面每个元素是 `T` 类型指针。
5. 线程池写成模板，是为了不把任务类型写死。
