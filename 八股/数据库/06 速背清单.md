# 数据库速背清单

返回：[[数据库导航]]

## 基础概念

- [[01 基础概念#SQL 是什么|SQL]]：结构化查询语言，用来操作关系型数据库。
- [[01 基础概念#常见 SQL 语句有哪些|常见 SQL]]：查询、连接、聚合、增删改、索引相关语句都要会看。
- [[01 基础概念#SQL 查询执行过程是什么|SQL 执行流程]]：连接器 -> 查询缓存 -> 解析预处理 -> 优化器 -> 执行器 -> 存储引擎。
- [[01 基础概念#事务 ACID 是什么|ACID]]：原子性、一致性、隔离性、持久性；一致性是目标，其余是手段。
- [[01 基础概念#事务隔离级别有哪些|隔离级别]]：读未提交、读已提交、可重复读、串行化；InnoDB 默认通常是可重复读。
- [[01 基础概念#事务隔离级别有哪些|并发问题]]：脏读、不可重复读、幻读。
- [[01 基础概念#表之间有哪些关系|表关系]]：一对一、一对多、多对多；多对多通常用中间表。
- [[01 基础概念#主键、外键和约束是什么|主键外键约束]]：主键标识一行，外键表示表关系，约束保证数据合法性。

## 索引

- [[02 索引#索引是什么|索引]]：帮助数据库快速定位数据的数据结构，类似书目录。
- [[02 索引#常见索引有哪些|索引种类]]：B+ 树、哈希、全文；主键、唯一、普通、联合；聚簇、非聚簇。
- [[02 索引#为什么 MySQL 常用 B+ 树|B+ 树优势]]：高扇出、树低、磁盘 I/O 少；叶子链表适合范围查询。
- [[02 索引#为什么 MySQL 常用 B+ 树|B 树 vs B+ 树]]：B 树非叶子也存数据，B+ 树数据集中在叶子，叶子链表范围扫更强。
- [[02 索引#什么时候适合建索引|适合建索引]]：高选择性、常在 `where/join/order by/group by` 中出现的列。
- [[02 索引#什么时候适合建索引|不适合建索引]]：小表、低区分度、频繁更新少查询、大字段。
- [[02 索引#索引失效场景有哪些|索引失效]]：跳过最左前缀、函数操作列、`like '%xx'`、隐式类型转换、`or` 使用不当。
- [[02 索引#聚簇索引和非聚簇索引有什么区别|聚簇索引]]：InnoDB 主键索引叶子存数据行；二级索引叶子通常存主键值，可能回表。

## 进阶机制

- [[03 进阶机制#MVCC 是什么|MVCC]]：多版本并发控制，读历史版本减少读写阻塞，依赖 undo log 和 Read View。
- [[03 进阶机制#数据库锁有哪些|数据库锁]]：表锁、行锁、共享锁、排他锁、意向锁、间隙锁、临键锁。
- [[03 进阶机制#乐观锁和悲观锁有什么区别|乐观锁和悲观锁]]：悲观锁先锁再改，乐观锁提交时用版本号检查冲突。
- [[03 进阶机制#行锁、表锁、间隙锁是什么|行锁表锁间隙锁]]：表锁粒度大，行锁并发高，间隙锁防范围插入导致幻读。
- [[03 进阶机制#慢查询怎么排查|慢查询排查]]：慢查询日志 + `EXPLAIN`，看索引、扫描行数、排序、临时表、JOIN 顺序。

## MySQL 深入

- [[04 MySQL深入#MySQL 执行引擎是什么|MySQL 分层]]：Server 层负责解析优化执行，存储引擎负责具体数据读写。
- [[04 MySQL深入#MySQL 常见存储引擎有哪些|存储引擎]]：InnoDB 支持事务、行锁、外键、崩溃恢复；MyISAM 不支持事务；Memory 数据在内存。
- [[04 MySQL深入#redo log、undo log、binlog 有什么区别|redo log]]：InnoDB 重做日志，保证崩溃恢复和持久性。
- [[04 MySQL深入#redo log、undo log、binlog 有什么区别|undo log]]：回滚日志，支持事务回滚和 MVCC 历史版本。
- [[04 MySQL深入#redo log、undo log、binlog 有什么区别|binlog]]：Server 层二进制日志，用于主从复制和恢复。
- [[04 MySQL深入#redo log、undo log、binlog 有什么区别|两阶段提交]]：`redo prepare -> binlog -> redo commit`，保证 redo 和 binlog 一致。
- [[04 MySQL深入#SQL 注入是什么，怎么防范|SQL 注入]]：恶意输入改变 SQL 语义；用预编译、参数绑定、最小权限防范。

## Redis

- [[05 Redis#Redis 常见数据结构有哪些|Redis 数据结构]]：String、Hash、List、Set、ZSet。
- [[05 Redis#Redis 过期策略有哪些|过期策略]]：惰性删除 + 定期删除；TTL 到了不代表立刻物理删除。
- [[05 Redis#Redis 淘汰策略有哪些|淘汰策略]]：内存满了删谁，如 LRU、LFU、random、ttl、noeviction。
- [[05 Redis#RDB 和 AOF 有什么区别|RDB]]：快照持久化，文件小、恢复快，但可能丢最近数据。
- [[05 Redis#RDB 和 AOF 有什么区别|AOF]]：写命令追加日志，更完整但文件大、恢复慢；生产常见 `everysec`。
- [[05 Redis#缓存雪崩、穿透、击穿有什么区别|缓存穿透]]：查不存在数据；参数校验、缓存空值、布隆过滤器。
- [[05 Redis#缓存雪崩、穿透、击穿有什么区别|缓存击穿]]：热点 key 过期；互斥锁、逻辑过期、热点预热。
- [[05 Redis#缓存雪崩、穿透、击穿有什么区别|缓存雪崩]]：大量 key 同时失效或 Redis 不可用；随机 TTL、高可用、多级缓存、限流降级。
- [[05 Redis#Redis 分布式锁怎么实现|Redis 分布式锁]]：`SET lockKey requestId NX PX 30000`，释放锁要校验 value 并用 Lua 保证原子性。
- [[05 Redis#布隆过滤器是什么|布隆过滤器]]：位数组 + 多哈希；可能误判存在，但不会误判不存在，常防缓存穿透。
- [[05 Redis#Redis 主从同步怎么实现|Redis 主从同步]]：从节点发 `PSYNC`，主节点根据 `replid + offset` 决定全量或增量同步。
