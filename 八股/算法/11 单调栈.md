## 单调栈核心模型

### 题目链接

- 代码随想录：[单调栈专题](https://programmercarl.com/0739.每日温度.html)
- 力扣页面：无。这一节是方法总结，不是单独力扣题。

### 简要回答

单调栈通常解决“找某个元素左边/右边第一个比它大或比它小的元素”。栈里常存下标，因为下标既能取值，也能计算距离和宽度。

### 判断方向

| 需求 | 常见栈形态 | 弹栈时机 |
|---|---|---|
| 右边第一个更大 | 单调递减栈 | 当前值大于栈顶值 |
| 右边第一个更小 | 单调递增栈 | 当前值小于栈顶值 |
| 接雨水 | 递减栈 | 当前柱子高于栈顶，形成右边界 |
| 柱状图最大矩形 | 递增栈 | 当前柱子低于栈顶，形成右侧更矮边界 |

### 面试表达

我会先说明栈里存的是下标，再说明栈维护什么单调性。弹栈时，当前元素通常就是“右边第一个打破单调性的元素”，栈顶弹出后新的栈顶常常就是左边界。

## 739 每日温度

### 题目链接

- 代码随想录：[739. 每日温度](https://programmercarl.com/0739.每日温度.html)
- 力扣页面：[739. Daily Temperatures](https://leetcode.cn/problems/daily-temperatures/)

### 题目描述

给定每日温度数组 `temperatures`，返回一个数组 `answer`，其中 `answer[i]` 表示第 `i` 天之后要等多少天才会有更高温度。如果之后没有更高温度，则为 0。

### 示例

```text
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
```

```text
输入：temperatures = [30,40,50,60]
输出：[1,1,1,0]
```

### 思路

找每个位置右边第一个更高温度。栈里存下标，维护从栈底到栈顶对应温度递减。当前温度比栈顶温度高时，说明当前下标就是栈顶下标等待的更高温度。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        vector<int> result(temperatures.size(), 0);
        stack<int> st; // 存下标，不存温度，方便计算天数差。

        for (int i = 0; i < temperatures.size(); ++i) {
            // 当前温度更高，说明它是栈顶那一天右边第一个更高温度。
            while (!st.empty() && temperatures[i] > temperatures[st.top()]) {
                int index = st.top();
                st.pop();

                // i - index 就是等待天数。
                result[index] = i - index;
            }

            // 当前天还没找到右边更高温度，先入栈等待。
            st.push(i);
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 栈里存下标比存值更通用。
- 没找到更高温度的位置默认就是 0。
- 每个下标最多入栈一次、出栈一次，所以总时间是 `O(n)`。

## 496 下一个更大元素 I

### 题目链接

- 代码随想录：[496. 下一个更大元素 I](https://programmercarl.com/0496.下一个更大元素I.html)
- 力扣页面：[496. Next Greater Element I](https://leetcode.cn/problems/next-greater-element-i/)

### 题目描述

`nums1` 是 `nums2` 的子集，两个数组元素都不重复。对 `nums1` 中每个元素，找到它在 `nums2` 中右边第一个更大的元素；如果不存在，返回 `-1`。

### 示例

```text
输入：nums1 = [4,1,2], nums2 = [1,3,4,2]
输出：[-1,3,-1]
```

```text
输入：nums1 = [2,4], nums2 = [1,2,3,4]
输出：[3,-1]
```

### 思路

先在 `nums2` 上用单调栈求出每个元素的下一个更大元素，并存入哈希表。再遍历 `nums1` 查表。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        // nextGreater[x] 表示 x 在 nums2 中的下一个更大元素。
        unordered_map<int, int> nextGreater;

        // 单调栈保持从栈底到栈顶递减。
        stack<int> st; // 本题元素唯一，栈里直接存元素值也可以。

        for (int x : nums2) {
            // 当前 x 比栈顶大，说明 x 是栈顶元素右边第一个更大值。
            while (!st.empty() && x > st.top()) {
                nextGreater[st.top()] = x;
                st.pop();
            }

            // x 暂时还没找到下一个更大元素。
            st.push(x);
        }

        vector<int> result;
        for (int x : nums1) {
            // nums1 是 nums2 子集，直接查预处理表。
            if (nextGreater.count(x)) {
                result.push_back(nextGreater[x]);
            } else {
                // 没查到说明 x 右侧没有更大元素。
                result.push_back(-1);
            }
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n + m)` |
| 空间 | `O(n)` |

### 易错点

- 本题元素唯一，所以可以用值作为哈希表 key。
- 如果数组有重复元素，通常要存下标。

## 503 下一个更大元素 II

### 题目链接

- 代码随想录：[503. 下一个更大元素 II](https://programmercarl.com/0503.下一个更大元素II.html)
- 力扣页面：[503. Next Greater Element II](https://leetcode.cn/problems/next-greater-element-ii/)

### 题目描述

给定一个循环数组 `nums`，返回每个元素的下一个更大元素。如果不存在，返回 `-1`。循环数组表示最后一个元素的下一个元素是第一个元素。

### 示例

```text
输入：nums = [1,2,1]
输出：[2,-1,2]
```

```text
输入：nums = [1,2,3,4,3]
输出：[2,3,4,-1,4]
```

### 思路

循环数组可以遍历两遍，用 `i % n` 映射回真实下标。第一遍正常入栈，第二遍只用于补答案，不再重复入栈。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        // 默认所有位置都没有下一个更大元素。
        vector<int> result(n, -1);
        stack<int> st; // 存下标。

        for (int i = 0; i < 2 * n; ++i) {
            // 通过取模模拟循环数组。
            int index = i % n;

            // 当前值 nums[index] 是一些栈顶元素的下一个更大值。
            while (!st.empty() && nums[index] > nums[st.top()]) {
                result[st.top()] = nums[index];
                st.pop();
            }

            // 只在第一轮入栈，第二轮只负责帮助第一轮元素找答案。
            if (i < n) {
                st.push(index);
            }
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 第二轮不要再把下标压栈。
- 结果初始为 `-1`，找不到更大元素的不用额外处理。

## 42 接雨水

### 题目链接

- 代码随想录：[42. 接雨水](https://programmercarl.com/0042.接雨水.html)
- 力扣页面：[42. Trapping Rain Water](https://leetcode.cn/problems/trapping-rain-water/)

### 题目描述

给定非负整数数组 `height`，每个数表示柱子的高度，计算这些柱子能接多少雨水。

### 示例

```text
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
```

```text
输入：height = [4,2,0,3,2,5]
输出：9
```

### 思路

单调栈按“横向层”计算雨水。栈里维护递减高度。当前柱子比栈顶高时，说明出现了右边界；弹出的柱子是凹槽底部，弹出后新的栈顶是左边界。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

class Solution {
public:
    int trap(vector<int>& height) {
        int result = 0;
        stack<int> st; // 存柱子下标，方便计算宽度。

        for (int i = 0; i < height.size(); ++i) {
            // 当前柱子比栈顶柱子高，可能形成接水区域。
            while (!st.empty() && height[i] > height[st.top()]) {
                int mid = st.top(); // mid 是凹槽底部。
                st.pop();

                // 没有左边界，就无法接水。
                if (st.empty()) break;

                int left = st.top(); // 弹出 mid 后，新的栈顶是左边界。

                // 宽度不包含左右边界，所以是 i - left - 1。
                int width = i - left - 1;

                // 水的高度由左右边界较矮者决定，再减去底部高度。
                int waterHeight = min(height[left], height[i]) - height[mid];

                result += width * waterHeight;
            }

            st.push(i);
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 弹出的 `mid` 是底部，不是边界。
- 弹出后新的栈顶才是左边界，当前 `i` 是右边界。
- 宽度是 `i - left - 1`。

## 84 柱状图中最大的矩形

### 题目链接

- 代码随想录：[84. 柱状图中最大的矩形](https://programmercarl.com/0084.柱状图中最大的矩形.html)
- 力扣页面：[84. Largest Rectangle in Histogram](https://leetcode.cn/problems/largest-rectangle-in-histogram/)

### 题目描述

给定柱状图高度数组 `heights`，每个柱子宽度为 1，求能形成的最大矩形面积。

### 示例

```text
输入：heights = [2,1,5,6,2,3]
输出：10
解释：高度 5 和 6 组成宽度 2 的矩形，面积为 10。
```

```text
输入：heights = [2,4]
输出：4
```

### 思路

对每个柱子，假设它是矩形高度，那么最大宽度由它左右两侧第一个更矮柱子决定。维护递增栈，当前柱子更矮时，弹出的柱子就找到了右侧第一个更矮柱子，弹出后新的栈顶是左侧第一个更矮柱子。

### C++ 详细注释代码

```cpp
#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        // 首尾补 0：
        // 开头 0 保证左边界存在；
        // 结尾 0 强制所有柱子最终都能被弹出计算。
        heights.insert(heights.begin(), 0);
        heights.push_back(0);

        int result = 0;
        stack<int> st;
        st.push(0);

        for (int i = 1; i < heights.size(); ++i) {
            // 当前柱子比栈顶矮，说明栈顶柱子的右侧更矮边界找到了。
            while (!st.empty() && heights[i] < heights[st.top()]) {
                int mid = st.top(); // mid 是当前用来当矩形高度的柱子。
                st.pop();

                int left = st.top(); // 弹出后，新的栈顶是左侧第一个更矮柱子。

                // 宽度不包含左右两个更矮边界。
                int width = i - left - 1;

                int area = heights[mid] * width;
                result = max(result, area);
            }

            st.push(i);
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 首尾补 0 可以减少边界特殊处理。
- 接雨水找更高边界，柱状图找更矮边界，二者栈的触发条件不同。
- 宽度是 `i - left - 1`。
