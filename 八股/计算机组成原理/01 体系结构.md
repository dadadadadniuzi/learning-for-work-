## 冯·诺依曼体系结构是什么

### 简要回答

冯·诺依曼体系结构把程序指令和数据统一存放在同一个存储器中，由 CPU 按顺序取指、译码、执行。

### 五大组成

1. 运算器
2. 控制器
3. 存储器
4. 输入设备
5. 输出设备

### 面试表达

> 冯·诺依曼结构的核心是“存储程序”，也就是程序和数据都放在存储器里，CPU 从存储器取指令并执行。

### 详细回答

冯·诺依曼体系结构最核心的思想是**存储程序**：程序和数据以同等地位存入存储器，计算机从程序首地址开始取指令并执行，之后按照程序规定的顺序继续执行，直到程序结束。

主要特点：

- 指令和数据都存放在同一个存储器中。
- 指令和数据都按地址访问。
- 计算机内部采用二进制表示指令和数据。
- 指令通常由操作码和地址码组成。
- 操作码表示做什么操作，地址码表示操作数在哪里。

## 哈佛体系结构是什么

### 简要回答

哈佛体系结构把指令存储器和数据存储器分开，指令和数据可以走不同通路。

### 详细回答

这样做的好处是指令读取和数据访问可以并行，减少冲突；缺点是结构更复杂，灵活性不如统一存储。

### 主要特点

- 指令存储器和数据存储器分离。
- 指令和数据各自有独立总线。
- CPU 可以在同一时钟周期内同时读取指令和访问数据。
- 并行性更好，但硬件复杂度更高。

## 冯·诺依曼结构和哈佛结构有什么区别

### 简要回答

冯·诺依曼结构指令和数据共用存储空间，哈佛结构指令和数据分开存储。

### 对比表

| 对比点 | 冯·诺依曼结构 | 哈佛结构 |
|---|---|---|
| 指令和数据 | 共用存储器 | 分开存储 |
| 通路 | 共用总线 | 指令和数据通路分离 |
| 灵活性 | 高 | 相对低 |
| 并行性 | 可能受总线限制 | 更容易并行 |
| 硬件复杂度 | 相对较低 | 相对较高 |
| 典型特点 | 存储程序，统一编址 | 指令和数据可并行访问 |

## 存储程序思想是什么

### 简要回答

存储程序思想是把程序指令像数据一样存入存储器，计算机按指令序列自动执行。

### 面试表达

> 有了存储程序思想，计算机不需要为每个任务重新改硬件，只要加载不同程序，就能执行不同任务。

## 指令、数据与存储器是什么关系

### 简要回答

在冯·诺依曼体系结构中，指令和数据都以二进制形式存放在存储器里，CPU 根据执行阶段和取用方式区分它们。

### 详细回答

同一串二进制，在不同上下文中可以被解释为指令，也可以被解释为数据。CPU 在取指阶段把从内存取出的内容当作指令，在执行阶段可能再根据指令中的地址码去读取操作数。

### 面试表达

> 指令和数据在存储形式上都是二进制，本质区别不在存储器里，而在 CPU 如何解释它们。

## 现代计算机补充

### 简要回答

现代计算机大体仍以冯·诺依曼结构为基础，通常由主机和外部设备组成。

### 详细回答

- CPU 和主存储器通常合称为主机。
- I/O 设备称为外部设备。
- CPU 负责取指、译码、执行。
- 主存储器保存正在运行的程序和数据。
