### 做法速记

- 有多少小于当前数字的数字：排序后记录每个数字第一次出现的位置，或用计数数组做前缀和。
- 有效的山脉数组：双指针从左右向山顶走，最后左右指针相遇且不能在两端。
- 独一无二的出现次数：哈希统计频率，再用集合判断频率是否重复。
- 移动零：快慢指针把非零元素前移，剩余位置补 0。
- 旋转数组：整体反转，再分别反转前 `k` 和后 `n-k` 段。
- 中心索引：维护左和、总和，判断 `left == sum - left - nums[i]`。
- 查找首尾位置：两次二分，分别找左边界和右边界。
- 按奇偶排序数组 II：偶数指针找错位偶位，奇数指针找错位奇位，然后交换。
- 搜索插入位置：标准二分，找第一个 `>= target` 的位置。

### 代表题：移动零

这题是快慢指针“原地稳定过滤”的代表。先把所有非零元素按原顺序放到前面，再把剩余位置补 `0`。

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int slow = 0;

        // slow 之前都是已经放好的非零元素。
        for (int fast = 0; fast < nums.size(); ++fast) {
            if (nums[fast] != 0) {
                nums[slow++] = nums[fast];
            }
        }

        // 后半段补 0。
        while (slow < nums.size()) {
            nums[slow++] = 0;
        }
    }
};
```

### 代表题：查找首尾位置

边界二分最稳的写法是写一个 `lowerBound`：找第一个 `>= target` 的位置。右边界可以通过找第一个 `> target`，也就是 `lowerBound(target + 1)`。

```cpp
class Solution {
public:
    int lowerBound(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size(); // 左闭右开区间 [left, right)

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return left;
    }

    vector<int> searchRange(vector<int>& nums, int target) {
        int start = lowerBound(nums, target);
        int end = lowerBound(nums, target + 1) - 1;

        if (start == nums.size() || nums[start] != target) {
            return {-1, -1};
        }
        return {start, end};
    }
};
```

## 链表额外题

| 题目 | 来源 |

| 环形链表 | [programmercarl](https://programmercarl.com/0141.环形链表.html) |
| 相交链表 | [programmercarl](https://programmercarl.com/0160.相交链表.html) |

### 做法速记

- 两两交换链表：虚拟头节点，按 `pre -> a -> b` 改成 `pre -> b -> a`。
- 回文链表：快慢指针找中点，反转后半段，再前后比较。
- 重排链表：找中点、反转后半段、两条链表交替合并。
- 环形链表：快慢指针是否相遇。
- 相交链表：双指针分别走 A+B 和 B+A，最终相遇即交点。

### 代表题：回文链表

链表不能随机访问，所以常用“快慢指针找中点 + 反转后半段 + 前后比较”。

```cpp
class Solution {
public:
    ListNode* reverse(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* cur = head;

        while (cur != nullptr) {
            ListNode* next = cur->next;
            cur->next = pre;
            pre = cur;
            cur = next;
        }

        return pre;
    }

    bool isPalindrome(ListNode* head) {
        if (head == nullptr || head->next == nullptr) return true;

        ListNode* slow = head;
        ListNode* fast = head;

        // slow 到达中点附近。
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        ListNode* right = reverse(slow);
        ListNode* left = head;

        while (right != nullptr) {
            if (left->val != right->val) return false;
            left = left->next;
            right = right->next;
        }

        return true;
    }
};
```

### 代表题：比较含退格的字符串

从后往前扫描可以避免真正构造字符串。`skip` 表示当前还要跳过几个普通字符。

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int getNextValidIndex(const string& s, int index) {
        int skip = 0;

        while (index >= 0) {
            if (s[index] == '#') {
                ++skip;
                --index;
            } else if (skip > 0) {
                --skip;
                --index;
            } else {
                break;
            }
        }

        return index;
    }

    bool backspaceCompare(string s, string t) {
        int i = s.size() - 1;
        int j = t.size() - 1;

        while (i >= 0 || j >= 0) {
            i = getNextValidIndex(s, i);
            j = getNextValidIndex(t, j);

            if (i < 0 || j < 0) return i == j;
            if (s[i] != t[j]) return false;

            --i;
            --j;
        }

        return true;
    }
};
```

## 二叉树额外题

| 题目 | 来源 |
|---|---|
| 求根到叶子节点数字之和 | [programmercarl](https://programmercarl.com/0129.求根到叶子节点数字之和.html) |
| 将二叉搜索树变平衡 | [programmercarl](https://programmercarl.com/1382.将二叉搜索树变平衡.html) |
| 相同的树 | [programmercarl](https://programmercarl.com/0100.相同的树.html) |
| 填充每个节点的下一个右侧节点指针 | [programmercarl](https://programmercarl.com/0116.填充每个节点的下一个右侧节点指针.html) |

### 做法速记

- 根到叶子数字之和：前序遍历携带当前数字 `sum = sum * 10 + val`，叶子处累加。
- BST 变平衡：中序遍历得到有序数组，再用中点递归构造平衡 BST。
- 相同的树：同步递归比较两个节点是否都空、值是否相等、左右子树是否相同。
- 填充 next 指针：层序遍历每层连接，完美二叉树也可用已建立的 next 指针横向连接。

### 代表题：根到叶子节点数字之和

路径题常见写法是递归参数携带“到当前节点为止的状态”。当前节点值加入方式是 `sum = sum * 10 + val`。

```cpp
class Solution {
public:
    int dfs(TreeNode* node, int sum) {
        if (node == nullptr) return 0;

        // 把当前节点接到路径数字末尾。
        sum = sum * 10 + node->val;

        // 叶子节点形成一条完整数字路径。
        if (node->left == nullptr && node->right == nullptr) {
            return sum;
        }

        return dfs(node->left, sum) + dfs(node->right, sum);
    }

    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);
    }
};
```

## 动态规划额外题

| 题目 | 来源 |
|---|---|
| 最长回文子串 | [programmercarl](https://programmercarl.com/0005.最长回文子串.html) |
| 分割回文串II | [programmercarl](https://programmercarl.com/0132.分割回文串II.html) |
| 最长递增子序列的个数 | [programmercarl](https://programmercarl.com/0673.最长递增子序列的个数.html) |

### 做法速记

- 最长回文子串：中心扩展或区间 DP，记录最长起点和长度。
- 分割回文串 II：先预处理 `isPal[i][j]`，再做最少切割 DP。
- 最长递增子序列的个数：`dp[i]` 记录长度，`count[i]` 记录达到该长度的方案数。

### 代表题：最长回文子串

中心扩展比区间 DP 更直观。每个位置都可能是奇数长度中心，也可能和右边位置一起作为偶数长度中心。

```cpp
#include <string>
using namespace std;

class Solution {
public:
    pair<int, int> expand(const string& s, int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            --left;
            ++right;
        }

        // 退出时 [left + 1, right - 1] 才是有效回文区间。
        return {left + 1, right - 1};
    }

    string longestPalindrome(string s) {
        int start = 0;
        int maxLen = 0;

        for (int i = 0; i < s.size(); ++i) {
            auto [l1, r1] = expand(s, i, i);
            auto [l2, r2] = expand(s, i, i + 1);

            if (r1 - l1 + 1 > maxLen) {
                start = l1;
                maxLen = r1 - l1 + 1;
            }

            if (r2 - l2 + 1 > maxLen) {
                start = l2;
                maxLen = r2 - l2 + 1;
            }
        }

        return s.substr(start, maxLen);
    }
};
```

## 图论和并查集额外题

| 单词接龙 | [programmercarl](https://programmercarl.com/0127.单词接龙.html) |
| 冗余连接 | [programmercarl](https://programmercarl.com/0684.冗余连接.html) |

### 做法速记

- 钥匙和房间：从 0 号房间 DFS/BFS，最后看是否访问全部房间。
- 单词接龙：BFS，每次改一个字符，第一次到达终点就是最短长度。
- 冗余连接：无向图并查集，第一条连接同集合的边就是冗余边。
- 冗余连接 II：有向图先处理入度为 2，再判断是否成环。

### 代表题：钥匙和房间

本质是有向图可达性。从 `0` 号房间出发，把拿到的钥匙当作可走的边。

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void dfs(vector<vector<int>>& rooms, vector<bool>& visited, int room) {
        visited[room] = true;

        for (int key : rooms[room]) {
            if (!visited[key]) {
                dfs(rooms, visited, key);
            }
        }
    }

    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        vector<bool> visited(rooms.size(), false);
        dfs(rooms, visited, 0);

        for (bool ok : visited) {
            if (!ok) return false;
        }
        return true;
    }
};
```

## 模拟和位运算额外题

| 题目 | 来源 |
|---|---|
| 机器人能否返回原点 | [programmercarl](https://programmercarl.com/0657.机器人能否返回原点.html) |
| 下一个排列 | [programmercarl](https://programmercarl.com/0031.下一个排列.html) |
| 岛屿的周长 | [programmercarl](https://programmercarl.com/0463.岛屿的周长.html) |
| 根据数字二进制下 1 的数目排序 | [programmercarl](https://programmercarl.com/1356.根据数字二进制下1的数目排序.html) |

### 做法速记

- 机器人能否返回原点：统计上下左右位移，最终坐标为 `(0,0)`。
- 下一个排列：从后找第一对升序，再从后找比它大的数交换，最后反转后缀。
- 岛屿周长：每个陆地贡献 4，和相邻陆地共享一条边就减 1。
- 按二进制 1 的数目排序：自定义排序，先比 `__builtin_popcount(x)`，再比数值。

### 代表题：下一个排列

下一个排列的目标是“刚好变大一点”。从后往前找第一对升序，是为了让被修改的位置尽量靠右；再用后缀里刚好比它大的数交换，最后反转后缀变成最小。

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int i = nums.size() - 2;

        // 找从右往左第一处 nums[i] < nums[i + 1]。
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            --i;
        }

        if (i >= 0) {
            int j = nums.size() - 1;

            // 后缀是降序的，从右往左第一个大于 nums[i] 的数就是刚好更大的数。
            while (j > i && nums[j] <= nums[i]) {
                --j;
            }

            swap(nums[i], nums[j]);
        }

        // 把后缀改成升序，让整体增幅最小。
        reverse(nums.begin() + i + 1, nums.end());
    }
};
```
