# C++ 速背清单

返回：[[C++导航]]

## 基础语法

- [[01 基础与语法#C++ 三大特性|C++ 三大特性]]：封装、继承、多态。
- [[03 指针引用与数组#指针和引用的区别|指针和引用]]：指针保存地址，可为空可改指向；引用是别名，通常不能为空且不能改绑。
- [[01 基础与语法#struct 和 class 的区别|struct 和 class]]：语法能力几乎一样，默认权限不同，`struct` 默认 `public`，`class` 默认 `private`。
- [[01 基础与语法#struct 和 union 的区别|struct 和 union]]：`struct` 成员独立存储；`union` 共享同一块内存。
- [[01 基础与语法#sizeof 和 strlen 的区别|sizeof 和 strlen]]：`sizeof` 看类型字节数，`strlen` 数到 `\0` 前字符数。
- [[01 基础与语法#浮点数比较方法|浮点数比较]]：多数情况下不用 `==`，固定范围用绝对误差，大范围计算常结合相对误差。
- [[01 基础与语法#C++ 四种类型转换|四种类型转换]]：`static_cast` 常规转换，`dynamic_cast` 安全向下转型，`const_cast` 改限定符，`reinterpret_cast` 底层重解释。

## 面向对象

- [[02 类与对象#构造函数和析构函数|构造和析构]]：构造负责初始化，析构负责释放资源；构造函数不能是虚函数，析构函数很多基类应写成虚函数。
- [[02 类与对象#构造函数有几种|构造函数种类]]：默认、参数化、拷贝、移动、委托、继承构造。
- [[02 类与对象#重载 重写和隐藏|重载和重写]]：重载是同作用域同名不同参，编译期决定；重写是子类重写父类虚函数，运行时决定。
- [[02 类与对象#C++ 如何实现多态|多态]]：运行时多态的核心是 `virtual + 继承 + 基类指针/引用 + 子类重写`。
- [[02 类与对象#虚函数和纯虚函数|虚函数和纯虚函数]]：虚函数可有默认实现；纯虚函数写成 `= 0`，通常让类变成抽象类。
- [[02 类与对象#虚函数表和虚函数指针|虚函数表]]：对象里的 `vptr` 指向类的 `vtable`，通过虚表做动态绑定。
- [[02 类与对象#多重继承和菱形继承|多重继承和菱形继承]]：多重继承表达力强，但布局复杂；菱形继承通常用虚继承解决。
- [[02 类与对象#如何禁止一个类被继承|禁止继承]]：现代 C++ 直接用 `final`。
- [[02 类与对象#深拷贝和浅拷贝|深拷贝和浅拷贝]]：浅拷贝复制地址，深拷贝复制资源副本；裸资源类要警惕 `double free`。
- [[02 类与对象#this 指针|this 指针]]：`this` 是非静态成员函数的隐藏参数，`*this` 是当前对象本身。
- [[02 类与对象#单例模式|单例模式]]：现代 C++ 首选 C++11 的 `Magic Static`。

## 模板与 STL

- [[04 模板与泛型#template typename T 是什么|template<typename T>]]：类型模板参数。
- [[04 模板与泛型#template int N 是什么|template<int N>]]：非类型模板参数，传的是编译期常量。
- [[04 模板与泛型#std list T 指针成员变量|std::list<T*>]]：双向链表里存放 `T*` 类型元素。
- [[04 模板与泛型#线程池为什么适合写成模板|线程池模板化]]：任务类型不写死，复用性更强。
- [[09 STL与容器|STL 主线]]：先按容器分类、`vector`、`map/unordered_map`、`rehash`、`allocator` 这条线复习。
- [[09 STL与容器#STL 中 allocator 的作用|allocator]]：把原始内存分配释放和对象构造析构分离开，容器因此能切换不同内存策略。
- [[09 STL与容器#STL 中迭代器失效的场景|迭代器失效]]：容器结构变化后旧迭代器可能失效；`vector` 扩容和 `unordered_map` 的 `rehash` 触发后是高频坑，删除遍历时优先接 `erase` 返回值。
- [[09 STL与容器#map 和 unordered_map 的区别与实现原理|map 和 unordered_map]]：`map` 是红黑树，天然有序，复杂度稳定 `O(log n)`；`unordered_map` 是哈希表，平均 `O(1)`，但冲突严重时最坏会退化到 `O(n)`。
- [[09 STL与容器#map deque list 的底层实现原理|map / deque / list]]：`map` 是红黑树，`deque` 是分段连续空间，`list` 是双向链表；`deque` 头尾操作强，`list` 中间插删强，`map` 适合有序键值场景。

## 关键字与类型推导

- [[05 关键字与类型推导#static 关键字|static]]：控制生命周期和可见性。
- [[05 关键字与类型推导#const 关键字|const]]：控制可修改性，表达只读语义。
- [[05 关键字与类型推导#extern C 的作用|extern "C"]]：禁止 C++ 名称修饰，方便和 C 语言二进制链接。
- [[05 关键字与类型推导#volatile 关键字|volatile]]：防止编译器把特殊访问乱优化，不是线程同步工具。
- [[05 关键字与类型推导#inline 函数和宏的区别|inline 和宏]]：能用函数解决的优先用 `inline/constexpr`，宏更适合条件编译和 `#`、`##`。
- [[05 关键字与类型推导#auto 和 decltype 的区别|auto 和 decltype]]：`auto` 省类型名，`decltype` 精确拿表达式类型。

## 生命周期与静态

- [[06 内存生命周期与静态成员#局部变量 全局变量 静态局部变量|局部变量、静态局部变量、全局变量]]：作用域、生命周期、初始化行为和存储位置不同。
- [[06 内存生命周期与静态成员#静态成员变量必须类外定义|静态成员变量类外定义]]：类内通常只是声明，类外才是真正定义。
- [[06 内存生命周期与静态成员#new 对象和 new 数组|new 对象和 new 数组]]：`new[]` 配 `delete[]`，`new` 配 `delete`。
- [[06 内存生命周期与静态成员#饿汉式单例中的静态成员初始化|饿汉式静态成员初始化]]：`Singleton::instance` 类外定义仍可访问私有构造，通常在 `main` 前初始化。
