# C++ 指针引用与数组

## 指针和引用的区别

### 简要回答

指针是一个变量，里面存地址；引用是变量的别名，定义后必须绑定对象，通常不能再改绑。

| 对比点 | 指针 | 引用 |
|---|---|---|
| 本质 | 保存地址的变量 | 已有对象的别名 |
| 是否可为空 | 可以为 `nullptr` | 一般不能为空 |
| 是否可改绑 | 可以改指向 | 初始化后不能改绑 |
| 使用方式 | `*p` 解引用 | 直接当原对象用 |
| 常见用途 | 动态对象、可选对象、数组遍历 | 参数传递、返回值别名 |

## const 和指针的组合

### 1. `const int *p`

`const` 修饰指针指向的对象。

```cpp
const int* p = &a;
*p = 10; // 错，不能通过 p 修改对象
p = &b;  // 对，可以改变 p 的指向
```

也可以写成：

```cpp
int const* p;
```

### 2. `int *const p`

`const` 修饰指针本身。

```cpp
int* const p = &a;
*p = 10; // 对，可以改对象
p = &b;  // 错，不能改变 p 的指向
```

### 3. `const int *const p`

指针本身和指向对象都不能改。

```cpp
const int* const p = &a;
*p = 10; // 错
p = &b;  // 错
```

### 速记

看 `const` 离谁近：靠近 `*` 左边的类型，通常限制指向的对象；在 `*` 右边，限制指针本身。

## 二级指针

### 简要回答

`int **pp` 是指向指针的指针。

```cpp
int a = 5;
int* p = &a;
int** pp = &p;
```

此时：

- `p` 是 `a` 的地址。
- `*p` 是 `a` 的值，也就是 `5`。
- `pp` 是 `p` 的地址。
- `*pp` 是 `p` 的值，也就是 `a` 的地址。
- `**pp` 是 `a` 的值，也就是 `5`。

## 指针引用

### 简要回答

`int* &k` 是“对 int 指针的引用”，也就是某个指针变量的别名。

```cpp
int a = 5;
int* p = &a;
int*& k = p;
```

此时：

- `k` 和 `p` 是同一个指针变量。
- `k == p == &a`。
- `*k == 5`。

### 使用场景

当函数里需要修改外部指针本身的指向时，可以使用指针引用。

```cpp
void reset(int*& p, int* q) {
    p = q;
}
```

## 指针数组

`int* arr[]` 是指针数组，数组里每个元素都是 `int*`。

```cpp
int a = 1;
int b = 2;
int* arr[] = {&a, &b};
```

注意它不是“数组指针”。数组指针的写法是：

```cpp
int (*p)[3];
```

## 字符指针数组和 cout 输出

```cpp
const int MAX = 4;
const char* names[MAX] = {
    "Zara Ali",
    "Hina Ali",
    "Nuha Ali",
    "Sara Ali",
};
```

### 输出规则

```cpp
cout << names[0];        // Zara Ali
cout << *names[0];       // Z
cout << *(names[0] + 1); // a
```

### 为什么 `cout << names[0]` 不输出地址

因为 `names[0]` 的类型是 `const char*`，`ostream` 对字符指针做了特殊重载，会把它当作 C 字符串输出，直到遇到 `\0`。

### 易错纠正

如果写 `cout << names[1]`，输出的是第二个字符串 `Hina Ali`，不是 `Zara Ali`。数组下标从 0 开始，`names[0]` 才是 `Zara Ali`。

## 指针相减规则

### 简要回答

同一个数组或同一段连续内存中的两个指针可以相减，结果是它们之间相差的元素个数，不是字节数。

```cpp
const char* file_name = "/var/log/server.log";
const char* p = strrchr(file_name, '/');

cout << (p - file_name) << endl; // 8
```

### 为什么是 8

字符串下标如下：

```text
/ v a r / l o g / s e r v e r . l o g
0 1 2 3 4 5 6 7 8
```

最后一个 `/` 的下标是 8，所以 `p - file_name == 8`。

### 易错点

你原来记的 `9` 容易把最后一个 `/` 后面的 `s` 也算进去。指针指向的是 `/` 本身，所以差值是 `/` 的下标 8。

## 数组为什么不能事后整体赋值

### 简要回答

C/C++ 中数组不是可修改的左值，不支持创建后再整体赋值。

```cpp
int a[3];
a = {1, 2, 3}; // 错
```

### 正确方式

初始化时赋值：

```cpp
int a[3] = {1, 2, 3};
```

逐个元素赋值：

```cpp
a[0] = 1;
a[1] = 2;
a[2] = 3;
```

使用 `std::array`：

```cpp
std::array<int, 3> a;
a = {1, 2, 3}; // 对
```

## 面试速背

1. 指针保存地址，引用是别名。
2. `const int* p` 不能通过 p 改值，但 p 可以改指向。
3. `int* const p` 可以通过 p 改值，但 p 不能改指向。
4. `int**` 是指向指针的指针。
5. `int*&` 是指针变量的引用。
6. `int* arr[]` 是指针数组。
7. 字符指针用 `cout` 输出时会被当作 C 字符串。
8. 指针相减得到元素个数。
