## 哈希表理论基础

### 题目链接

- 代码随想录：[哈希表理论基础](https://programmercarl.com/哈希表理论基础.html)
- 力扣页面：无。这一节是基础概念，不是单独力扣题。

### 简要回答

哈希表是根据关键码直接访问数据的数据结构。它通过哈希函数把 `key` 映射到数组下标，常用于快速判断元素是否出现过、统计次数、保存元素对应下标。

### 常见结构

| 结构 | 底层 | 是否有序 | 是否去重 | 常见用途 |
|---|---|---|---|---|
| `set` | 红黑树 | 有序 | 去重 | 需要有序集合 |
| `unordered_set` | 哈希表 | 无序 | 去重 | 快速判断存在 |
| `map` | 红黑树 | 有序 | key 去重 | 有序 key-value |
| `unordered_map` | 哈希表 | 无序 | key 去重 | 快速查次数、下标 |
| 数组 | 连续内存 | 下标有序 | 由自己控制 | key 范围小，如 26 个字母 |

### 面试表达

哈希表适合快速判断一个元素是否出现过。key 范围小，比如小写字母，就用数组；只查存在性用 `unordered_set`；既要查存在又要保存下标或次数，就用 `unordered_map`。

## 242 有效的字母异位词

### 题目链接

- 代码随想录：[242. 有效的字母异位词](https://programmercarl.com/0242.有效的字母异位词.html)
- 力扣页面：[242. Valid Anagram](https://leetcode.cn/problems/valid-anagram/)

### 题目描述

给定两个字符串 `s` 和 `t`，判断 `t` 是否是 `s` 的字母异位词。字母异位词表示两个字符串中字母出现次数完全相同，只是顺序不同。

### 示例

```text
输入：s = "anagram", t = "nagaram"
输出：true
```

```text
输入：s = "rat", t = "car"
输出：false
```

### 思路

题目只包含小写字母，字符范围固定为 26 个，所以用数组比哈希表更轻。遍历 `s` 时对应字符次数加一，遍历 `t` 时减一，最后所有计数都为 0，说明两个字符串字符频率一致。

### C++ 详细注释代码

```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool isAnagram(string s, string t) {
        // record[i] 表示字符 'a' + i 出现次数的差值。
        int record[26] = {0};

        // s 中出现的字符加一。
        for (char c : s) {
            // c - 'a' 把字符映射到 0..25 的数组下标。
            ++record[c - 'a'];
        }

        // t 中出现的字符减一。
        for (char c : t) {
            // 如果 t 和 s 字符频率一致，最终会抵消回 0。
            --record[c - 'a'];
        }

        // 如果两个字符串字符频率完全相同，每个位置都应该回到 0。
        for (int i = 0; i < 26; ++i) {
            if (record[i] != 0) {
                return false;
            }
        }

        return true;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n + m)` |
| 空间 | `O(1)`，数组大小固定为 26 |

### 易错点

- 本题是小写字母，可以用数组；如果字符集很大，再考虑 `unordered_map`。
- 只比较长度不够，必须比较每个字符出现次数。

## 349 两个数组的交集

### 题目链接

- 代码随想录：[349. 两个数组的交集](https://programmercarl.com/0349.两个数组的交集.html)
- 力扣页面：[349. Intersection of Two Arrays](https://leetcode.cn/problems/intersection-of-two-arrays/)

### 题目描述

给定两个整数数组 `nums1` 和 `nums2`，返回它们的交集。结果中的每个元素必须唯一，顺序不限。

### 示例

```text
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]
```

```text
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
```

### 思路

交集要求去重，所以用 `unordered_set`。先把 `nums1` 放进集合，再遍历 `nums2`，如果元素在集合中出现过，就放进结果集合。

### C++ 详细注释代码

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        // numsSet 保存 nums1 中出现过的元素，自动去重。
        unordered_set<int> numsSet(nums1.begin(), nums1.end());

        // resultSet 保存交集，使用 set 是为了避免结果重复。
        unordered_set<int> resultSet;

        for (int num : nums2) {
            // 如果 num 在 nums1 中出现过，就属于交集。
            if (numsSet.find(num) != numsSet.end()) {
                resultSet.insert(num);
            }
        }

        // 把集合转成 vector 返回。
        return vector<int>(resultSet.begin(), resultSet.end());
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | 平均 `O(n + m)` |
| 空间 | `O(n + k)` |

### 易错点

- 结果必须去重，不能直接把每次命中的元素都 push 到数组。
- 如果数值范围很小，也可以用数组做哈希。

## 202 快乐数

### 题目链接

- 代码随想录：[202. 快乐数](https://programmercarl.com/0202.快乐数.html)
- 力扣页面：[202. Happy Number](https://leetcode.cn/problems/happy-number/)

### 题目描述

对一个正整数，每次把它替换为各位数字平方和。如果最终能变成 1，这个数就是快乐数；如果陷入循环且永远到不了 1，就不是快乐数。

### 示例

```text
输入：n = 19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1
```

```text
输入：n = 2
输出：false
```

### 思路

如果计算过程中重复出现某个数字，就说明进入循环，不可能再到 1。用 `unordered_set` 记录出现过的数字。

### C++ 详细注释代码

```cpp
#include <unordered_set>
using namespace std;

class Solution {
public:
    int getSum(int n) {
        int sum = 0; // 当前数字各位平方和。

        while (n > 0) {
            int digit = n % 10;      // 取个位数字。
            sum += digit * digit;    // 累加该位平方。
            n /= 10;                 // 去掉个位。
        }

        return sum;
    }

    bool isHappy(int n) {
        // seen 记录已经出现过的中间结果，用来判断是否进入循环。
        unordered_set<int> seen;

        while (true) {
            // 计算 n 的下一轮数字。
            int sum = getSum(n);

            // 能到 1 就是快乐数。
            if (sum == 1) {
                return true;
            }

            // sum 之前出现过，说明进入循环。
            if (seen.find(sum) != seen.end()) {
                return false;
            }

            // 记录当前中间值，然后继续迭代。
            seen.insert(sum);
            n = sum;
        }
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | 与迭代次数和数字位数有关，通常可看作较小常数 |
| 空间 | 与出现过的中间值数量有关 |

### 易错点

- 不是判断原始 `n` 是否重复，而是判断每次计算出的 `sum` 是否重复。
- 可以用快慢指针判断循环，但哈希集合更直观。

## 1 两数之和

### 题目链接

- 代码随想录：[1. 两数之和](https://programmercarl.com/0001.两数之和.html)
- 力扣页面：[1. Two Sum](https://leetcode.cn/problems/two-sum/)

### 题目描述

给定整数数组 `nums` 和整数目标值 `target`，在数组中找出和为 `target` 的两个数，并返回它们的数组下标。每个输入只对应一个答案，同一个元素不能使用两次。

### 示例

```text
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：nums[0] + nums[1] = 2 + 7 = 9。
```

```text
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

### 思路

遍历数组时，对于当前值 `nums[i]`，需要找之前是否出现过 `target - nums[i]`。因此用 `unordered_map` 保存“元素值 -> 下标”。

### C++ 详细注释代码

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // key 是数组元素值，value 是该元素下标。
        unordered_map<int, int> map;

        for (int i = 0; i < nums.size(); ++i) {
            // complement 是当前 nums[i] 需要的另一个数。
            int complement = target - nums[i];

            // 如果之前见过 complement，说明 complement + nums[i] == target。
            auto iter = map.find(complement);
            if (iter != map.end()) {
                // iter->second 是 complement 的下标，i 是当前元素下标。
                return {iter->second, i};
            }

            // 当前元素暂时没找到搭档，把它存起来，供后面的元素查找。
            map[nums[i]] = i;
        }

        // 题目保证有答案，正常不会走到这里。
        return {};
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | 平均 `O(n)` |
| 空间 | `O(n)` |

### 易错点

- 要先查找，再插入当前元素，避免同一个元素被用两次。
- `unordered_map` 存下标，不是只存是否存在。

## 454 四数相加 II

### 题目链接

- 代码随想录：[454. 四数相加 II](https://programmercarl.com/0454.四数相加II.html)
- 力扣页面：[454. 4Sum II](https://leetcode.cn/problems/4sum-ii/)

### 题目描述

给定四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，计算有多少个元组 `(i,j,k,l)` 满足：

```text
nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0
```

### 示例

```text
输入：
nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出：2
解释：
1 + (-2) + (-1) + 2 = 0
2 + (-1) + (-1) + 0 = 0
```

### 思路

把四个数组拆成两组。先统计 `nums1 + nums2` 每个和出现的次数，再枚举 `nums3 + nums4`，查找它的相反数出现过几次。

### C++ 详细注释代码

```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int fourSumCount(vector<int>& nums1, vector<int>& nums2,
                     vector<int>& nums3, vector<int>& nums4) {
        // key 是 nums1[i] + nums2[j] 的和，value 是这个和出现的次数。
        unordered_map<int, int> countAB;

        for (int a : nums1) {
            for (int b : nums2) {
                // 相同的 a+b 可能由多组下标产生，所以要累加次数。
                ++countAB[a + b];
            }
        }

        int result = 0;

        for (int c : nums3) {
            for (int d : nums4) {
                // 需要 A+B == -(C+D)。
                int target = 0 - (c + d);

                // 如果 A+B 中存在 target，那么 target + c + d == 0。
                auto iter = countAB.find(target);
                if (iter != countAB.end()) {
                    // A+B 等于 target 的组合有 iter->second 种。
                    result += iter->second;
                }
            }
        }

        // result 是所有满足四数和为 0 的元组数量。
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n^2)` |
| 空间 | `O(n^2)` |

### 易错点

- 这里统计的是元组数量，不需要去重。
- `unordered_map` 的 value 是次数，不是下标。

## 383 赎金信

### 题目链接

- 代码随想录：[383. 赎金信](https://programmercarl.com/0383.赎金信.html)
- 力扣页面：[383. Ransom Note](https://leetcode.cn/problems/ransom-note/)

### 题目描述

给定两个字符串 `ransomNote` 和 `magazine`，判断 `ransomNote` 能否由 `magazine` 里面的字符构成。`magazine` 中每个字符只能使用一次。

### 示例

```text
输入：ransomNote = "a", magazine = "b"
输出：false
```

```text
输入：ransomNote = "aa", magazine = "aab"
输出：true
```

### 思路

因为都是小写字母，用长度为 26 的数组统计 `magazine` 中每个字符数量，再遍历 `ransomNote` 消耗字符。某个字符不够用时返回 `false`。

### C++ 详细注释代码

```cpp
#include <string>
using namespace std;

class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        // 小写字母只有 26 个，用数组统计比 unordered_map 更轻。
        int record[26] = {0};

        // 统计 magazine 能提供的字符数量。
        for (char c : magazine) {
            ++record[c - 'a'];
        }

        // ransomNote 每使用一个字符，就消耗一次。
        for (char c : ransomNote) {
            --record[c - 'a'];

            // 如果减成负数，说明 magazine 中该字符不够。
            if (record[c - 'a'] < 0) {
                return false;
            }
        }

        return true;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n + m)` |
| 空间 | `O(1)` |

### 易错点

- `magazine` 的字符只能用一次，所以要统计次数。
- 小写字母范围固定，用数组比 map 更简单。

## 15 三数之和

### 题目链接

- 代码随想录：[15. 三数之和](https://programmercarl.com/0015.三数之和.html)
- 力扣页面：[15. 3Sum](https://leetcode.cn/problems/3sum/)

### 题目描述

给定整数数组 `nums`，找出所有不重复的三元组 `[nums[i], nums[j], nums[k]]`，使三数之和为 0。答案中不能包含重复三元组。

### 示例

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

```text
输入：nums = [0,0,0,0]
输出：[[0,0,0]]
```

### 思路

虽然这题在哈希表章节，但排序 + 双指针更适合处理去重。先排序，固定第一个数 `nums[i]`，再用左右指针在 `i` 后面找两数之和等于 `-nums[i]`。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        // 排序后，重复元素相邻，方便去重和双指针移动。
        sort(nums.begin(), nums.end());

        for (int i = 0; i < nums.size(); ++i) {
            // 排序后，如果第一个数已经大于 0，后面都更大，不可能凑成 0。
            if (nums[i] > 0) {
                break;
            }

            // 对第一个数去重。同一层不能重复固定相同的 nums[i]。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.size() - 1;

            while (left < right) {
                // 当前固定 nums[i]，用 left/right 找另外两个数。
                int sum = nums[i] + nums[left] + nums[right];

                if (sum > 0) {
                    // 和太大，右指针左移，让总和变小。
                    --right;
                } else if (sum < 0) {
                    // 和太小，左指针右移，让总和变大。
                    ++left;
                } else {
                    result.push_back({nums[i], nums[left], nums[right]});

                    // 对 left 和 right 去重，避免重复三元组。
                    while (left < right && nums[left] == nums[left + 1]) ++left;
                    while (left < right && nums[right] == nums[right - 1]) --right;

                    // 找到一组答案后，左右指针都向中间移动。
                    ++left;
                    --right;
                }
            }
        }

        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n^2)` |
| 空间 | `O(1)`，不算返回结果；排序栈空间视实现而定 |

### 易错点

- 第一个数去重要和前一个比：`nums[i] == nums[i - 1]`。
- 找到答案后，左右指针也要去重。
- 不建议用纯哈希硬做，去重逻辑会更复杂。

## 18 四数之和

### 题目链接

- 代码随想录：[18. 四数之和](https://programmercarl.com/0018.四数之和.html)
- 力扣页面：[18. 4Sum](https://leetcode.cn/problems/4sum/)

### 题目描述

给定整数数组 `nums` 和目标值 `target`，找出所有不重复的四元组，使四数之和等于 `target`。

### 示例

```text
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

```text
输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]
```

### 思路

四数之和是在三数之和外面再套一层循环。排序后固定前两个数 `nums[k]` 和 `nums[i]`，再用左右指针找剩余两个数。注意去重和整数溢出。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        // 排序后才能使用双指针，并且方便跳过重复值。
        sort(nums.begin(), nums.end());

        // k 固定四元组中的第一个数。
        for (int k = 0; k < nums.size(); ++k) {
            // 对第一个固定数去重。
            if (k > 0 && nums[k] == nums[k - 1]) {
                continue;
            }

            // i 固定四元组中的第二个数。
            for (int i = k + 1; i < nums.size(); ++i) {
                // 对第二个固定数去重。
                if (i > k + 1 && nums[i] == nums[i - 1]) {
                    continue;
                }

                int left = i + 1;
                int right = nums.size() - 1;

                while (left < right) {
                    // 用 long long 防止四个 int 相加溢出。
                    long long sum = (long long)nums[k] + nums[i] + nums[left] + nums[right];

                    if (sum > target) {
                        // 和偏大，需要让右侧数字变小。
                        --right;
                    } else if (sum < target) {
                        // 和偏小，需要让左侧数字变大。
                        ++left;
                    } else {
                        // 找到一个不重复四元组。
                        result.push_back({nums[k], nums[i], nums[left], nums[right]});

                        // 对左右指针去重。
                        while (left < right && nums[left] == nums[left + 1]) ++left;
                        while (left < right && nums[right] == nums[right - 1]) --right;

                        ++left;
                        --right;
                    }
                }
            }
        }

        // 所有四元组收集完毕。
        return result;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n^3)` |
| 空间 | `O(1)`，不算返回结果 |

### 易错点

- 四数相加可能溢出，要转 `long long`。
- 两层固定数都要去重。
- 四数之和的 `target` 不一定是 0，剪枝条件不能完全照搬三数之和。

### 哈希题型速记

| 题型 | 关键词 | 常用套路 |
|---|---|---|
| 字符计数 | 小写字母、频率 | 长度 26 数组 |
| 去重交集 | 唯一、不重复 | `unordered_set` |
| 是否进入循环 | 重复出现 | `unordered_set` 记录状态 |
| 找目标搭档 | 两数之和 | `unordered_map<值, 下标>` |
| 多数组求和计数 | 四数相加 II | 两两分组 + map 计数 |
| 三数/四数去重 | 不重复元组 | 排序 + 双指针 |

### 面试总表达

哈希法的核心是用空间换时间。遇到“是否出现过”用 set，遇到“出现几次或对应下标”用 map，遇到 key 范围很小就用数组。三数之和、四数之和的难点是去重，排序加双指针通常更清晰。
