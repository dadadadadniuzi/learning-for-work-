## 344 反转字符串

### 题目链接

- 代码随想录：[344. 反转字符串](https://programmercarl.com/0344.反转字符串.html)
- 力扣页面：[344. Reverse String](https://leetcode.cn/problems/reverse-string/)

### 题目描述

给定一个字符数组 `s`，原地反转它。必须使用 `O(1)` 额外空间。

### 示例

```text
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

```text
输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

### 思路

原地反转最自然的做法是左右双指针：左指针从头开始，右指针从尾开始，每次交换两个字符，然后同时向中间移动。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0;              // 指向当前左侧待交换字符。
        int right = s.size() - 1;  // 指向当前右侧待交换字符。

        while (left < right) {
            // 交换左右两端字符。
            swap(s[left], s[right]);

            // 两个指针同时向中间靠拢。
            ++left;
            --right;
        }
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- 题目要求原地修改，不要新建字符串返回。
- 循环条件是 `left < right`，相遇时不用交换。

## 541 反转字符串 II

### 题目链接

- 代码随想录：[541. 反转字符串 II](https://programmercarl.com/0541.反转字符串II.html)
- 力扣页面：[541. Reverse String II](https://leetcode.cn/problems/reverse-string-ii/)

### 题目描述

给定字符串 `s` 和整数 `k`，从字符串开头算起，每计数至 `2k` 个字符，就反转这 `2k` 字符中的前 `k` 个字符。剩余字符不足 `k` 个时全部反转；剩余字符在 `[k, 2k)` 个时，只反转前 `k` 个。

### 示例

```text
输入：s = "abcdefg", k = 2
输出："bacdfeg"
```

```text
输入：s = "abcd", k = 2
输出："bacd"
```

### 思路

每一轮处理一个长度为 `2k` 的区间，只反转区间起点开始的前 `k` 个字符。循环变量每次增加 `2k`。

### C++ 详细注释代码

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string reverseStr(string s, int k) {
        // i 是每个 2k 区间的起点。
        for (int i = 0; i < s.size(); i += 2 * k) {
            // reverse 的区间是左闭右开：[first, last)。
            // 如果剩余字符至少有 k 个，反转 [i, i + k)。
            if (i + k <= s.size()) {
                reverse(s.begin() + i, s.begin() + i + k);
            } else {
                // 剩余字符不足 k 个时，全部反转。
                reverse(s.begin() + i, s.end());
            }
        }

        return s;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)`，不算返回字符串 |

### 易错点

- `reverse` 的右边界是开区间。
- 循环步长是 `2 * k`，不是 `k`。
- 剩余字符不足 `k` 个时要全部反转。

## 54 替换数字

### 题目链接

- 代码随想录：[54. 替换数字](https://programmercarl.com/kamacoder/0054.替换数字.html)
- 代码随想录：[剑指 Offer 05. 替换空格](https://programmercarl.com/剑指Offer05.替换空格.html)
- 卡码网页面：[54. 替换数字](https://kamacoder.com/problempage.php?pid=1064)
- 力扣页面：无。这是卡码网 ACM 模式题，不是力扣题。

### 题目描述

给定一个字符串，把字符串中的每个数字字符替换成字符串 `"number"`。

### 示例

```text
输入：a1b2c3
输出：anumberbnumbercnumber
```

### 思路

如果从前往后替换，字符串会不断移动，效率较低。可以先统计数字个数，扩容字符串，然后从后往前填充：遇到数字就倒着写入 `"number"`，遇到普通字符就直接搬过去。

> [!note]
> 这题和网页里的“剑指 Offer 05. 替换空格”是同一类扩容替换题：替换空格是把 `' '` 变成 `"%20"`，替换数字是把数字字符变成 `"number"`。共同套路都是“先统计需要扩容的字符，再从后往前填”，避免从前往后导致大量字符搬移。

### C++ 详细注释代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int oldSize = s.size();
    int count = 0;

    // 统计数字字符数量。
    for (char c : s) {
        if (c >= '0' && c <= '9') {
            ++count;
        }
    }

    // 每个数字原本占 1 个字符，替换成 "number" 后占 6 个字符。
    // 所以每个数字额外增加 5 个位置。
    s.resize(oldSize + count * 5);

    int oldIndex = oldSize - 1;      // 指向原字符串末尾。
    int newIndex = s.size() - 1;     // 指向扩容后字符串末尾。

    while (oldIndex >= 0) {
        if (s[oldIndex] >= '0' && s[oldIndex] <= '9') {
            // 从后往前写入 "number"。
            s[newIndex--] = 'r';
            s[newIndex--] = 'e';
            s[newIndex--] = 'b';
            s[newIndex--] = 'm';
            s[newIndex--] = 'u';
            s[newIndex--] = 'n';
        } else {
            // 普通字符直接搬到新位置。
            s[newIndex--] = s[oldIndex];
        }
        --oldIndex;
    }

    cout << s << endl;
    return 0;
}
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)`，不算字符串扩容本身 |

### 易错点

- 从后往前填，避免前面字符被覆盖。
- `"number"` 长度是 6，所以每个数字额外增加 5 个字符。

## 151 翻转字符串里的单词

### 题目链接

- 代码随想录：[151. 翻转字符串里的单词](https://programmercarl.com/0151.翻转字符串里的单词.html)
- 力扣页面：[151. Reverse Words in a String](https://leetcode.cn/problems/reverse-words-in-a-string/)

### 题目描述

给定字符串 `s`，反转字符串中单词的顺序。单词之间用单个空格连接，结果中不能有前导空格、尾随空格或多个连续空格。

### 示例

```text
输入：s = "the sky is blue"
输出："blue is sky the"
```

```text
输入：s = "  hello world  "
输出："world hello"
```

```text
输入：s = "a good   example"
输出："example good a"
```

### 思路

先移除多余空格，让字符串变成单词之间只有一个空格；再整体反转字符串；最后逐个反转每个单词。这样单词顺序被翻转，但每个单词内部字符恢复正常。

### C++ 详细注释代码

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    void removeExtraSpaces(string& s) {
        int slow = 0; // slow 指向压缩后字符串的写入位置。

        for (int fast = 0; fast < s.size(); ++fast) {
            // fast 跳过空格，只在遇到单词首字符时进入处理。
            if (s[fast] != ' ') {
                // 如果不是第一个单词，先补一个单词间空格。
                if (slow != 0) {
                    s[slow++] = ' ';
                }

                // 复制当前单词。
                while (fast < s.size() && s[fast] != ' ') {
                    s[slow++] = s[fast++];
                }
            }
        }

        // 删除 slow 之后的无效字符。
        s.resize(slow);
    }

    string reverseWords(string s) {
        // 1. 去掉首尾空格和中间多余空格。
        removeExtraSpaces(s);

        // 2. 整体反转，例如 "the sky" -> "yks eht"。
        reverse(s.begin(), s.end());

        // 3. 再反转每个单词，让单词内部恢复正常。
        int start = 0;
        for (int i = 0; i <= s.size(); ++i) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }

        return s;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)`，不算返回字符串 |

### 易错点

- 要先清理多余空格，否则结果格式不对。
- 整体反转后必须再反转每个单词。
- `reverse` 右边界是开区间。

## 55 右旋字符串

### 题目链接

- 代码随想录：[55. 右旋字符串](https://programmercarl.com/kamacoder/0055.右旋字符串.html)
- 卡码网页面：[55. 右旋字符串](https://kamacoder.com/problempage.php?pid=1065)
- 力扣页面：无。这是卡码网 ACM 模式题，不是力扣题。

### 题目描述

给定整数 `k` 和字符串 `s`，把字符串右旋 `k` 位。右旋 `k` 位表示把字符串后 `k` 个字符移动到字符串前面。

### 示例

```text
输入：
2
abcdefg

输出：
fgabcde
```

### 思路

右旋可以通过三次反转完成。以 `"abcdefg"` 右旋 2 位为例：

```text
整体反转：gfedcba
反转前 k 个：fgedcba
反转后 n-k 个：fgabcde
```

### C++ 详细注释代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    int k;
    string s;
    // ACM 模式：先读旋转位数，再读字符串。
    cin >> k >> s;

    int n = s.size();
    // k 可能大于字符串长度，取模后效果相同。
    k %= n;

    // 1. 整体反转。
    reverse(s.begin(), s.end());

    // 2. 反转前 k 个字符。
    reverse(s.begin(), s.begin() + k);

    // 3. 反转剩余字符。
    reverse(s.begin() + k, s.end());

    cout << s << endl;
    return 0;
}
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(1)` |

### 易错点

- `k` 可能大于字符串长度，先取模。
- 右旋和左旋的三次反转顺序不同。

## 28 找出字符串中第一个匹配项的下标

### 题目链接

- 代码随想录：[28. 实现 strStr](https://programmercarl.com/0028.实现strStr.html)
- 力扣页面：[28. Find the Index of the First Occurrence in a String](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/)

### 题目描述

给定两个字符串 `haystack` 和 `needle`，返回 `needle` 在 `haystack` 中第一次出现的下标；如果不存在，返回 `-1`。

### 示例

```text
输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 第一次出现在下标 0。
```

```text
输入：haystack = "leetcode", needle = "leeto"
输出：-1
```

### 思路

KMP 用来避免主串指针回退。核心是给模式串 `needle` 构造 `next` 数组：`next[i]` 表示 `needle[0..i]` 这个子串的最长相等前后缀长度。匹配失败时，模式串根据 `next` 回退到合适位置，而主串继续向前。

### next 数组怎么理解

以前缀表不减一写法为例：

```text
needle = "aabaaf"
next   = [0,1,0,1,2,0]
```

`next[4] = 2` 表示子串 `"aabaa"` 的最长相等前后缀是 `"aa"`，长度为 2。如果下一位匹配失败，模式串可以回退到下标 2 继续比。

### C++ 详细注释代码

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    void getNext(vector<int>& next, const string& s) {
        // j 表示当前最长相等前后缀的长度。
        // 也表示前缀末尾的下一个位置。
        int j = 0;
        next[0] = 0;

        // i 表示后缀末尾位置，从 1 开始。
        for (int i = 1; i < s.size(); ++i) {
            // 如果 s[i] 和 s[j] 不相等，j 就根据 next 回退。
            // 一直回退到能匹配，或 j 变成 0。
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }

            // 如果相等，说明最长相等前后缀长度可以加一。
            if (s[i] == s[j]) {
                ++j;
            }

            // next[i] 记录 s[0..i] 的最长相等前后缀长度。
            next[i] = j;
        }
    }

    int strStr(string haystack, string needle) {
        if (needle.empty()) return 0;

        vector<int> next(needle.size());
        getNext(next, needle);

        // j 指向 needle 当前要匹配的位置。
        int j = 0;

        // i 指向 haystack 当前要匹配的位置。
        for (int i = 0; i < haystack.size(); ++i) {
            // 匹配失败时，needle 根据 next 回退，haystack 不回退。
            while (j > 0 && haystack[i] != needle[j]) {
                j = next[j - 1];
            }

            // 当前字符匹配成功，needle 指针后移。
            if (haystack[i] == needle[j]) {
                ++j;
            }

            // j 到达 needle.size()，说明完整匹配了一次。
            if (j == needle.size()) {
                return i - needle.size() + 1;
            }
        }

        return -1;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n + m)` |
| 空间 | `O(m)` |

### 易错点

- `next` 数组是给模式串 `needle` 构造的，不是给主串构造的。
- 匹配失败时主串 `i` 不回退，只回退模式串 `j`。
- 返回起点是 `i - needle.size() + 1`。

### 面试表达

KMP 的关键是模式串自我匹配得到前缀表。当前字符匹配失败时，不需要让主串回退，而是让模式串跳到最长相等前后缀对应的位置继续匹配。

## 459 重复的子字符串

### 题目链接

- 代码随想录：[459. 重复的子字符串](https://programmercarl.com/0459.重复的子字符串.html)
- 力扣页面：[459. Repeated Substring Pattern](https://leetcode.cn/problems/repeated-substring-pattern/)

### 题目描述

给定一个非空字符串 `s`，判断它是否可以由它的某个子串重复多次构成。

### 示例

```text
输入：s = "abab"
输出：true
解释：可以由 "ab" 重复两次构成。
```

```text
输入：s = "aba"
输出：false
```

```text
输入：s = "abcabcabcabc"
输出：true
解释：可以由 "abc" 重复四次构成。
```

### 思路

如果字符串由重复子串构成，那么最长相等前后缀长度 `next[n - 1]` 不为 0，并且字符串长度 `n` 能被 `n - next[n - 1]` 整除。其中 `n - next[n - 1]` 就是最小重复单元长度。

### C++ 详细注释代码

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    void getNext(vector<int>& next, const string& s) {
        // 这段和 28 题 KMP 的 getNext 完全一致。
        int j = 0;
        next[0] = 0;

        for (int i = 1; i < s.size(); ++i) {
            // 不匹配时，根据已经求出的前缀表回退 j。
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }

            // 匹配时，最长相等前后缀长度增加。
            if (s[i] == s[j]) {
                ++j;
            }

            // 记录 s[0..i] 的最长相等前后缀长度。
            next[i] = j;
        }
    }

    bool repeatedSubstringPattern(string s) {
        int n = s.size();
        vector<int> next(n);
        // 构造整个字符串的前缀表。
        getNext(next, s);

        // longestPrefixSuffix 是整个字符串的最长相等前后缀长度。
        int longestPrefixSuffix = next[n - 1];

        if (longestPrefixSuffix == 0) {
            return false;
        }

        // repeatLength 是可能的最小重复子串长度。
        int repeatLength = n - longestPrefixSuffix;

        // 如果 n 能整除 repeatLength，说明可以重复构成。
        return n % repeatLength == 0;
    }
};
```

### 复杂度

| 项目 | 复杂度 |
|---|---|
| 时间 | `O(n)` |
| 空间 | `O(n)` |

### 易错点

- `next[n - 1] == 0` 说明没有相等前后缀，不可能由重复子串构成。
- 判断条件是 `n % (n - next[n - 1]) == 0`。

### 另一种理解

如果 `s` 是重复子串构成，那么把 `s + s` 去掉首尾字符，中间仍然能找到 `s`。但面试中如果正在考 KMP，建议用前缀表解释。

## 总结篇

### 题目链接

- 代码随想录：[字符串总结篇](https://programmercarl.com/字符串总结篇.html)
- 力扣页面：无。这是专题总结，不是单独力扣题。

### 字符串题型速记

| 题型 | 关键词 | 常用套路 |
|---|---|---|
| 原地反转 | 字符数组、空间 O(1) | 左右双指针 |
| 区间反转 | 每 `2k` 个处理一次 | 找每段起点 |
| 替换扩容 | 字符替换成长字符串 | 先扩容，再从后往前填 |
| 单词反转 | 去空格、调顺序 | 清空格 + 整体反转 + 单词反转 |
| 旋转字符串 | 左旋/右旋 | 三次反转 |
| 子串匹配 | 查找模式串 | KMP 前缀表 |
| 重复子串 | 是否周期重复 | KMP 看最长相等前后缀 |

### 面试总表达

字符串题看起来像模拟，但本质常常是双指针和边界控制。遇到子串匹配时，暴力会重复比较，KMP 用模式串的前缀表让主串不回退。
