## 中断和异常有什么区别

### 简要回答

中断通常来自 CPU 外部设备，是异步的；异常通常来自 CPU 执行当前指令时产生的问题，是同步的。

### 详细回答

- 中断：比如键盘输入、网卡收包、磁盘 I/O 完成、时钟中断。
- 异常：比如除零、非法指令、缺页异常。

### 面试表达

> 中断是外部事件打断 CPU，异常是当前指令执行过程中发现问题。两者都会让 CPU 进入内核态，由操作系统处理。

### 细节补充

中断和异常机制是操作系统获得 CPU 控制权的重要方式。发生中断或异常后，CPU 会切换到内核态，操作系统执行对应处理程序。

异常常见类型：

- 故障：如缺页异常，处理后可以回到原指令继续执行。
- 陷阱：如系统调用，通常是有意触发。
- 终止：严重错误，通常无法恢复。

## 中断处理流程是什么

### 简要回答

保存现场、进入内核态、查找中断处理程序、处理中断、恢复现场、返回原程序继续执行。

### 详细回答

1. CPU 检测到中断信号。
2. 保存当前程序上下文。
3. 根据中断向量找到处理函数。
4. 执行具体处理逻辑。
5. 恢复上下文。
6. 返回被中断程序。

### 展开流程

```text
中断请求 -> 中断判优 -> 保存断点和程序状态 -> 查找中断向量
-> 执行中断服务程序 -> 恢复现场 -> 返回原程序
```

面试里可以强调两个点：

- 保存现场是为了中断处理完还能回到原程序。
- 中断服务程序运行在内核态。

## 系统调用、中断、异常有什么关系

### 简要回答

它们都可能导致从用户态进入内核态，但来源不同。

### 详细回答

- 系统调用：用户程序主动请求内核服务。
- 中断：外部设备异步通知 CPU。
- 异常：当前指令执行出错或需要内核介入。

### 面试表达

> 系统调用是主动进内核，中断是外部事件触发，异常是执行当前指令时触发。它们最后都会走到内核处理逻辑。

## 缺页异常是什么

### 简要回答

缺页异常是进程访问的虚拟页不在物理内存中，CPU 触发异常，让操作系统把对应页调入内存。

### 详细回答

缺页不一定是错误，它是虚拟内存按需调页机制的一部分。操作系统会检查访问是否合法，合法就从磁盘加载页面；不合法就可能触发段错误。

## 时钟中断是什么

### 简要回答

时钟中断是由硬件定时器周期性产生的中断，用来让操作系统定期获得 CPU 控制权。

### 详细回答

如果没有时钟中断，一个进程可能一直占着 CPU 不放。操作系统通过时钟中断周期性打断当前进程，进入内核态执行调度逻辑，从而实现时间片轮转、进程调度、定时器管理等功能。

### 面试表达

> 时钟中断是操作系统实现抢占式调度的重要基础。它让内核有机会定期检查当前进程是否该让出 CPU。

## 上下文切换是什么

### 简要回答

上下文切换是 CPU 从一个进程或线程切换到另一个进程或线程时，保存当前执行现场并恢复另一个执行现场的过程。

### 需要保存什么

- 程序计数器
- 寄存器
- 栈指针
- 进程或线程状态
- 调度相关信息

### 面试表达

> 上下文切换不是免费操作，它需要保存和恢复执行现场，还可能影响缓存和 TLB 命中率。所以线程或进程数量不是越多越好。
