## 双指针是什么

### 核心分类

| 类型 | 指针移动方式 | 维护的不变量 | 典型题 |
|---|---|---|---|
| 同向快慢指针 | 两个指针都向右，快指针探路，慢指针写入 | `[0, slow)` 是已处理有效区间 | 移除元素、移动零 |
| 相向双指针 | 一个从左，一个从右 | 左右边界逐步缩小 | 反转字符串、三数之和 |
| 从后向前双指针 | 旧指针和新指针都从尾部走 | 未处理旧字符不会被覆盖 | 替换数字、替换空格 |
| 链表快慢指针 | 快指针先走或每次走两步 | 两指针保持距离或速度差 | 倒数第 N 个、环形链表 |
| 链表同步指针 | 两个指针走过相同总长度 | 尾部对齐后同步比较 | 链表相交 |

### 面试表达

双指针的本质是用两个位置减少重复枚举。数组和字符串里通常用下标，链表里通常用节点指针。写代码前我会先定义不变量，例如慢指针之前都是保留元素、左右指针之间是待处理区间、快慢指针之间固定相隔 `n` 个节点。

## 27 移除元素

### 题目链接

- 代码随想录：[27. 移除元素](https://programmercarl.com/0027.移除元素.html)
- 力扣页面：[27. Remove Element](https://leetcode.cn/problems/remove-element/)
- 详细笔记：[[01 数组#27 移除元素]]

### 题目描述

给定数组 `nums` 和值 `val`，原地移除所有等于 `val` 的元素，返回移除后的新长度。元素顺序可以改变，但最常见写法会保持相对顺序。

### 示例

```text
输入：nums = [3,2,2,3], val = 3
输出：2
解释：前两个元素可以是 [2,2]
```

### 核心不变量

- `fast`：遍历原数组，负责看当前元素是否保留。
- `slow`：指向下一个可写入位置。
- 始终保证 `[0, slow)` 是已经处理好的有效元素。

### C++ 详细注释代码

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int slow = 0;

        for (int fast = 0; fast < nums.size(); ++fast) {
            // fast 遇到不等于 val 的元素，说明这个元素要保留。
            if (nums[fast] != val) {
                // 把保留元素写到 slow 位置。
                nums[slow] = nums[fast];

                // slow 前进一步，继续维护 [0, slow) 是有效区间。
                ++slow;
            }
        }

        return slow;
    }
};
```

### 易错点

- `slow` 返回的是长度，不是最后一个有效下标。
- 如果题目不要求保持顺序，也可以用相向指针把末尾元素覆盖到当前位置。
- 同向覆盖写法适用于“保留相对顺序”的原地过滤问题。

## 344 反转字符串

### 题目链接

- 代码随想录：[344. 反转字符串](https://programmercarl.com/0344.反转字符串.html)
- 力扣页面：[344. Reverse String](https://leetcode.cn/problems/reverse-string/)
- 详细笔记：[[04 字符串#344 反转字符串]]

### 题目描述

给定字符数组 `s`，原地反转数组，不能额外分配另一个数组。

### 示例

```text
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

### 核心不变量

`left` 左边和 `right` 右边都已经反转完成，`[left, right]` 是还没处理的区间。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            // 交换左右两端字符，完成一对位置的反转。
            swap(s[left], s[right]);

            // 向中间收缩未处理区间。
            ++left;
            --right;
        }
    }
};
```

### 易错点

- 条件是 `left < right`，相遇时中间字符不需要处理。
- 空数组时 `right` 会是 `-1`，用 `int` 更方便控制边界。

## 54 替换数字

### 题目链接

- 代码随想录：[54. 替换数字](https://programmercarl.com/kamacoder/0054.替换数字.html)
- 代码随想录：[剑指 Offer 05. 替换空格](https://programmercarl.com/剑指Offer05.替换空格.html)
- 卡码网：[54. 替换数字](https://kamacoder.com/problempage.php?pid=1064)
- 详细笔记：[[04 字符串#54 替换数字]]

### 题目描述

给定字符串，把每个数字字符替换成 `"number"`。这是“替换后字符串变长”的典型题。

### 示例

```text
输入：a1b2c3
输出：anumberbnumbercnumber
```

### 核心不变量

扩容后从后往前填，`oldIndex` 指向原字符串还没处理的位置，`newIndex` 指向新字符串下一个写入位置。这样不会覆盖还没处理的旧字符。

### C++ 详细注释代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int oldSize = s.size();
    int count = 0;

    // 先统计数字个数，计算扩容后长度。
    for (char c : s) {
        if (c >= '0' && c <= '9') {
            ++count;
        }
    }

    // 每个数字由 1 个字符变成 6 个字符，额外增加 5 个位置。
    s.resize(oldSize + count * 5);

    int oldIndex = oldSize - 1;
    int newIndex = static_cast<int>(s.size()) - 1;

    while (oldIndex >= 0) {
        if (s[oldIndex] >= '0' && s[oldIndex] <= '9') {
            // 从后往前写入 number，所以字符顺序要倒着放。
            s[newIndex--] = 'r';
            s[newIndex--] = 'e';
            s[newIndex--] = 'b';
            s[newIndex--] = 'm';
            s[newIndex--] = 'u';
            s[newIndex--] = 'n';
        } else {
            // 普通字符直接搬到新位置。
            s[newIndex--] = s[oldIndex];
        }

        --oldIndex;
    }

    cout << s << endl;
    return 0;
}
```

### 易错点

- 先扩容，再从后往前写；从前往后会造成反复移动。
- 写 `"number"` 时因为从后往前填，所以要倒序写入。
- 剑指 Offer 替换空格是同类题，只是替换串从 `"number"` 换成 `"%20"`。

## 151 翻转字符串里的单词

### 题目链接

- 代码随想录：[151. 翻转字符串里的单词](https://programmercarl.com/0151.翻转字符串里的单词.html)
- 力扣页面：[151. Reverse Words in a String](https://leetcode.cn/problems/reverse-words-in-a-string/)
- 详细笔记：[[04 字符串#151 翻转字符串里的单词]]

### 题目描述

给定字符串，去掉多余空格，并把单词顺序反转。

### 示例

```text
输入："  hello   world  "
输出："world hello"
```

### 核心套路

1. 快慢指针去掉首尾和中间多余空格。
2. 整体反转字符串。
3. 再逐个反转每个单词。

### C++ 详细注释代码

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    void removeExtraSpaces(string& s) {
        int slow = 0;

        for (int fast = 0; fast < s.size(); ++fast) {
            if (s[fast] == ' ') continue;

            // 如果不是第一个单词，先补一个单词间空格。
            if (slow != 0) {
                s[slow++] = ' ';
            }

            // 复制当前单词。
            while (fast < s.size() && s[fast] != ' ') {
                s[slow++] = s[fast++];
            }
        }

        s.resize(slow);
    }

    string reverseWords(string s) {
        removeExtraSpaces(s);

        // 整体反转后，单词顺序已经反了，但每个单词内部也反了。
        reverse(s.begin(), s.end());

        int start = 0;
        for (int i = 0; i <= s.size(); ++i) {
            if (i == s.size() || s[i] == ' ') {
                // 把当前单词内部再反一次。
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }

        return s;
    }
};
```

### 易错点

- 去空格时要保证单词之间只保留一个空格。
- 整体反转后必须再反转每个单词，否则单词内部字符顺序是反的。
- 遍历单词时可以让 `i <= s.size()`，把字符串末尾当作最后一个分隔点。

## 206 反转链表

### 题目链接

- 代码随想录：[206. 反转链表](https://programmercarl.com/0206.翻转链表.html)
- 力扣页面：[206. Reverse Linked List](https://leetcode.cn/problems/reverse-linked-list/)
- 详细笔记：[[02 链表#206 反转链表]]

### 题目描述

给定单链表头节点，反转链表并返回新的头节点。

### 示例

```text
输入：1 -> 2 -> 3 -> 4 -> 5
输出：5 -> 4 -> 3 -> 2 -> 1
```

### 核心不变量

`pre` 指向已经反转好的链表头，`cur` 指向待反转的当前节点，`temp` 临时保存后继，避免断链。

### C++ 详细注释代码

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* cur = head;

        while (cur != nullptr) {
            // 先保存后继，否则改变 cur->next 后会丢失后半段链表。
            ListNode* temp = cur->next;

            // 反转当前节点指向。
            cur->next = pre;

            // pre 和 cur 各向前推进一步。
            pre = cur;
            cur = temp;
        }

        // cur 为空时，pre 正好是新头节点。
        return pre;
    }
};
```

### 易错点

- 必须先保存 `cur->next`。
- 循环结束后返回 `pre`，不是 `cur`。
- 递归写法本质也是改变每个节点的 `next` 指向。

## 19 删除链表的倒数第 N 个节点

### 题目链接

- 代码随想录：[19. 删除链表的倒数第 N 个节点](https://programmercarl.com/0019.删除链表的倒数第N个节点.html)
- 力扣页面：[19. Remove Nth Node From End of List](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)
- 详细笔记：[[02 链表#19 删除链表的倒数第 N 个节点]]

### 题目描述

删除链表倒数第 `n` 个节点，返回头节点。

### 示例

```text
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

### 核心不变量

让 `fast` 先走 `n + 1` 步，这样 `fast` 到空时，`slow` 正好停在待删除节点的前一个节点。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummy = new ListNode(0);
        dummy->next = head;

        ListNode* fast = dummy;
        ListNode* slow = dummy;

        // fast 先走 n + 1 步，拉开距离。
        for (int i = 0; i <= n; ++i) {
            fast = fast->next;
        }

        // fast 到空时，slow 停在待删除节点前驱。
        while (fast != nullptr) {
            fast = fast->next;
            slow = slow->next;
        }

        ListNode* deleteNode = slow->next;
        slow->next = slow->next->next;
        delete deleteNode;

        ListNode* result = dummy->next;
        delete dummy;
        return result;
    }
};
```

### 易错点

- 虚拟头节点能统一处理删除头节点的情况。
- 快指针走 `n + 1` 步，是为了让慢指针停在前驱；如果只走 `n` 步，慢指针会停在待删节点。
- 如果平台不要求释放内存，也可以省略 `delete`，但真实 C++ 项目里要注意。

## 面试题 02.07 链表相交

### 题目链接

- 代码随想录：[面试题 02.07. 链表相交](https://programmercarl.com/面试题02.07.链表相交.html)
- 力扣页面：[Intersection of Two Linked Lists](https://leetcode.cn/problems/intersection-of-two-linked-lists-lcci/)
- 详细笔记：[[02 链表#面试题 02.07 链表相交]]

### 题目描述

给定两个单链表头节点，判断它们是否相交。相交指的是两个链表共享同一个节点地址，不是节点值相同。

### 示例

```text
A: 4 -> 1 -> 8 -> 4 -> 5
B: 5 -> 6 -> 1 -> 8 -> 4 -> 5
输出：节点 8
```

### 核心不变量

两个指针分别走 `A + B` 和 `B + A`，如果有交点，它们会在第二轮对齐后相遇；如果没有交点，最后都走到 `nullptr`。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        ListNode* curA = headA;
        ListNode* curB = headB;

        while (curA != curB) {
            // A 走完后切到 B，保证总路程变成 A+B。
            curA = (curA == nullptr) ? headB : curA->next;

            // B 走完后切到 A，保证总路程变成 B+A。
            curB = (curB == nullptr) ? headA : curB->next;
        }

        return curA;
    }
};
```

### 易错点

- 比较的是节点指针地址，不是 `val`。
- 无交点时，两个指针最终都会是 `nullptr`，循环也会结束。
- 这类写法不需要提前计算链表长度。

## 142 环形链表 II

### 题目链接

- 代码随想录：[142. 环形链表 II](https://programmercarl.com/0142.环形链表II.html)
- 力扣页面：[142. Linked List Cycle II](https://leetcode.cn/problems/linked-list-cycle-ii/)
- 详细笔记：[[02 链表#142 环形链表 II]]

### 题目描述

判断链表是否有环；如果有环，返回环的入口节点；如果无环，返回 `nullptr`。

### 示例

```text
输入：head = [3,2,0,-4], pos = 1
输出：节点 2
```

### 核心不变量

先用快慢指针判断是否相遇。相遇后，让一个指针从头节点出发，另一个从相遇点出发，每次都走一步，再次相遇的位置就是环入口。

### C++ 详细注释代码

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;

            if (slow == fast) {
                ListNode* index1 = head;
                ListNode* index2 = slow;

                while (index1 != index2) {
                    index1 = index1->next;
                    index2 = index2->next;
                }

                return index1;
            }
        }

        return nullptr;
    }
};
```

### 易错点

- `fast` 每次走两步，所以循环条件必须检查 `fast` 和 `fast->next`。
- 相遇点不一定是入口。
- 找入口时两个指针都每次走一步。

## 15 三数之和

### 题目链接

- 代码随想录：[15. 三数之和](https://programmercarl.com/0015.三数之和.html)
- 力扣页面：[15. 3Sum](https://leetcode.cn/problems/3sum/)
- 详细笔记：[[03 哈希表#15 三数之和]]

### 题目描述

给定整数数组，找出所有不重复三元组，使三数之和为 `0`。

### 示例

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

### 核心不变量

排序后固定 `i`，`left` 和 `right` 在右侧区间相向移动。如果和太小，说明需要更大数，`left++`；如果和太大，说明需要更小数，`right--`。

### C++ 详细注释代码

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());

        for (int i = 0; i < nums.size(); ++i) {
            // 排序后第一个数已经大于 0，后面不可能凑出 0。
            if (nums[i] > 0) break;

            // i 去重：同一个固定数只处理一次。
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = nums.size() - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    ++left;
                } else if (sum > 0) {
                    --right;
                } else {
                    result.push_back({nums[i], nums[left], nums[right]});

                    // left/right 去重：跳过相同的第二、第三个数。
                    while (left < right && nums[left] == nums[left + 1]) ++left;
                    while (left < right && nums[right] == nums[right - 1]) --right;

                    ++left;
                    --right;
                }
            }
        }

        return result;
    }
};
```

### 易错点

- 去重的是值，不是下标。
- `i` 的去重要和前一个比，不能和后一个比，否则会漏答案。
- 找到答案后，要先跳过重复值，再移动 `left/right`。

## 18 四数之和

### 题目链接

- 代码随想录：[18. 四数之和](https://programmercarl.com/0018.四数之和.html)
- 力扣页面：[18. 4Sum](https://leetcode.cn/problems/4sum/)
- 详细笔记：[[03 哈希表#18 四数之和]]

### 题目描述

给定整数数组和目标值 `target`，找出所有不重复四元组，使四数之和等于 `target`。

### 示例

```text
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

### 核心不变量

比三数之和多固定一层 `j`，之后仍然用 `left/right` 相向逼近。因为 `target` 不一定是 `0`，剪枝要比三数之和更谨慎。

### C++ 详细注释代码

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());

        for (int i = 0; i < nums.size(); ++i) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < nums.size(); ++j) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int left = j + 1;
                int right = nums.size() - 1;

                while (left < right) {
                    // 用 long long 防止四个 int 相加溢出。
                    long long sum = static_cast<long long>(nums[i]) + nums[j] + nums[left] + nums[right];

                    if (sum < target) {
                        ++left;
                    } else if (sum > target) {
                        --right;
                    } else {
                        result.push_back({nums[i], nums[j], nums[left], nums[right]});

                        while (left < right && nums[left] == nums[left + 1]) ++left;
                        while (left < right && nums[right] == nums[right - 1]) --right;

                        ++left;
                        --right;
                    }
                }
            }
        }

        return result;
    }
};
```

### 易错点

- 四数之和的 `target` 不一定为 `0`，不要套三数之和里 `nums[i] > 0` 的剪枝。
- 求和要转 `long long`。
- 每一层都要去重：`i`、`j`、`left/right` 都要处理。

## 双指针总结

### 速记表

| 看见什么 | 想到什么 |
|---|---|
| 原地删除、保留相对顺序 | 快慢指针覆盖 |
| 反转、两端有序 | 左右相向指针 |
| 替换后字符串变长 | 从后向前填充 |
| 链表倒数第 N 个 | 快指针先走，虚拟头节点 |
| 链表有环 | 快慢指针先相遇，再找入口 |
| 两链表相交 | 地址相等，A+B 和 B+A |
| 三数/四数不重复组合 | 排序 + 双指针 + 多层去重 |

### 面试总表达

我判断双指针题时，会先看能不能用两个位置共同维护一个不变量：比如有效区间、左右边界、固定距离或尾部对齐。只要这个不变量明确，代码边界就不容易乱。
