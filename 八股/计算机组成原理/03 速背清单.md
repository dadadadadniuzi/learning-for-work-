# 计算机组成原理速背清单

返回：[[计算机组成原理导航]]

## 体系结构

- [[01 体系结构#冯·诺依曼体系结构是什么|冯·诺依曼体系结构]]：指令和数据放在同一存储器里，CPU 按取指、译码、执行流程工作。
- [[01 体系结构#存储程序思想是什么|存储程序思想]]：程序像数据一样预先存入存储器，换程序不用改硬件。
- [[01 体系结构#冯·诺依曼体系结构是什么|五大组成]]：运算器、控制器、存储器、输入设备、输出设备。
- [[01 体系结构#指令、数据与存储器是什么关系|指令和数据]]：存储形式都是二进制，区别在于 CPU 如何解释。
- [[01 体系结构#哈佛体系结构是什么|哈佛体系结构]]：指令存储器和数据存储器分离，指令和数据可并行访问。
- [[01 体系结构#冯·诺依曼结构和哈佛结构有什么区别|冯·诺依曼 vs 哈佛]]：前者统一存储、结构简单；后者分离存储、并行性好但硬件复杂。
- [[01 体系结构#现代计算机补充|现代计算机]]：CPU 和主存合称主机，I/O 设备属于外部设备。

## 处理器

- [[02 处理器#CPU 和 GPU 有什么区别|CPU 和 GPU]]：CPU 核少但单核强，适合复杂控制；GPU 核多，适合大规模并行。
- [[02 处理器#CPU 主要由哪些部分组成|CPU 组成]]：主要由运算器和控制器组成，也可看作数据通路和控制部件。
- [[02 处理器#CPU 主要由哪些部分组成|CPU 功能]]：指令控制、操作控制、时序控制、中断控制、数据加工。
- [[02 处理器#GPU 主要由哪些部分组成|GPU 组成]]：大量流处理器 + 显存，核心优势是高吞吐并行。
- [[02 处理器#为什么 GPU 适合并行计算|GPU 并行]]：大量小核心同时处理相似任务，如像素计算、矩阵运算、深度学习。
- [[02 处理器#CPU 更适合什么场景|CPU 适合场景]]：复杂分支、任务调度、系统调用、强顺序依赖。
- [[02 处理器#CPU 和 GPU 如何协作|CPU/GPU 协作]]：CPU 管复杂逻辑和调度，GPU 承担大规模并行计算。
