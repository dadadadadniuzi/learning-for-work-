## Workflow-13 / Workflow-14 的作用

- `Workflow-13 myweb首页随机5张图片全流程模拟.md`
  - 讲 `GET /` 首页请求。
  - 重点包括 Workflow 接收 HTTP、创建 `WFRedisTask`、执行 `SRANDMEMBER myweb:images 5`、Redis 返回 5 个随机文件名、拼接 HTML 并返回。

- `Workflow-14 myweb图片文件返回全流程模拟.md`
  - 讲浏览器拿到 HTML 后继续请求 `/image/1.jpg`。
  - 重点包括图片路由、文件名校验、创建 `WFFileIOTask`、异步读取本地图片、设置 `Content-Type/Content-Length` 并返回图片二进制。

两篇都按 TinyWebServer 那种“逐步模拟 + 参数变化 + 调用链”的细度写成 Obsidian 笔记。

## myweb/scripts 中 5 个脚本

- `build.sh`
  - 编译项目，生成 `build/myweb`。
  - 改了 `.cpp/.h` 后运行。

- `start_redis.sh`
  - 启动本地 Redis，默认端口 `6379`。
  - 会优先使用 `/home/avavaava/.local/redis-src/src/redis-server`。

- `load_gallery.sh`
  - 扫描 `gallery/images` 中的图片，把文件名写入 Redis 集合 `myweb:images`。
  - Redis 中只存文件名，不存图片本体。

- `dev_run.sh`
  - 一键开发运行：启动 Redis、导入图库、编译项目、启动 myweb 网站。
  - 平时学习和演示最推荐用它。

- `stop_redis.sh`
  - 停止本地 Redis。

常用启动方式：

```bash
cd /home/avavaava/workspace/myweb
./scripts/dev_run.sh
```

手动分步启动方式：

```bash
./scripts/start_redis.sh
./scripts/load_gallery.sh
./scripts/build.sh
./build/myweb 8888 redis://127.0.0.1:6379 /home/avavaava/workspace/myweb/gallery/images myweb:images
```
