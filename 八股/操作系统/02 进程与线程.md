## 进程和线程有什么区别

### 简要回答

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。

### 详细回答

| 对比点 | 进程 | 线程 |
|---|---|---|
| 资源 | 拥有独立地址空间和资源 | 共享所属进程资源 |
| 调度 | 可以被调度 | 更轻量的调度单位 |
| 通信 | IPC 成本较高 | 共享内存通信方便 |
| 崩溃影响 | 一个进程崩溃通常不影响其他进程 | 一个线程崩溃可能影响整个进程 |

### 面试表达

> 进程更强调资源隔离，线程更强调执行流。多进程稳定性更好，多线程共享数据方便但要注意同步问题。

## PCB 和 TCB 是什么

### 简要回答

`PCB` 是进程控制块，保存进程管理所需的信息；`TCB` 是线程控制块，保存线程调度和运行所需的信息。

### 详细回答

PCB 常见内容：

- 进程标识符 PID
- 进程状态
- 程序计数器
- CPU 寄存器现场
- 调度信息
- 内存管理信息
- 打开的文件和 I/O 信息

TCB 常见内容：

- 线程 ID
- 线程状态
- 程序计数器
- 寄存器
- 栈指针
- 所属进程信息

### 面试表达

> PCB 是操作系统管理进程的“档案”，TCB 是管理线程的“档案”。上下文切换时，操作系统需要保存和恢复这些控制块里的执行现场。

## 进程有哪些状态

### 简要回答

进程常见基本状态有就绪态、运行态、阻塞态；扩展后还可能有创建态、终止态。

### 状态说明

- 创建态：进程正在被创建。
- 就绪态：资源已满足，只差 CPU。
- 运行态：正在 CPU 上执行。
- 阻塞态：等待 I/O、锁、事件等条件。
- 终止态：进程执行结束，等待系统回收。

### 状态转换

```text
创建态 -> 就绪态 -> 运行态 -> 终止态
              ^       |
              |       v
            阻塞态 <- 运行态
```

### 面试表达

> 就绪态和阻塞态的区别是：就绪态只是在等 CPU，阻塞态是在等某个事件或资源，即使 CPU 空闲也不能运行。

### 细节补充

进程的特点：

- 动态性：进程从创建到消亡，有完整生命周期。
- 并发性：多个进程可以并发执行。
- 独立性：进程是资源分配的基本单位。
- 异步性：进程推进速度不可预知，受调度、I/O、同步互斥影响。

引入线程的意义：

- 提高并发性，同一进程内多个执行流可以并发推进。
- 线程之间共享地址空间，通信成本低。
- 创建、切换、撤销线程通常比进程更轻量。
- 图形界面、网络服务等场景中，线程可以提升响应性。

## 进程间通信有哪些方式

### 简要回答

常见 IPC 有管道、命名管道、消息队列、共享内存、信号量、信号、Socket。

### 详细回答

- 管道：适合有亲缘关系的进程，半双工。
- 命名管道：通过文件路径关联，无亲缘关系也能通信。
- 消息队列：按消息为单位传递。
- 共享内存：速度快，但需要同步机制。
- 信号量：主要用于同步和互斥。
- 信号：用于异步通知。
- Socket：可用于本机或跨机器通信。

### 适用场景

- 管道：父子进程之间简单传输数据。
- 消息队列：按消息粒度传递结构化数据。
- 共享内存：大量数据高效传输。
- 信号量：多个进程访问共享资源时做同步。
- Socket：本机不同进程或不同机器之间通信。

### 面试表达

> 如果只看速度，共享内存最快，因为少了内核态数据拷贝；但共享内存本身不解决同步问题，通常要配合信号量或互斥锁。

## 进程调度算法有哪些

### 简要回答

常见调度算法有先来先服务、短作业优先、高响应比优先、时间片轮转、优先级调度、多级反馈队列。

### 详细回答

- 先来先服务：简单，但短任务可能等待很久。
- 短作业优先：平均等待时间短，但可能导致长作业饥饿。
- 高响应比优先：兼顾等待时间和服务时间，响应比越高越优先。
- 时间片轮转：公平，适合分时系统。
- 优先级调度：重要任务优先，但低优先级可能饥饿。
- 多级反馈队列：兼顾响应时间和公平性。

### 适用场景

- 批处理系统：常见先来先服务、短作业优先、高响应比优先。
- 分时系统：常见时间片轮转。
- 交互式系统：常见多级反馈队列。

### 高响应比公式

```text
响应比 = (等待时间 + 要求服务时间) / 要求服务时间
```

等待越久，响应比越高，可以缓解长作业一直得不到调度的问题。

## 线程共享哪些资源，独享哪些资源

### 简要回答

同一进程内线程共享地址空间、堆、全局变量、文件描述符等；每个线程独享栈、寄存器、线程 ID、程序计数器。

### 面试表达

> 线程共享进程的大部分资源，所以通信方便；但每个线程有自己的执行上下文，所以需要独立栈和寄存器状态。

## 进程切换和线程切换有什么区别

### 简要回答

进程切换通常比线程切换更重，因为进程切换涉及地址空间切换，线程切换一般只切换执行上下文。

### 详细回答

进程切换可能导致页表、TLB、缓存命中率受到影响；同进程线程共享地址空间，所以切换成本更低。但线程切换也不是免费，仍然要保存和恢复寄存器、栈等上下文。

## 作业调度、内存调度、进程调度有什么区别

### 简要回答

作业调度决定哪些作业进入系统，内存调度决定哪些进程调入内存，进程调度决定哪个就绪进程获得 CPU。

### 对比表

| 类型 | 决定什么 | 发生层次 |
|---|---|---|
| 作业调度 | 外存作业是否进入系统 | 作业级 |
| 内存调度 | 进程是否调入内存 | 内存级 |
| 进程调度 | 哪个就绪进程运行 | CPU 级 |

### 面试表达

> 三者的粒度不同。作业调度偏“进不进系统”，内存调度偏“在不在内存”，进程调度偏“谁现在用 CPU”。

## 处理机有哪些状态

### 简要回答

处理机常见两种状态是用户态和核心态，也叫用户模式和内核模式。

### 详细回答

- 用户态：普通应用程序运行状态，不能执行特权指令。
- 内核态：操作系统内核运行状态，可以执行特权指令，访问核心资源。

处理机状态的切换通常发生在系统调用、中断、异常时。
